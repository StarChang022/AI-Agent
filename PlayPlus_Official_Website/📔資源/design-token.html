PlayPlus Design System Spec

依據 Anthropic (anthropic.com) 現代人文紙質與高端刊物感（Warm Editorial & Paper Aesthetic）風格重塑之官方網站 Design Tokens、語意化色彩系統、組件應用與 CSS / Tailwind 交付規範。

Anthropic Editorial v2026.3 Active
🌾 主視覺基調： Oat 燕麥暖色 #E3DACC + Ivory 象牙白 #FAF9F5 / #F0EEE6
🖤 核心按鈕與文字： Slate Dark 深石板黑 #141413

🔤 主文字體： DM Sans + Aldrich + Noto Sans TC

1. Global Color Tokens

Anthropic 視覺系統採用溫潤的燕麥紙色（#E3DACC）與暖象牙白（#FAF9F5 / #F0EEE6）為全站氛圍底色，搭配極具質感的深石板黑（#141413）作為主要文字與行動按鈕。點擊 Token 名稱可直接複製變數。

4. RWD Breakpoints & Layout

響應式斷點與版面佈局規則，確保於手機、平板與桌上型螢幕皆能獲得最佳操作體驗。

Mobile Small <= 480px 極窄螢幕優化，按鈕改垂直堆疊、Header 緊湊模式、隱藏浮動徽章。
Mobile <= 768px 桌機選單轉為漢堡選單抽屜、卡片 3 欄 / 2 欄全部轉為單欄、時間軸改 2 欄。
Tablet 769px ~ 1024px Hero 轉單欄垂直排列（視覺置頂）、服務卡片轉 2 欄、時間軸轉 3 欄、頁尾 2 欄。
Desktop >= 1025px 全展開多欄排版，Hero 雙欄並排、服務卡片 3 欄、時間軸 6 欄線性推進。
Wide Desktop >= 1440px 滿版寬螢幕，Container 鎖定 90% (max 1200px) 居中，兩側保留對稱留白。
