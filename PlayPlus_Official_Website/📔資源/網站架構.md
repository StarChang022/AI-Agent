# 檔案與資料夾命名、放置規範

1. 如果是有內頁的架構，請新增該分類資料夾，將內頁新增於分類資料夾內。例如根目錄有 blogs.html 列表頁，則內頁 example.html 路徑為 /blogs/example.html 這樣。
2. 圖片一律放置於 images 資料夾內。
3. 承上，如果是內頁的圖片，請新增該分類資料夾及頁面名稱資料夾，再將圖片放入。例如 /blogs/example.html 的圖片 image.jpg 路徑為 /images/blogs/example/image.jpg 這樣。
4. CSS 一律放置於 css 資料夾內。
5. JS 一律放置於 js 資料夾內。
6. 調整縮排一律使用 Tab Size 4 方式，不要使用空白鍵。
