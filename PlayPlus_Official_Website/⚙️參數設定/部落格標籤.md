## UI/UX

- **搜尋意圖** : 了解介面美學與體驗設計如何轉化為商業價值與營收。
- **涵蓋範疇** : 使用者體驗、轉換率優化、介面改版、信任設計、微互動、產品體驗。

## 技術知識

- **搜尋意圖** : 非工程背景也能看懂的網站架構與底層運作邏輯。
- **涵蓋範疇** : HTTP 狀態碼、API/LINE Bot 架構、網站效能、系統維運、伺服器與資訊安全基礎。

## 預算規劃

- **搜尋意圖** : 解決發包前最直接的焦慮：要花多少錢、錢花去哪裡。
- **涵蓋範疇** : 網站費用結構拆解、訪談報價機制、隱形成本評估、預算分級與投資回報。

## 規格定義

- **搜尋意圖** : 專案如何落地：把模糊的想法收斂成精確的功能範疇。
- **涵蓋範疇** : MVP 最小可行性產品、需求訪談（What/Who/How）、功能優先級拆解、會員系統商業邏輯。
