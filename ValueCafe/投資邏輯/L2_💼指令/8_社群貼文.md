## 貼文格式

貼文格式分為以下4段項目，彼此之間以「<!-- ------------------ 分隔線 ------------------ -->」隔開。

1. **文章來源** : 這篇貼文是閱讀哪則文章。
2. **文章解析** : 閱讀文章後，主要是基於什麼樣的觀點才寫出這篇貼文。
3. **Facebook** : 為 Facebook 撰寫的適合受眾屬性的社群貼文。
4. **Threads** : 為 Threads 撰寫的適合受眾屬性的社群貼文。

## 文件名稱規則

文件名稱 {YYYY}{MM}{DD}{serial}.md 的含義如以下。

- **YYYY** : 當天的西元年。
- **MM** : 當天的月份。
- **DD** : 當天的日期。
- **serial** : 順序流水號，放在當天依照順序排列。如果當天未存在其他社群貼文，則序號為001號；如果已存在001序號，則序號為002號，依此類推。
