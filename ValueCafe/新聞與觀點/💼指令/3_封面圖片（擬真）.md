## 5. Prompt 撰寫指南

呼叫圖片生成工具時，Prompt 必須包含以下結構要素：

1. **構圖方向聲明**：開頭強調 "WIDE LANDSCAPE orientation, 3:2 aspect ratio"，並要求元素佈滿整個畫面寬度。
2. **畫風描述**：明確指定 "photorealistic, cinematic lighting, highly detailed, high quality news editorial photography, realistic texture, 8k resolution"。
3. **構圖內容**：根據 `## 1. 文章情境解析` 提煉的關鍵字，寫實地描述場景、主體人物或物品及其互動方式。善用攝影術語如 "shallow depth of field", "wide angle" 等來增強專業感。
4. **禁止事項**：明確聲明 "NO text, NO labels, NO logos, NO cartoon style"。

## 6. 圖片後處理

由於圖片生成工具預設產出 1024×1024 正方形圖片，需要透過以下 Python 腳本進行後處理，將圖片裁切為 3:2 比例後再等比放大至 1920×1280，避免拉伸失真：

```python
from PIL import Image

img = Image.open('<生成圖片的路徑>')
w, h = img.size

# 裁切為 3:2 比例（保留完整寬度，裁切上下）
target_ratio = 1920 / 1280  # 1.5
new_h = int(w / target_ratio)
top = (h - new_h) // 2
img_cropped = img.crop((0, top, w, top + new_h))

# 等比放大至 1920x1280
img_final = img_cropped.resize((1920, 1280), Image.LANCZOS)

# 儲存為 WebP 格式
img_final.save('<輸出路徑>/cover.webp', 'webp', quality=90)
```
