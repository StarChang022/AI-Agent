# 《股價淨值比》越低越好嗎？只看體重沒辦法挑出跑得快的冠軍馬

淨值代表企業的「資產重量」，但只看重量選不出跑得快的冠軍馬。低 P/B 可能是便宜，也可能是即將報廢的破銅爛鐵。


<!-- ----------- Content ----------- -->

在尋找便宜股票時，許多投資人習慣打開看盤軟體，篩選「股價淨值比（P/B）小於 1」的標的，以為只要用低於淨值的價格買進，就一定是撿到大便宜。

然而，**低 P/B 往往是市場上最容易踩到的價值陷阱之一**。

## 什麼是股價淨值比？

股價淨值比（Price-to-Book Ratio, 簡稱 P/B）衡量的是目前市場股價相對於公司每股淨資產（帳面價值）的倍數。

### 計算公式

```
股價淨值比 (P/B) = 目前股價 ÷ 每股淨值 (Book Value per Share)
每股淨值 = (總資產 - 總負債) ÷ 流通股數
```

- **P/B < 1**：代表目前股價低於公司的帳面淨值，市場以「打折價」在交易這家公司。
- **P/B > 1**：代表投資人願意為公司的資產溢價買單。

## 常見誤區：為什麼淨值打折不一定是賺到？

帳面淨值是歷史會計成本的累積，它有三大致命盲點：

1. **資產變現水分**：倉庫裡過時的存貨、已經落後淘汰的晶圓機台，在報表上雖然記有淨值，但一旦變賣可能連 1 折都賣不掉。
2. **無形資產難以衡量**：偉大企業的強大品牌、專利技術、使用者生態系（如可口可樂、Google），其真實價值遠遠大於帳面資產。
3. **持續虧損會侵蝕淨值**：一家每年虧損 20% 的公司，就算今天 P/B 只有 0.8 倍，兩年後它的淨值就會被虧損吃光，股價自然一路向下。

## 正確用法：P/B 必須與 ROE 聯姻

要判斷低 P/B 到底是不是寶藏，唯一的解方就是**結合 ROE（股東權益報酬率）**：

| P/B 與 ROE 組合 | 股票體質評估 | 市場含義與投資策略 |
| :--- | :--- | :--- |
| **低 P/B + 高 ROE** | 💎 絕佳珍珠 | 被市場過度錯殺的賺錢機器，安全邊際極大，絕佳買點！ |
| **低 P/B + 低 ROE** | 🚨 典型價值陷阱 | 賺錢效率低下，資產正在貶值腐爛，便宜有其道理，勿碰！ |
| **高 P/B + 高 ROE** | 🚀 成長型護城河 | 市場願意給予溢價的優質企業，需等待估值適度回檔。 |

## P/B 估值法最適合應用在哪些產業？

1. **金融與銀行業**：銀行的資產主要由流動性極佳的現金、放款與有價證券構成，淨值極具參考價值。
2. **重資產景氣循環股（鋼鐵、航運、石化）**：在景氣谷底、全市場悲觀虧損導致 P/B 跌至歷史超低區間（如 0.5 ~ 0.7 倍）時，往往是絕佳的週期底部布局信號。

## Mr.Cafe 的投資備忘錄

1. **不買單純因為便宜的低 P/B 爛公司**。
2. **檢視資產真實品質**：剔除商譽過高或存貨積壓嚴重的企業。
3. **搭配歷史 P/B 河流圖**：觀察目前 P/B 處於該公司歷史估值波動的哪一個分位點。
