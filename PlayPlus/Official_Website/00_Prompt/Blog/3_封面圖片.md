## 圖片後處理

由於圖片生成工具預設產出 1024×1024 正方形圖片，需要透過以下 Python 腳本進行後處理，將圖片裁切為 3:2 比例後再等比放大至 1920×1080，避免拉伸失真：

```python
from PIL import Image

img = Image.open('<生成圖片的路徑>')
w, h = img.size

# 裁切為 3:2 比例（保留完整寬度，裁切上下）
target_ratio = 1920 / 1080  # 1.5
new_h = int(w / target_ratio)
top = (h - new_h) // 2
img_cropped = img.crop((0, top, w, top + new_h))

# 等比放大至 1920x1080
img_final = img_cropped.resize((1920, 1080), Image.LANCZOS)

# 儲存為 WebP 格式
img_final.save('<輸出路徑>/cover.webp', 'webp', quality=90)
