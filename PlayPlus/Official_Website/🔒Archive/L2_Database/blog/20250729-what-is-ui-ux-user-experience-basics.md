		<p>造成 UX 失敗的原因，很多來自於錯誤的設計流程，跳過前期的使用者研究與流程規劃，直接進行畫面視覺設計。 UX 不只是一個流程步驟，而是網站的根基。</p>

	<div class="column">
		<h2 class="inside">UI 與 UX 是什麼？為什麼你應該在意？</h2>
		<p>當你聽到「UI/UX 設計」會不會直覺聯想到「設計感」或「動畫效果」，但其實這兩者分別扮演著完全不同的角色，UI（User Interface）使用者介面是你看到的外觀；UX（User Experience）使用者體驗是你實際操作這個網站的過程。</p>
		<h3 class="inside">UX 是藍圖，UI 是裝潢</h3>
		<p>如果把網站設計比喻成蓋一棟房子，那 UX 就像是建築師畫的藍圖，決定格局、動線、水電管線怎麼走；而 UI 則像是室內設計師幫你挑地板、燈具、沙發，讓整體風格看起來舒服。</p>
		<p>UI 解決的是「看起來怎麼樣」，而 UX 關心的是「用起來順不順」。就像你走進一家店，裝潢很美（UI），但動線亂、東西找不到、結帳流程又卡（UX），你很可能一下子就會想要走出去。</p>
		<ul>
			<li>UX 的任務是使用者流程、邏輯與動線設計，關心誰會來用這個網站、想完成什麼任務、怎麼走才能最有效率地走完動線。</li>
			<li>UI 的任務是視覺風格、介面細節的呈現，關心要用什麼字型、配色、按鈕樣式，以及圖片的風格能否和品牌一致。</li>
		</ul>
	</div>
	<div class="column">
		<h2 class="inside">使用者體驗沒做好，網站再漂亮也留不住使用者</h2>
		<p>網站要有人來用，都是圍繞在「流量」和「留住人」這2件事，流量的部分先不在這邊展開討論，「留住人」就是 UX 的任務。</p>
		<p>通常沒辦法留住人不是因為網站不夠漂亮，而是使用者體驗沒做好，來了但撐不到轉換那一步就離開了。反過來說，如果你提供的服務或資訊，是你的目標受眾需要的，而且網站動線幫助他們很容易找到需要的東西，即使網站視覺很平庸，也不會阻止他們來使用網站。</p>
		<h3 class="inside">沉默的流失有多嚴重？</h3>
		<p>前言提到<b>不滿意使用者會直接離開網站而不提出任何反饋</b>，也就是說，你可能根本不知道網站正在持續錯失商機。幾個典型 UX 問題包括以下。</p>
		<ul>
			<li>如果訪客找不到聯絡方式或結帳流程太複雜，他們往往不會回來第二次。</li>
			<li>模糊不清的按鈕文案、過長的表單欄位，都是典型的 UX 阻礙，直接拉低轉換率。</li>
			<li>Google 研究顯示，只要網站載入超過 3 秒，就可能流失 53% 的行動用戶，使用者還沒看到畫面就已經跳出。</li>
			<li>結帳流程步驟太多。</li>
			<li>CTA 按鈕語意不清，例如內容導讀後的按鈕是「提交」，而不是「立即預約」，導致使用者猶豫。</li>
		</ul>
		<p>這些問題看似細微，實際上是網站轉換率的隱性殺手。</p>
		<h3 class="inside">常見流程錯誤與代價</h3>
		<p>發生這些狀況不是能力問題，通常是因為流程錯誤，或者沒有機會認知到「先考慮 UX 再設計 UI」這件事。常見的錯誤包括以下。</p>
		<ul>
			<li>規劃階段沒有定義使用者角色（Persona），就開始畫面設計。</li>
			<li>頁面規劃完全以「老闆想看的」視覺為導向，而不是考慮使用者體驗。</li>
			<li>沒有流程圖、沒有使用者路徑分析，只靠經驗做決策。</li>
			<li>沒有定義任務完成目標與轉換行為，導致網頁缺乏商業導向。</li>
		</ul>

		<h2 class="inside">如何提升網站轉換率？先從 UX 開始</h2>
		<p>談到「轉換率」，大家可能會想到買廣告、做SEO，這是沒錯的，但除此之外，也不要忽略「使用者體驗」這個根本問題唷，不然就會白白流失你投入的金額和努力。</p>
		<p>根據 Forrester 的研究顯示，每投資1元在 UX 上，平均可帶來100元的報酬，我無法保證實際上有沒有那麼高的報酬率，但一定會帶來你感受得到的效果。既然都決定要灌水到水桶裡面，盡量把水桶的漏洞補起來，絕對可以讓你更快灌到目標水平線。</p>
		<h3 class="inside">UX 投資的三大紅利</h3>
		<ol>
			<li><b>提高轉換率。</b>使用者可以更快完成他想做的事，像是預約、填表、下單或聯絡你。例如同樣是電商購物平台，蝦皮用起來有沒有比其他平台順，讓你更願意繼續使用？</li>
			<li><b>降低客服與營運成本。</b>一個設計良好的網站，能幫助使用者在不提問的情況下完成任務，這代表你不用回答重複的問題。</li>
			<li><b>建立品牌信任與忠誠度。</b>使用者在你網站上體驗愉快、任務順利，會提升使用者的信心與信任度。</li>
		</ol>
