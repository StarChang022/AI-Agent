# MetaTag

**id**: 此頁面的網址結尾命名，並加上當天的日期（YYYYMMDD-）。例如「20260323-line-chatbot-business」這樣。
**title**: 此頁面的標題。
**description**: 此頁面的描述，並用於搜尋引擎爬蟲的 Meta Description 值。規劃 description 的方式，不要用「本文將...」或「剖析」什麼的，我要的是直接告訴讀者這篇文章在講什麼。
**keywords**: 此頁面的關鍵字，並用於搜尋引擎爬蟲的 Meta Keywords。
**name**: 頁面簡短名稱，作為首頁與列表頁的文章標題
**tags**: 組成方式是從 `## 標籤` 裡面選出適合的標籤，數量不限於1個。如果有多個標籤，每個標籤之間以半形逗號及空格隔開。例如「Macro, Commodities, Forex」。
**date**: 當天日期，格式為 YYYY/MM/DD 。
