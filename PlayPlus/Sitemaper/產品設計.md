# Rules

1. 所有功能請使用 CSS 和 JS 完成，請放置獨立資料夾，不要混雜在 Html 檔案內。
1. 儲存資料則需要規劃 JSON 或 JS 方式，由你判斷。
1. 暫時不用做帳號密碼登入，就只有我1個使用者。

# 畫布檢視

（參考 A 圖片）

我要將專案詳情內頁的規格表攤開在畫布上，這樣可以方便我後續與團隊討論時檢視。

1. 像是 Figma 那樣，可以任意拖拉分組、可以任意放大縮小。
2. 切換每個分組的每列排列「1欄／2欄／3欄」。
3. 切換每個分組底下的卡片資訊「全部展開／最多3行／僅留標題」。
4. 「回到專案」按鈕、「回到首頁」按鈕。
