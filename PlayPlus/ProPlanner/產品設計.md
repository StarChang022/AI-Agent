# 專案管理首頁

用於管理多個專案。

1. 卡片樣式呈現專案概略資訊，每1列4張卡片。
2. 卡片可以封存。所以剛進入此頁面看到的是一般卡片，但要有個地方可以檢視封存資料夾。專案卡片和資料夾卡片都可以封存。
3. 可以新增資料夾，資料夾就同樣是卡片，可以任意將專案卡片放入或移出。資料夾卡片和專案卡片放在同樣的層級，點擊進去可以看到資料夾裡面的卡片。資料夾裡面可以再新增資料夾以及專案卡片，所以是無限層級。
4. 承上，所以介面上方需要 Breadcrumb 。
5. 
6. ［**資料夾卡片欄位**］每張卡片都固定同一個 icon（置中）、資料夾名稱、操作按鈕（重新命名／刪除／封存或解除封存／移動到指定資料夾底下或根目錄）。

# 專案詳情內頁

（參考 [詳情檢視](directory;file:///Users/starchang/Documents/CloudFolder/GitHub/AI-Agent/PlayPlus/ProPlanner/images/詳情檢視.png) 圖片）

點擊指定專案後進入查看詳情的頁面。所有編輯格都採用「所見即所得」的管理方式，也就是畫面上的欄位，點擊後可以直接編輯。

## 畫面上半部

1. ［**上**］標題區塊（專案名稱／簡述），區塊的右邊放個點點點按鈕（緊貼著，不是置右），點擊後下拉式展開動作（刪除／封存或解除封存／移動到指定資料夾底下或根目錄）。
2. ［**中**］客戶名稱、統一編號、聯絡人名稱、聯絡人 Email 。
3. ［**下**］備註區。平常最多只顯示1行，其餘文字就呈現點點點，點擊會展開 PopUp 看到完整內容。參考附圖 [notion](directory;file:///Users/starchang/Documents/CloudFolder/GitHub/AI-Agent/PlayPlus/ProPlanner/images/notion.png) ，像是 Notnio 那樣編輯文字樣式，只有文字顏色、文字底色、粗體、斜體、下底線、刪除線、超連結、清除樣式。

## 畫面下半部

1. 規格 Table 表格（要可以直接從 Google Sheet 的儲存格複製貼上）。
2. 「回到首頁」按鈕。
3. 切換「詳情檢視／分組檢視」。
4. 另外放1顆「畫布檢視」按鈕，點擊後進到畫布檢視頁面。
5. ［**詳情檢視**］預設格式，將所有欄位直接攤開的 Excel 樣式。
6. ［**分組檢視**］相同模組的項目合併成1個群組，參考附圖 [分組檢視](directory;file:///Users/starchang/Documents/CloudFolder/GitHub/AI-Agent/PlayPlus/ProPlanner/images/分組檢視.png) 。
7. ［**表格欄位**］模組、項目、說明、分類（前台／後台／系統）。
8. 「分類」是事先設定好的選項，但「模組」是每個專案獨立管理。可參考 Notino 管理方式。
9. 表格上方要有「管理分組／匯出 Excel」2個按鈕。「匯出 Excel」顧名思義就是要將表格內容繪製成 Excel 並匯出；「管理分組」則是切換為「分組檢視」時出現，拖曳調整分組位置。

# 畫布檢視

（參考 [figma](directory;file:///Users/starchang/Documents/CloudFolder/GitHub/AI-Agent/PlayPlus/ProPlanner/images/figma.png) 圖片）

我要將專案詳情內頁的規格表攤開在畫布上，這樣可以方便我後續與團隊討論時檢視。

1. 像是 Figma 那樣，可以任意拖拉分組、可以任意放大縮小。
2. 切換每個分組的每列排列「1欄／2欄／3欄」。
3. 切換每個分組底下的卡片資訊「全部展開／最多3行／僅留標題」。
4. 「回到專案」按鈕、「回到首頁」按鈕。
