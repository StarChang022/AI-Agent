# QA Checklist — 稽核日誌模組

> **驗證對象**：管理員查看稽核日誌時，可見範圍、篩選、明細內容與唯讀規則是否正確；員工與其他公司是否被正確擋住；各模組的操作是否都有寫入日誌。
> **前置**：準備兩家公司的帳號（各有管理員），其中一家有至少一名員工，並有已停用的員工；先做過一些操作（新增、編輯、刪除、還原、永久刪除、狀態切換、作廢、取消作廢）讓日誌有資料。
> **注意**：本清單只驗證「功能流程與規則」；顏色、字級、按鈕樣式等 UI 細節由設計規範統一把關，不在此列。
> **日誌的顯示名稱**：「後台 → 系統 → 稽核日誌」。

---

## 1. 進入權限

- [ ] 管理員登入後台 → 左側「系統」群組看得到「稽核日誌」
- [ ] 員工登入 → 前台與選單都看不到「稽核日誌」
- [ ] 員工直接在網址輸入稽核日誌頁面 → 被導回前台，看不到任何日誌內容
- [ ] 員工直接在網址輸入其他後台頁面（如支出管理）→ 同樣被導回前台
- [ ] 未登入直接輸入稽核日誌網址 → 導向登入頁
- [ ] 管理員從手機瀏覽稽核日誌 → 可正常查看列表與明細

## 2. 列表基本內容

- [ ] 管理員進入稽核日誌 → 看到本公司全部紀錄，最新的在最上面
- [ ] 每一筆列出：時間、操作人、對象、動作
- [ ] 列表每一列有「查看」按鈕 → 點了打開該筆明細；列表本身不列出異動欄位
- [ ] 點列表的任一整列 → 同樣打開該筆明細
- [ ] 紀錄很多時 → 可分頁瀏覽，可切換每頁筆數；翻頁後排序仍是由新到舊
- [ ] 還沒有任何紀錄的新公司 → 顯示「目前沒有紀錄」之類的空狀態，不報錯
- [ ] 載入中與重新篩選時 → 列表顯示載入中的狀態

## 3. 對象的顯示

對象欄位顯示「類型 ＋ 該筆名稱」：

- [ ] 支出 → 顯示「支出」加賣方名稱
- [ ] 收入 → 顯示「收入」加客戶名稱
- [ ] 代墊款 → 顯示「代墊款」加申請人姓名
- [ ] 支出的賣方是空白、或收入的客戶是空白 → 改顯示該筆的日期與金額
- [ ] 帳戶 → 顯示「帳戶」加帳戶名稱
- [ ] 類別 → 顯示「類別」加類別名稱
- [ ] 固定收支範本 → 顯示「固定收支範本」加項目名稱
- [ ] 資金移轉 → 顯示「資金移轉」加「轉出帳戶 → 轉入帳戶」
- [ ] 預算 → 顯示「預算」加「類別名稱＋期間」，例如「交通費 2026/11 月預算」「交通費 2026 年預算」
- [ ] 一筆已移到垃圾桶的紀錄 → 日誌仍看得到它的名稱
- [ ] 一筆已永久刪除的紀錄 → 日誌仍看得到它的名稱（從當時留下的內容取得）
- [ ] 對象之後被改名（例如帳戶改名）→ 舊的日誌一律顯示現在的新名稱，不會整列消失或出現空白
- [ ] 已永久刪除的對象，之前曾改過名 → 日誌顯示刪除當時的名稱

## 4. 動作的顯示與篩選

- [ ] 動作下拉選單共 **8 種**：建立、編輯、刪除、還原、永久刪除、狀態切換、作廢、取消作廢；**沒有「退款」**
- [ ] 選「建立」→ 列表包含：手動新增的紀錄、固定收支自動產生的紀錄、Excel 匯入的紀錄、資金移轉產生的手續費支出
- [ ] 固定收支自動產生的紀錄 → 列表動作處顯示「固定收支自動產生」字樣
- [ ] 資金移轉自動產生的手續費支出 → 列表動作處顯示「資金移轉手續費自動產生」字樣
- [ ] Excel 匯入的紀錄 → 列表動作處顯示「Excel 匯入」字樣
- [ ] 選動作「建立」→ Excel 匯入的紀錄仍在結果內；選「編輯」→ 匯入時重新啟用類別產生的紀錄（同樣標示 Excel 匯入）找得到
- [ ] 支出／收入／代墊款詳情抽屜的歷程中，Excel 匯入的紀錄 → 顯示同樣的「Excel 匯入」字樣，不會再多一行「建立方式」
- [ ] 固定收支自動產生的紀錄 → 操作人顯示範本的建立者
- [ ] 選其他動作（如「刪除」）→ 只剩該動作的紀錄

## 5. 篩選

### 5.1 對象

- [ ] 對象下拉選單有 8 種類型：支出、收入、代墊款、帳戶、類別、固定收支範本、資金移轉、預算
- [ ] 選一種類型 → 只列出該類型的紀錄，與名稱無關（例如選「支出」，所有賣方的支出都在）

### 5.2 操作人

- [ ] 操作人下拉選單列出本公司全部人員（管理員、員工）
- [ ] 已停用的員工 **也在選單內**，選他可查到他當時的操作
- [ ] 邀請中、尚未加入的人 → **不在**選單內
- [ ] 選一位沒有任何操作紀錄的人 → 顯示查無紀錄
- [ ] 選一位操作人 → 只列出他操作的紀錄
- [ ] 選單內不會出現其他公司的人

### 5.3 日期

- [ ] 設定起訖日期 → 只列出操作時間落在該區間的紀錄（以「操作的時間」為準，不是該筆支出／收入本身的日期）
- [ ] 選定區間的**最後一天深夜**（如 23:30）的紀錄 → 仍出現在結果內
- [ ] 選定區間的第一天凌晨（如 00:10）的紀錄 → 出現在結果內
- [ ] 區間前一天深夜、後一天凌晨的紀錄 → 不出現
- [ ] 只選起始日 → 列出該日（含）之後的紀錄

### 5.4 組合與清除

- [ ] 同時選對象＋動作＋操作人＋日期 → 結果同時符合全部條件
- [ ] 任一條件改變後 → 分頁回到第一頁
- [ ] 條件下沒有符合的紀錄 → 顯示查無資料，且有清除條件的方式
- [ ] 清除條件 → 回到完整列表

## 6. 明細（變更前後內容）

- [ ] 點「查看」按鈕或整列打開一筆 → 看到變更前與變更後的內容
- [ ] 「建立」→ 只有變更後內容，沒有變更前，且列出全部欄位
- [ ] 「編輯」「狀態切換」等其他動作 → 只列出有異動的欄位，前後內容並列
- [ ] 「永久刪除」→ 看得到被刪除時的完整內容（列出全部欄位）
- [ ] 「刪除」（移到垃圾桶）→ 看得到刪除時間；完整內容留在之後的永久刪除紀錄
- [ ] 「狀態切換」（如待付款改已付款）→ 看得到狀態與相關日期的前後變化
- [ ] 「作廢」「取消作廢」→ 看得到前後狀態
- [ ] 內容依**欄位名稱**顯示（如「金額」「賣方」「類別」），不出現英文欄位名稱或一串代號
- [ ] 內容中提到類別、帳戶、人員時 → 顯示名稱，不顯示代號
- [ ] 金額、日期、狀態、是／否 → 以一般人看得懂的格式顯示（千分位、日期格式、中文狀態）
- [ ] 永久刪除後的紀錄、已移到垃圾桶的紀錄 → 明細仍可完整開啟
- [ ] 明細可用 Esc 或關閉按鈕關閉，關閉後回到原本的列表位置與篩選條件

## 7. 唯讀

- [ ] 列表與明細都**沒有**編輯、刪除、新增按鈕
- [ ] 沒有任何方式可以修改或清除日誌（包含多選、批次操作）
- [ ] 管理員對一筆紀錄做永久刪除 → 日誌不會因此消失，反而多一筆「永久刪除」紀錄

## 8. 公司間隔離

- [ ] A 公司管理員看不到 B 公司的任何紀錄
- [ ] A 公司的操作人選單看不到 B 公司的人
- [ ] A 公司管理員用 B 公司某筆紀錄的明細網址／編號直接開 → 看不到內容（顯示找不到或無權限）
- [ ] 兩家公司各自操作後 → 各自只看得到自己的新紀錄

## 9. 各模組的操作是否寫入日誌

對每項操作執行後，到稽核日誌確認有一筆對應紀錄（對象、動作、操作人、時間正確）：

### 9.1 支出／收入／代墊款

- [ ] 新增一般支出 → 建立
- [ ] 編輯支出 → 編輯，明細看得到改了什麼
- [ ] 支出標記已付款／改回待付款 → 狀態切換
- [ ] 收入標記已收款／改回待收款 → 狀態切換
- [ ] 支出移到垃圾桶 → 刪除；從垃圾桶還原 → 還原；永久刪除 → 永久刪除
- [ ] 收入同上（建立、編輯、狀態切換、刪除、還原、永久刪除）
- [ ] 員工提交代墊款 → 建立
- [ ] 員工編輯自己的代墊款（一般編輯）→ 編輯
- [ ] 員工提交送審、被駁回後重送、撤回 → 各有一筆「狀態切換」
- [ ] 管理員核准、駁回、發放 → 各有一筆「狀態切換」
- [ ] 管理員核准 → 另有一筆對應支出的「建立」紀錄
- [ ] 代墊款作廢、取消作廢 → 作廢、取消作廢
- [ ] 代墊款作廢 → 連動的支出另有一筆「刪除」；取消作廢 → 連動的支出另有一筆「還原」
- [ ] Excel 匯入多筆 → 每筆各有一筆「建立」，動作處顯示「Excel 匯入」

### 9.2 帳戶、固定收支、資金移轉

- [ ] 新增、編輯、刪除、還原、永久刪除帳戶 → 各有紀錄
- [ ] 修改帳戶起始金額或起始月份 → 有「編輯」紀錄，明細看得到前後數值
- [ ] 新增、編輯、刪除、還原、永久刪除固定收支範本 → 各有紀錄
- [ ] 固定收支排程自動產生一筆待付款／待收款 → 有「建立」紀錄，標示「固定收支自動產生」
- [ ] 新增資金移轉 → 有移轉的「建立」紀錄
- [ ] 資金移轉含手續費 → 另有手續費支出的「建立」紀錄，標示「資金移轉手續費自動產生」
- [ ] 編輯、刪除、還原、永久刪除資金移轉 → 各有紀錄；手續費支出隨之異動也有紀錄

### 9.3 類別

- [ ] 新增類別 → 建立
- [ ] 編輯類別名稱或會計科目 → 編輯
- [ ] 停用類別 → 有一筆「編輯」紀錄，明細看得到啟用狀態的前後變化；啟用類別 → 同樣是「編輯」
- [ ] 刪除、還原、永久刪除類別 → 各有紀錄
- [ ] Excel 匯入時新增了新類別 → 日誌有一筆該類別的「建立」，標示「Excel 匯入」，操作人是執行匯入的人
- [ ] Excel 匯入時重新啟用了停用中的類別 → 日誌有一筆該類別的「編輯」，同樣標示「Excel 匯入」，操作人是執行匯入的人
- [ ] **調整類別排序** → 日誌**不會**新增紀錄
- [ ] 新公司註冊自動產生的起始類別 → 日誌**不會**有紀錄
- [ ] 新增含手續費的資金移轉，導致「手續費」類別被自動補回或調整 → 日誌**不會**為類別新增紀錄

### 9.4 預算

- [ ] 設定某類別某月的預算 → 有一筆「建立」，對象顯示如「交通費 2026/11 月預算」
- [ ] 設定某類別整年的預算 → 有一筆「建立」，對象顯示如「交通費 2026 年預算」
- [ ] 修改預算金額並儲存 → 有一筆「編輯」，明細看得到金額前後變化
- [ ] 儲存時金額與原本相同 → 日誌**不會**新增紀錄
- [ ] 清除某期預算 → 有一筆「刪除」，明細看得到清除前的完整內容
- [ ] 預算清除後 → 該筆日誌的對象仍顯示類別名稱與期間，不會空白；類別之後改名，顯示新名稱
- [ ] 編輯基本預算（設定或修改金額）→ 日誌**不會**新增紀錄
- [ ] 套用基本預算 → 每個受影響的預算各有一筆紀錄，標示「套用基本預算」，操作人是套用的人
- [ ] 套用基本預算時，原本沒有預算的類別 → 記「建立」；金額不同的 → 記「編輯」
- [ ] 套用基本預算時，金額本來就相同的類別 → 不記
- [ ] 基本預算為 0 或沒設定，套用後原有預算被清除 → 每筆記「刪除」，標示「套用基本預算」
- [ ] 停用有預算的類別 → 當期與未來每一期的預算各有一筆「刪除」，標示「類別停用或刪除連帶清除」，操作人是停用類別的人
- [ ] 刪除（移到垃圾桶）有預算的類別 → 同上，當期與未來的預算各一筆「刪除」，標示相同，操作人是刪除類別的人
- [ ] 上述連帶清除 → 過往月份的預算不受影響，也沒有對應日誌
- [ ] 類別改名後 → 該類別預算的日誌對象（含舊紀錄，不論預算是否已清除）顯示新名稱
- [ ] 類別永久刪除後 → 該類別預算的日誌仍顯示刪除當時的類別名稱
- [ ] 對象篩選選「預算」→ 只出現預算的紀錄，不混入類別等其他對象

## 10. 操作人與時間

- [ ] 管理員操作 → 操作人顯示該管理員姓名
- [ ] 員工提交代墊款 → 操作人顯示該員工
- [ ] 員工後來被停用 → 舊紀錄操作人仍顯示他的姓名
- [ ] 時間以台北時間顯示，與實際操作的時間一致（跨日的操作歸在正確的那一天）

## 11. 不影響既有功能

- [ ] 支出／收入／代墊款詳情抽屜內的「歷程紀錄」→ 歷程的內容與筆數不變；動作文字與稽核日誌頁用相同名稱（編輯、狀態切換、刪除、還原）
- [ ] 稽核日誌頁新增後，各模組的新增、編輯、刪除等操作速度與結果與先前一致，沒有因寫日誌失敗而操作失敗
