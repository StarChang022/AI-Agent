# QA：垃圾桶批次還原與永久刪除

> 對應規格：產品規格文件 第 18 條「批次還原與永久刪除」（2026-11-06 定案）。
> 適用範圍：**只有支出、收入**的垃圾桶；其他垃圾桶維持逐筆操作。
> 視角：管理員。收入垃圾桶請整份清單再驗一輪（第 12 節）。

## 測試前準備

- [ ] 準備至少 25 筆在垃圾桶的支出（超過兩頁，每頁 10 筆），分屬不同類別、不同日期，方便測換頁與篩選
- [ ] 其中包含：一般支出、來源代墊款尚未作廢的支出（≥3 筆）、來源代墊款已作廢的支出（≥1 筆）、資金移轉手續費支出（移轉也在垃圾桶的 ≥1 筆、移轉已不在垃圾桶／手續費改為 0 而留在垃圾桶的各 ≥1 筆）
- [ ] 收入垃圾桶準備至少 25 筆一般收入

---

## 1. 勾選與全選

- [ ] 進入支出垃圾桶 → 每一列都有勾選框，表頭有勾選框
- [ ] 沒有勾選任何一筆 → 看不到「已選取」文字，也沒有「還原」「永久刪除」按鈕
- [ ] 勾選 1 筆 → 顯示「已選取本頁 1 筆」，並出現「還原」「永久刪除」兩個按鈕
- [ ] 逐筆勾選或取消 → 已選取筆數即時跟著變；全部取消後提示與按鈕消失
- [ ] 按表頭勾選框 → 只選取目前這一頁的全部紀錄（例如本頁 10 筆就顯示「已選取本頁 10 筆」），不會選到其他頁
- [ ] 本頁已全選時再按表頭勾選框 → 本頁選取全部取消
- [ ] 本頁只勾選部分筆數 → 表頭勾選框呈現「部分選取」，不是全選

## 2. 選取清空的時機

- [ ] 勾選數筆後換到下一頁 → 選取清空，提示與按鈕消失；回到上一頁也不會保留先前勾選
- [ ] 勾選數筆後改變每頁筆數（10 → 20）→ 選取清空
- [ ] 勾選數筆後變更任一篩選條件 → 選取清空
- [ ] 勾選數筆後輸入或修改關鍵字搜尋 → 選取清空
- [ ] 勾選數筆後點開某筆詳情再關閉 → 選取維持不變（只看詳情不算異動）
- [ ] 重新整理頁面或離開垃圾桶再回來 → 沒有任何勾選

## 3. 批次還原

- [ ] 勾選 3 筆（一般支出）按「還原」→ 這 3 筆離開垃圾桶，回到支出列表，沒勾選的仍在垃圾桶
- [ ] 還原完成 → 顯示成功 3 筆，垃圾桶列表與總筆數立即更新、選取清空
- [ ] 還原回來的支出內容（金額、類別、日期、帳戶、狀態）與進垃圾桶前一致
- [ ] 跨頁情境：第 1 頁勾選 2 筆還原，再到第 2 頁 → 第 2 頁的紀錄沒有被誤還原
- [ ] 勾選 3 筆按「還原」→ 先跳出確認視窗，顯示「3 筆」（與實際勾選筆數相同），此時紀錄尚未還原
- [ ] 在確認視窗按確認 → 才開始還原，結果同上
- [ ] 在確認視窗按取消 → 視窗關閉，沒有任何紀錄被還原，已勾選的仍保持勾選
- [ ] 按 Esc 關閉視窗 → 與取消相同，沒有還原、選取保留
- [ ] 還原的確認視窗**沒有**作廢原因欄位，也沒有「無法還原」提示（還原不需填原因）
- [ ] 確認後連續快速點擊確認 → 只處理一次
- [ ] 垃圾桶內某一列的單筆「還原」→ **仍不跳**確認視窗，直接還原
- [ ] 還原後的支出，到支出列表可以用原本的條件查到

## 4. 批次永久刪除：確認視窗

- [ ] 勾選 3 筆一般支出按「永久刪除」→ 跳出確認視窗，顯示「3 筆」（與實際勾選筆數相同）
- [ ] 確認視窗有明確提示「永久刪除後無法還原」
- [ ] 不含「來源代墊款尚未作廢」的支出時 → 確認視窗**沒有**作廢原因欄位，也沒有代墊款作廢的提示
- [ ] 在確認視窗按取消 → 視窗關閉，沒有任何紀錄被刪除，已勾選的仍保持勾選
- [ ] 按 Esc 關閉視窗 → 與取消相同，沒有刪除任何紀錄
- [ ] 確認刪除後 → 這幾筆從垃圾桶消失，到支出列表、報表、儀表板、稽核以外的任何地方都找不到，也無法再還原
- [ ] 沒勾選的紀錄不受影響，仍在垃圾桶

## 5. 批次永久刪除：含來源代墊款尚未作廢的支出

> 這類支出是員工代墊款經管理員「核准」後產生的支出，其來源代墊款目前是「已核銷（待發放）」、尚未作廢。已發放的支出不能刪除，不會出現在垃圾桶。

- [ ] 勾選 5 筆，其中 2 筆來源代墊款尚未作廢 → 確認視窗顯示總筆數「5 筆」，另外提示「其中 2 筆的來源代墊款會同時作廢」（數字為 2，不是 5）
- [ ] 此時確認視窗出現「作廢原因」欄位，且為必填
- [ ] 作廢原因留空按確認 → 擋下，提示要填寫作廢原因，沒有任何紀錄被刪除
- [ ] 只輸入空白字元 → 視同沒填，擋下
- [ ] 填入原因後確認 → 5 筆都被永久刪除
- [ ] 到代墊款（請款）列表查看那 2 筆的來源代墊款 → 狀態都變成「已作廢」，作廢原因都是剛才填的**同一段文字**
- [ ] 沒有被勾選、也不是這 2 筆來源的其他代墊款 → 狀態不變
- [ ] 員工在前台看自己那兩筆請款 → 也顯示已作廢與原因
- [ ] 勾選的全部都是一般支出（沒有代墊款來源）→ 不出現作廢原因欄位
- [ ] 勾選的全部都是來源代墊款尚未作廢的支出 → 提示筆數等於勾選筆數，仍要填原因
- [ ] 同一張代墊款只對應一筆支出，不會因此重複作廢或重複計數

## 6. 部分失敗

> 單筆不能做的，批次也不能做，列為失敗，不影響其他筆。

### 6-1 批次還原

- [ ] 勾選混合：2 筆一般支出 + 1 筆來源代墊款已作廢的支出 + 1 筆資金移轉產生的手續費支出，按「還原」→ 完成後顯示「成功 2 筆、失敗 2 筆」
- [ ] 失敗清單逐筆列出項目（可辨識是哪一筆）與原因：「來源代墊款已作廢，不可還原」、「手續費由資金移轉產生，不可還原」之類，兩筆原因各自正確
- [ ] 成功的 2 筆已回到支出列表；失敗的 2 筆仍留在垃圾桶
- [ ] 完成後垃圾桶列表與總筆數正確（少了成功的那幾筆，失敗的還在）
- [ ] 全部都失敗（只勾來源已作廢的）→ 顯示成功 0 筆、失敗 N 筆與原因，沒有任何紀錄離開垃圾桶
- [ ] 失敗清單可以關閉；關閉後不影響列表繼續操作

### 6-2 批次永久刪除

- [ ] 勾選混合：2 筆一般支出 + 1 筆「移轉仍在垃圾桶的手續費支出」，按「永久刪除」並確認 → 顯示成功 2 筆、失敗 1 筆，原因為「所屬資金移轉還在垃圾桶，不可單獨永久刪除」之類
- [ ] 失敗的那筆留在垃圾桶，成功的 2 筆消失
- [ ] 手續費改為 0 而留在垃圾桶的支出（移轉不在垃圾桶）→ 批次永久刪除可以成功
- [ ] 來源代墊款已作廢的支出 → 批次永久刪除**可以**成功（只有還原會被擋）
- [ ] 只勾選來源代墊款已作廢的支出按「永久刪除」→ 確認視窗不提示代墊款作廢、不要求填作廢原因，只有筆數與無法還原提示
- [ ] 部分失敗時，含代墊款作廢的筆數：只有**實際刪除成功**的那幾筆，其來源代墊款才變成已作廢；失敗那筆的代墊款維持原狀
- [ ] 失敗清單所列的項目數 + 成功筆數 = 勾選總筆數

## 7. 本頁全部移出時回到前一頁

- [ ] 垃圾桶共 25 筆，切到第 3 頁（5 筆），全選本頁 → 還原或永久刪除成功後，自動回到第 2 頁，不會停在空白的第 3 頁
- [ ] 回到前一頁後，列表與總筆數正確，選取已清空
- [ ] 只有 1 頁時，全部紀錄都移出 → 顯示垃圾桶空白狀態，不會報錯
- [ ] 第 2 頁全選但其中有失敗的、留在原頁 → 停留在本頁，不回上一頁
- [ ] 在非最後一頁全選並刪除 → 留在同一頁，後面的紀錄補上來

## 8. 不能重複送出

- [ ] 按下確認後，處理期間「還原」「永久刪除」與確認視窗的確認按鈕都停用 → 連續快速點擊也只處理一次
- [ ] 處理期間列表勾選不會造成第二次送出；完成後按鈕恢復
- [ ] 實際核對：快速連點確認後，稽核日誌中同一筆紀錄不會出現兩次刪除或兩次還原
- [ ] 處理失敗（例如斷網）→ 按鈕恢復可再操作，紀錄沒有被誤刪，並有錯誤提示

## 9. 稽核日誌

- [ ] 批次還原 3 筆 → 稽核日誌新增 3 筆「還原」紀錄，每筆各對應一筆支出，不是合併成一筆
- [ ] 批次永久刪除 3 筆 → 稽核日誌新增 3 筆「永久刪除」紀錄，各自對應自己的支出
- [ ] 部分失敗時 → 只有成功的紀錄寫入稽核日誌；失敗的不寫入
- [ ] 含代墊款作廢時 → 每張被作廢的代墊款也各寫一筆作廢紀錄，且記錄的原因為填寫的原因
- [ ] 稽核日誌的操作人為執行的管理員、時間為實際操作時間
- [ ] 稽核日誌的格式與內容比照單筆操作（同樣的動作名稱與摘要）

## 10. 權限與資料隔離

- [ ] 員工帳號無法進入後台垃圾桶，也沒有任何批次操作入口
- [ ] 管理員只能看到並操作自己公司垃圾桶內的紀錄
- [ ] 另一家公司的管理員，無法對這家公司的垃圾桶紀錄做還原或永久刪除（即使知道紀錄編號）

## 11. 手機版

- [ ] 手機寬度下，垃圾桶每列可以勾選，表頭可以全選本頁
- [ ] 手機版勾選後「已選取本頁 X 筆」與「還原」「永久刪除」按鈕可見、可點，不被遮住
- [ ] 手機版確認視窗完整顯示筆數、無法還原提示；含代墊款時的作廢原因欄位可輸入
- [ ] 手機版部分失敗時，失敗清單可以捲動閱讀，每筆項目與原因看得到
- [ ] 手機版換頁、改每頁筆數、改篩選後選取同樣清空
- [ ] 手機版處理完成後回到前一頁行為與桌機一致

## 12. 收入垃圾桶（同樣驗一輪）

- [ ] 進入收入垃圾桶 → 每列可勾選，表頭為「本頁全選」，勾選後顯示「已選取本頁 X 筆」與「還原」「永久刪除」
- [ ] 全選只選本頁；換頁、改每頁筆數、改篩選、改關鍵字後選取清空
- [ ] 批次還原勾選的收入 → 回到收入列表，沒勾選的仍在垃圾桶，顯示成功筆數
- [ ] 收入批次還原前同樣先跳確認視窗，顯示選取筆數；取消或 Esc 不還原且選取保留；確認後才還原。單筆還原仍不跳視窗
- [ ] 批次永久刪除 → 確認視窗筆數正確、有「永久刪除後無法還原」提示
- [ ] 收入沒有來源代墊款 → 永久刪除確認視窗**沒有**作廢原因欄位與代墊款提示
- [ ] 確認後，勾選的收入從垃圾桶消失，沒勾選的不受影響
- [ ] 部分失敗：若能製造單筆不可操作的收入情境，失敗項目留在垃圾桶並列出原因；若系統沒有此類情境，則確認收入批次操作不會出現「手續費」「來源代墊款」的失敗訊息
- [ ] 本頁全部移出時回到前一頁；處理中不能重複送出
- [ ] 稽核日誌每筆收入各一筆還原或永久刪除紀錄
- [ ] 手機版可勾選與操作
- [ ] 員工無法進入、他公司管理員無法操作

## 13. 其他垃圾桶不受影響

- [ ] 類別、帳戶、資金移轉、固定收支等其他垃圾桶 → 沒有勾選框與批次按鈕，維持逐筆還原／永久刪除
- [ ] 支出垃圾桶內單筆還原、單筆永久刪除仍可正常使用，規則與批次一致（含來源代墊款作廢需填原因）
