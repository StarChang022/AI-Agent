# QA Checklist — 類別管理模組

> **驗證對象**：管理員操作類別管理功能時，各種情境下的行為與規則是否正確。
> **前置**：以管理員身分登入後台，進入「類別管理」頁面。若要從全新狀態測試，請洽工程師協助重置資料。
> **注意**：本清單只驗證「功能流程與規則」；顏色、字級、按鈕樣式等 UI 細節由設計規範統一把關，不在此列。

---

## 1. 初次進入頁面

- [ ] 頁面上方有「支出類別」「收入類別」兩個分頁，預設停在「支出類別」
- [ ] 「支出類別」看到 **14 筆起始類別**：交通費、差旅費、伙食費、文具用品、郵電費、水電瓦斯費、廣告費、交際費、修繕費、教育訓練費、保險費、租金支出、其他費用、手續費（「手續費」是資金移轉用的系統保留類別，見第 13 節）
- [ ] 「收入類別」看到 **4 筆起始類別**：銷售收入、服務收入、利息收入、其他收入
- [ ] 支出類別與收入類別各自獨立管理：在一邊新增、編輯、停用、排序，不影響另一邊
- [ ] 起始類別與使用者自建類別在外觀上**沒有差別**（不會有「預設」標記），也不受任何操作限制；唯一例外是「手續費」：列表上標示系統保留，不能停用、刪除（可改名，見第 13 節）
- [ ] 頁面上方分成兩區：「使用中」與「已停用」，兩區都顯示目前數量
- [ ] 首次進入預設停在「使用中」區
- [ ] 「支出類別」的「使用中」有 14 筆、「已停用」有 0 筆；「收入類別」的「使用中」有 4 筆、「已停用」有 0 筆
- [ ] 清單欄位為：類別名稱、會計科目、使用筆數、操作按鈕（「本月支出」欄已不存在；要看金額請到「類別預算」頁）

## 2. 新增類別

- [ ] 點頁面右上「新增類別」→ 出現填寫視窗（類別種類、類別名稱、會計科目代碼）；種類預設為目前所在的分頁，可改選
- [ ] 若「使用中」清單為空 → 出現引導訊息與「新增類別」按鈕；點該按鈕效果等同於右上的「新增類別」（同一個填寫視窗）
- [ ] 只填名稱、代碼留空 → 可成功建立
- [ ] 名稱留空按儲存 → 出現錯誤提示「請填寫類別名稱」，視窗不關
- [ ] 輸入的名稱與現有類別相同（不分大小寫、不管前後有沒有空格）→ 出現「已有同名類別」錯誤，不允許建立（同一種類內比對；支出類別與收入類別可各有同名）
- [ ] 儲存成功 → 出現「已新增類別」提示、視窗自動關閉、新類別出現在「使用中」清單最後
- [ ] 新增後「使用中」的數量 +1
- [ ] 按「取消」或關閉視窗 → 不建立任何類別

## 3. 編輯類別

- [ ] 使用中的類別可以點「編輯」→ 出現預填好的視窗
- [ ] **所有類別（含起始 14 筆，包含「手續費」）都可以編輯名稱與代碼**
- [ ] 已停用的類別**沒有編輯按鈕**；要修改需先到「已停用」區點「解除停用」
- [ ] 沒有做任何修改直接儲存 → 不會誤判為同名重複，可成功關閉
- [ ] 改成與其他類別相同的名稱 → 出現「已有同名類別」錯誤
- [ ] 名稱清空後儲存 → 出現「請填寫類別名稱」錯誤
- [ ] 儲存成功 → 出現「已更新類別」提示、清單當下反映新名稱

## 4. 停用類別

- [ ] 使用中類別可以點「停用」→ 出現確認視窗，說明：停用後不會出現在新增支出/請款下拉；該類別基本預算與當期/未來預算會被清除（過往期間保留）；舊紀錄仍會保留類別名稱
- [ ] 點「取消」→ 類別維持不變
- [ ] 點「確認停用」→ 出現「已停用」提示、該類別從「使用中」消失,出現在「已停用」
- [ ] 兩區的數量對應加減
- [ ] **除系統保留的「手續費」外，所有類別(含起始 13 筆)都可以被停用**；「手續費」沒有停用按鈕（見第 13 節）
- [ ] 停用後**不會**動到過去已建立的支出或請款紀錄
- [ ] 停用會連帶清除該類別的基本預算與當期/未來期間的預算金額(過往期間保留);詳細測試點見 QA_類別預算.md「類別停用連動」

## 5. 恢復已停用的類別

- [ ] 進入「已停用」區，該類別旁有「解除停用」按鈕
- [ ] 點「解除停用」→ 直接生效（不需再確認）、出現「已解除停用」提示
- [ ] 類別回到「使用中」區，可以再次被選用
- [ ] 停用時被清除的基本預算與當期/未來預算**不會自動恢復**；需到「預算」頁面重新設定

## 6. 搜尋

- [ ] 上方搜尋框輸入英數字類別名稱關鍵字 → 清單即時過濾（不需按 Enter）
- [ ] 輸入中文（使用注音、拼音、倉頡等中文輸入法）→ 選字過程中清單**不會**跳動；確認選字（按空白/Enter 或選詞）後才過濾
- [ ] 輸入會計科目代碼數字（例如 `6114`）→ 找到對應的類別（例如「交通費」「差旅費」）
- [ ] 大小寫、全形半形不影響搜尋結果
- [ ] 找不到任何符合的類別 → 顯示「沒有結果」的空狀態畫面
- [ ] 清空搜尋 → 恢復顯示全部
- [ ] 搜尋只作用在目前所在的分區（在「使用中」搜尋不會跨到「已停用」）

## 7. 切換「使用中」與「已停用」

- [ ] 點「已停用」→ 上方出現說明文字，提醒使用者此區的類別不會出現在新增下拉，但舊紀錄仍會顯示原名
- [ ] 兩區的類別數量隨新增/停用/恢復即時更新
- [ ] 任一區無資料 → 顯示對應的空狀態說明（例：「停用類別後會出現在這裡」）

## 8. 調整類別順序（拖曳）

> 情境：想把常用類別往上搬，讓新增支出的下拉與預算列表更順手。

- [ ] 使用中類別每列左側有拖曳把手；按住把手拖曳可調整順序
- [ ] 已停用區**沒有**拖曳把手
- [ ] 搜尋狀態下**沒有**拖曳把手（避免只在搜尋結果內排序造成誤解）
- [ ] 點了欄位標題排序後，拖曳把手暫時消失；取消欄位排序後把手恢復
- [ ] 拖曳到新位置放開 → 看到「已更新類別順序」提示
- [ ] 重新整理頁面 / 關閉瀏覽器再打開 → 順序維持
- [ ] 到「新增支出」/「新增請款」/「類別預算」看類別清單 → 都依此順序顯示
- [ ] 新增類別預設排在使用中清單的**最後**
- [ ] 拖曳使用中類別**不會影響**已停用類別的排序（之後解除停用時仍會接在使用中類別後面）

## 9. 依欄位暫時排序

> 情境：想按某一欄暫時排序看資料，不希望覆寫自訂順序。

- [ ] 使用中區可點「會計科目」欄標題排序：第一次遞增、第二次遞減、第三次回到自訂順序
- [ ] 使用中區可點「使用筆數」欄標題排序，循環同上
- [ ] 已停用區的欄位排序行為相同
- [ ] 「類別名稱」欄不開放排序（固定依自訂順序，避免與拖曳混淆）
- [ ] 排序中拖曳把手暫時消失；取消排序（點第三次或切分頁）後把手恢復
- [ ] 排序**不會儲存**：重新整理頁面後，排序取消、回到自訂順序

## 10. 資料保留

- [ ] 新增/編輯/停用/恢復/調整順序任一動作後，重新整理頁面 → 狀態仍在
- [ ] 關閉瀏覽器再重新打開 → 狀態仍在

## 11. 對其他功能的影響（跨模組）

**新增支出（後台）**
- [ ] 進入「新增支出」，類別下拉**只顯示使用中類別**，已停用的看不到
- [ ] 選擇某類別存檔後，若之後該類別被停用 → 已存在的支出仍顯示原類別名稱、不會變成空白或錯誤
- [ ] 若該類別被改名 → 已存在的支出**當下反映新名稱**

**新增請款（前台）**
- [ ] 員工在前台送出請款時，類別下拉**只顯示使用中類別**
- [ ] 過去已送出的請款紀錄，即使類別被停用或改名，仍顯示送出當下的類別名稱（改名情境會反映新名稱）

**代墊款轉支出（撥款流程）**
- [ ] 管理員審核通過並撥款、要一併建立支出時，帶入的類別欄位是原代墊款上選擇的類別

**Dashboard 預算總覽**
- [ ] Dashboard 上按類別分組的金額，即使類別被停用，只要歷史上有支出就仍顯示

**極端情境**
- [ ] 若某筆舊紀錄的類別因某種原因找不到（例如資料異常）→ 該列不會整個消失或跳錯誤，會用可辨識的方式顯示（例如原代碼字串），讓使用者知道「這裡有資料，只是類別對不上」

## 12. 刪除類別與垃圾桶

> 規格來源：PRD 第 18 條。支出類別與收入類別規則相同，各驗一次。

### 12.1 刪除（進垃圾桶）

- [ ] 使用中或已停用的類別點「刪除」→ 出現確認視窗，說明該類別的預算會被清除；確認後類別從列表消失，到「垃圾桶」可找到
- [ ] 垃圾桶中的類別顯示刪除時間與操作人
- [ ] 類別已被支出、收入、代墊款使用 → 仍可刪除進垃圾桶，既有紀錄仍顯示原類別名稱，不會變空白
- [ ] 類別正被**進行中的固定收支範本**使用 → 點「刪除」被擋，提示該類別正被固定收支使用，請先處理範本
- [ ] 類別只被**已到期（歷史）範本**使用 → 可刪除
- [ ] 刪除類別時留下稽核紀錄
- [ ] 垃圾桶中的類別不可編輯，不可停用或解除停用

### 12.2 名稱佔用

- [ ] 類別在垃圾桶內時，新增同類型（支出或收入）的同名類別 → 出現「已有同名類別」錯誤
- [ ] 把另一個類別改名成垃圾桶內類別的名稱 → 同樣被擋
- [ ] 支出類別與收入類別名稱各自獨立：垃圾桶內有支出類別「其他」，仍可新增收入類別「其他」
- [ ] 把垃圾桶內的類別永久刪除後，該名稱才可再使用

### 12.3 預算清除

- [ ] 有基本預算與當期、未來預算的類別刪除後 → 到類別預算頁，該類別不再出現，其基本預算與當期、未來的預算金額已清除
- [ ] 過往期間的預算金額保留（可在歷史期間的預算查詢到）
- [ ] 把類別從垃圾桶還原 → 先前被清除的基本預算與當期、未來預算**不會恢復**，需重新設定

### 12.4 還原

- [ ] 垃圾桶中的類別點「還原」→ 類別回到類別管理列表，名稱、會計科目、排序與刪除前一致
- [ ] 刪除前是使用中的類別 → 還原後在「使用中」
- [ ] 刪除前是停用的類別 → 還原後仍在「已停用」，不會自動變成使用中
- [ ] 還原後，類別可再次出現在新增與匯入的選項（原本停用的除外）
- [ ] 還原會留下稽核紀錄

### 12.5 垃圾桶內的類別不出現在選項

- [ ] 類別在垃圾桶時，新增支出（收入）的類別下拉看不到它
- [ ] 前台新增請款的類別下拉看不到它
- [ ] 新增、編輯固定收支範本的類別下拉看不到它
- [ ] Excel 匯入時，檔案中的類別名稱若等於垃圾桶內的類別 → 視為找不到，需由使用者在預覽畫面重新對應到使用中類別
- [ ] 類別預算頁面不列出垃圾桶內的類別
- [ ] 已有紀錄使用的垃圾桶類別 → 紀錄在列表與詳情仍顯示原類別名稱，不會整列消失

### 12.6 停用的限制（連動固定收支）

- [ ] 類別正被進行中的固定收支範本使用 → 點「停用」被擋，提示該類別正被固定收支使用
- [ ] 範本已到期（歷史）後，該類別可停用
- [ ] 範本被刪除進垃圾桶後，該類別可停用
- [ ] 類別被歷史範本使用且已停用 → 到固定收支把該歷史範本的結束月份往後延，被擋，提示先解除停用類別或改選其他類別
- [ ] 類別被垃圾桶內的範本使用且已停用（或在垃圾桶）→ 該範本不可還原，提示先解除停用（或還原）類別
- [ ] 延長結束月份時在同一次編輯換成使用中的類別 → 可成功
- [ ] 解除類別停用後，上述歷史範本可延長、垃圾桶範本可還原

### 12.7 永久刪除

- [ ] 垃圾桶中、**完全沒有被使用**的類別 → 點「永久刪除」出現確認視窗，確認後從垃圾桶消失，之後該名稱可重新使用
- [ ] 已被任何**支出、收入或代墊款**使用（包含這些紀錄在垃圾桶中）→ 不可永久刪除，提示因已有紀錄使用
- [ ] 已被**歷史範本或垃圾桶內範本**使用 → 不可永久刪除
- [ ] 曾經有**過往期間的預算**（即使現在已無任何支出）→ 不可永久刪除
- [ ] 把所有使用它的紀錄、範本都永久刪除後，過往預算若仍存在 → 仍不可永久刪除（過往預算不會隨紀錄消失）
- [ ] 永久刪除會留下稽核紀錄，保存類別完整內容

- [x] 管理員新增一般支出，類別選「手續費」 → 可以建立；列表來源顯示「一般支出」

- [x] 該筆可編輯（改金額後儲存成功）
- [x] 該筆可標記為已付款、改回待付款
- [x] 該筆可移至垃圾桶，並可從垃圾桶還原
- [x] 員工請款選「手續費」 → 核准後進支出列表，來源顯示「代墊款」

- [x] 移轉產生的那筆手續費支出仍唯讀：直接開啟編輯頁 → 被導回資金移轉並提示請到資金移轉修改；強行修改被擋下
- [x] 來源篩選選「移轉手續費」 → 只列移轉產生的那一筆，手動選「手續費」類別的一般支出與代墊款都不列入
