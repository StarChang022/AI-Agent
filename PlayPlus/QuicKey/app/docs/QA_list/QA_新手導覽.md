# QA Checklist — 新手導覽

> **驗證對象**：admin 首次登入後台自動觸發 11 步新手導覽（先介紹帳戶設定）、導覽結束後依公司資料引導建立第一個帳戶與第一筆收支、員工首次登入前台自動觸發 4 步新手導覽、可隨時關閉、可從使用者選單重跑；桌機與手機皆需完整支援。
> **規格來源**：PRD 第 20、22 條（2026-11-03 更新版，commit 089c074）。
> **前置**：請工程師先清空瀏覽器 localStorage（key `quickey.onboarding.v1`），或改用另一個未跑過導覽的測試帳號。
> **測試帳號**：[admin@example.com](mailto:admin@example.com)（管理員）、[ming@example.com](mailto:ming@example.com)（員工）；密碼皆為 `password123`。
> **注意**：本清單只驗證「功能流程與規則」；顏色、字級、按鈕樣式等 UI 細節由設計規範統一把關,不在此列。

## 1. 首次觸發

- [x] 以未跑過導覽的管理員登入 → 進入儀表板後,畫面自動彈出導覽提示卡,標題為「歡迎使用 Quickey」;開場後會自動跳到「帳戶設定」頁做第 1 步定位
- [x] 以未跑過導覽的員工登入 → 進入前台首頁後,畫面自動彈出導覽提示卡,標題為「歡迎使用 Quickey」;開場後會自動跳到「新增代墊款」頁做第 1 步定位
- [x] 已完成導覽的使用者再度登入 → 進入首頁不會彈出導覽
- [x] 已完成的使用者重整瀏覽器 → 仍然不會再彈出導覽
- [x] 員工登入前台看到的是員工版導覽（4 步），不會出現管理員版本的內容
- [x] 管理員登入後台看到的是管理員版導覽（11 步），不會出現員工版本的內容



## 2. 管理員導覽（11 步）流轉

> 導覽只做說明，過程中不需操作；先介紹帳戶設定，再介紹支出、收入等功能。

- [ ] 步驟 1（歡迎使用 Quickey／帳戶設定）：頁面自動切到「帳戶設定」→ 打亮帳戶設定頁面；sidebar「帳戶設定」打亮；提示卡說明帳戶是記錄收支的基礎、需先建立並填寫實際金額；描述提到接下來 11 步
- [ ] 步驟 2（支出管理）：按「下一步」→ 頁面切到「支出管理」→ 打亮「新增支出」按鈕；sidebar「支出管理」打亮
- [ ] 步驟 3（填寫支出內容）：按「下一步」→ 頁面切到「新增支出」→ 打亮憑證上傳與辨識區塊
- [ ] 步驟 4（查看支出列表）：按「下一步」→ 頁面切回「支出管理」→ 打亮支出表格
- [ ] 步驟 5（查看請款記錄）：按「下一步」→ 頁面切到「請款記錄」→ 打亮請款清單
- [ ] 步驟 6（簽核代墊款）：按「下一步」→ 頁面切到「簽核」→ 打亮待簽核清單；手機／平板下清單會自動水平捲到最右,讓「通過／駁回」按鈕可見
- [ ] 步驟 7（設定費用類別）：按「下一步」→ 頁面切到「類別管理」→ 打亮「新增類別」按鈕
- [ ] 步驟 8（建立第一筆預算）：按「下一步」→ 頁面切到「預算管理」→ 打亮整個預算頁面,頁面標題未被切掉
- [ ] 步驟 9（邀請員工）：按「下一步」→ 頁面切到「人員管理」→ 打亮「邀請員工」按鈕
- [ ] 步驟 10（儀表板）：按「下一步」→ 頁面切到「儀表板」→ 打亮整個儀表板區塊（含「本月支出／未結清代墊款」KPI 與圖表）,頁面標題未被切掉
- [ ] 步驟 11（新手導覽）：按「下一步」→ 停在儀表板頁 → 右上角使用者選單自動展開 → 打亮「新手導覽」選項；按鈕文字變成「完成」
- [ ] 導覽過程中沒有任何步驟要求使用者操作（不必先建帳戶才能繼續下一步）；公司沒有帳戶時也能完整走完 11 步
- [ ] 點「完成」→ 使用者選單自動收起、導覽關閉、sidebar 打亮效果同步消失；接著依公司資料進入「導覽結束後的引導」（見第 4 節）
- [ ] 每一步的提示卡右下角顯示「第 X 步 / 共 11 步」進度文字
- [ ] 手機（375px）執行任一步時,sidebar 藏在 drawer 內看不到打亮效果,頁面內 target 仍照常打亮
- [ ] 任一步按「上一步」→ 回到前一步的頁面 + target,不會停在原頁只顯示中央提示卡；從步驟 11 按「上一步」→ 使用者選單會自動收起,再顯示步驟 10 的儀表板打亮



## 3. 員工導覽（4 步）流轉

- [ ] 步驟 1（歡迎使用 Quickey）：頁面自動切到「新增代墊款」→ 打亮憑證上傳區塊(拍照／選擇檔案／開始辨識按鈕整組)；頁面標題「新增代墊款」未被切掉；提示卡描述提到接下來 4 步
- [ ] 步驟 2（追蹤代墊款進度）：按「下一步」→ 頁面切到「歷史記錄」→ 打亮清單(若無資料則提示卡顯示在畫面中央)
- [ ] 步驟 3（首頁一覽）：按「下一步」→ 頁面切到首頁 → 打亮整個首頁(問候語 + 待收款／已發放 KPI + 最近請款紀錄)
- [ ] 步驟 4（新手導覽）：按「下一步」→ 停在首頁 → 右上角使用者選單自動展開 → 打亮「新手導覽」選項；按鈕文字變成「完成」
- [ ] 點「完成」→ 使用者選單自動收起、導覽關閉,使用者停留在「首頁」
- [ ] 每一步的提示卡右下角顯示「第 X 步 / 共 4 步」進度文字
- [ ] 任一步按「上一步」→ 回到前一步的頁面 + target；從步驟 4 按「上一步」→ 使用者選單會自動收起,再顯示步驟 3 的首頁打亮



## 4. 管理員導覽結束後的引導

> 帳戶與收支都不含垃圾桶內的紀錄；手動新增、匯入、系統產生的紀錄（固定收支、資金移轉手續費、代墊款核准）都算收支。

### 4.1 沒有任何帳戶

- [ ] 新註冊公司（沒有帳戶）走完 11 步按「完成」→ 跳出視窗，詢問是否現在建立第一個帳戶，選項為「建立帳戶」「之後再說」
- [ ] 同樣情況按「結束導覽」→ 一樣跳出詢問是否建立第一個帳戶的視窗
- [ ] 選「建立帳戶」→ 前往帳戶設定，並自動打開新增帳戶視窗
- [ ] 自動打開的新增帳戶視窗旁邊（窄螢幕在視窗下方）有一張說明卡 → 說明帳戶名稱、類型、起始金額、起始月份怎麼填，並說明起始金額要填「起始月份月初的實際餘額」
- [ ] 說明卡顯示期間可直接在視窗中填寫與選擇，不被擋住；說明卡不在視窗裡面，也不遮住要填的欄位
- [ ] 沒按「結束引導」，填完直接儲存 → 帳戶建立成功，出現在帳戶設定列表，接著跳出視窗詢問是否新增第一筆收支（接續 4.2）
- [ ] 按說明卡的「結束引導」→ 只收起說明卡，新增帳戶視窗不關，已填內容保留，可繼續填寫
- [ ] 按「結束引導」收起說明卡後再儲存 → 帳戶建立成功，**仍會**接著跳出詢問是否新增第一筆收支的視窗
- [ ] 按「結束引導」後把視窗關掉沒儲存 → 引導結束，不會詢問收支，之後不再自動出現
- [ ] 在帳戶設定頁自己按「新增帳戶」打開的視窗 → 沒有說明卡；儲存後也不會跳出新增第一筆收支的詢問
- [ ] 引導中儲存時漏填或名稱重複 → 照原本規則提示，視窗不關，說明卡仍在，補正後可再儲存
- [ ] 選「之後再說」→ 視窗關閉、引導結束，停留在當前頁，之後不再自動出現
- [ ] 選「建立帳戶」後，新增帳戶視窗沒有儲存就關掉（按取消、關閉或 Esc）→ 也算結束引導，不會再詢問收支，之後不再自動出現
- [ ] 公司沒有帳戶時進入帳戶設定頁（不是從引導進入）→ 顯示一般的空白畫面，沒有「建立第一個帳戶」的提示，也不會自動打開新增帳戶視窗
- [ ] 引導中建立的帳戶，之後可在帳戶設定正常編輯（修改起始金額、起始月份需二次確認）

### 4.2 已有帳戶、但沒有任何收支

- [ ] 公司已有帳戶但沒有任何支出或收入，走完導覽 → 不詢問建帳戶，直接跳出視窗詢問是否新增第一筆收支，選項為「新增支出」「新增收入」「之後再說」
- [ ] 選「新增支出」→ 進入新增支出頁並開始逐步引導；選「新增收入」→ 進入新增收入頁並開始逐步引導
- [ ] 選「之後再說」→ 視窗關閉、引導結束，之後不再自動出現
- [ ] 公司只有一筆系統自動產生的紀錄（例如固定收支產生的、代墊款核准的支出）→ 視為已有收支，不再詢問新增第一筆
- [ ] 公司只有垃圾桶內的收支 → 視為沒有收支，仍詢問是否新增第一筆
- [ ] 公司唯一的帳戶在垃圾桶內 → 視為沒有帳戶，走完導覽後詢問是否建立第一個帳戶
- [ ] 引導中建立的收支，之後可在支出列表／收入列表修改，與一般資料相同

### 4.2.1 新增第一筆支出的逐步引導（共 6 步）

- [ ] 步驟 1：提示上傳憑證並辨識，或跳過改為手動輸入 → 上傳辨識後欄位自動帶入；選擇跳過則直接手動填寫
- [ ] 步驟 2：提示確認文件類型、日期、賣方與發票號碼
- [ ] 步驟 3：提示確認金額；品項為選填，不填也能繼續
- [ ] 步驟 4：提示選擇類別與帳戶
- [ ] 步驟 5：提示選擇付款狀態與日期
- [ ] 步驟 6：提示儲存
- [ ] 每一步都有「上一步」「下一步」「結束引導」三個按鈕（步驟 1 沒有上一步可退則不影響流程）
- [ ] 引導期間可以直接操作表單（輸入、選擇、上傳），不會被遮罩擋住
- [ ] 按「上一步」→ 回到前一步，已填的內容保留
- [ ] 在尚未填寫必填欄位時按「下一步」→ 不檢查、不出現缺漏提示，照常進到下一步
- [ ] 走到儲存這一步，必填漏填就按儲存 → 出現原本表單的缺漏提示，引導仍停在儲存這一步，不會結束
- [ ] 補齊欄位後再按儲存 → 儲存成功，出現完成提示，引導結束
- [ ] 儲存成功後 → 這筆支出出現在支出列表；之後不再自動出現引導
- [ ] 儲存失敗（例如網路中斷）→ 引導仍停在儲存這一步，可重試
- [ ] 在引導中途按「結束引導」→ 引導立即結束，表單內容保留，可繼續自行填寫與儲存；之後不再自動出現
- [ ] 引導期間離開新增頁（例如點側邊欄其他頁、按瀏覽器上一頁）→ 視同結束引導，之後不再自動出現

### 4.2.2 新增第一筆收入的逐步引導（共 6 步）

- [ ] 步驟 1：提示上傳憑證並辨識，或跳過改為手動輸入
- [ ] 步驟 2：提示確認文件類型、日期、客戶與發票號碼（對象是「客戶」，不是賣方）
- [ ] 步驟 3：提示確認金額；品項為選填
- [ ] 步驟 4：提示選擇類別與帳戶；類別只列收入類別
- [ ] 步驟 5：提示選擇收款狀態與日期（用詞是「收款」，不是「付款」）
- [ ] 步驟 6：提示儲存
- [ ] 每一步都有「上一步」「下一步」「結束引導」；引導期間可直接操作表單
- [ ] 按「下一步」不檢查必填；儲存時漏填會提示且引導停在儲存這一步
- [ ] 儲存成功 → 出現完成提示，引導結束；這筆收入出現在收入列表
- [ ] 按「結束引導」或離開新增頁 → 引導結束，之後不再自動出現

### 4.3 帳戶與收支都已有

- [ ] 公司已有帳戶與收支，走完導覽 → 停在儀表板，不再出現任何引導

### 4.4 略過

- [ ] 在「是否建立第一個帳戶」的視窗選「之後再說」→ 視窗消失，之後重新整理或換頁都不會再自動出現
- [ ] 在「是否新增第一筆收支」的視窗選「之後再說」→ 視窗消失，之後不再自動出現
- [ ] 逐步引導途中按「結束引導」，或新增帳戶視窗沒儲存就關掉 → 同樣不再自動出現（見 4.2.1、4.2.2）
- [ ] 略過引導後 → 其他功能正常使用，但沒有帳戶時新增收支、固定收支、Excel 匯入、批次匯入憑證仍不能用，並提示先建立帳戶
- [ ] 略過引導後，重新登入 → 不會再自動彈出引導
- [ ] 引導進行到一半（例如已建立帳戶、尚未新增收支）離開頁面 → 之後不會一直重複彈出
- [ ] 引導途中關掉瀏覽器分頁再重新登入 → 不會從頭再自動引導

### 4.5 從選單重新開始

- [ ] 略過引導後，從右上角選單點「新手導覽」→ 重新走完導覽，結束後依公司當下資料再次引導（沒有帳戶就引導建帳戶；有帳戶沒收支就引導新增第一筆）
- [ ] 略過後重新開始導覽，結束後進入新增第一筆收支的引導，走完到儲存成功 → 引導結束，之後不再自動出現
- [ ] 公司已建立帳戶與收支後重新開始導覽 → 走完後不再引導
- [ ] 重新開始導覽時按「結束導覽」→ 同樣進入依資料的引導

### 4.6 員工

- [ ] 員工走完 4 步導覽 → 沒有任何建立帳戶或新增收支的引導，停留在首頁



## 5. 隨時關閉

- [ ] 任一步右上角有「結束導覽」文字按鈕(不是 X icon)
- [ ] 在第 3 步按「結束導覽」→ 導覽立刻關閉；管理員會依公司資料進入導覽結束後的引導（見第 4 節）、員工停留於當前頁；若當時使用者選單為開啟狀態(第 11 / 4 步),選單會一併收起
- [ ] 關閉後重整頁面 → 不會再自動彈出導覽
- [ ] 按鍵盤 Esc → 效果等同按「結束導覽」(關閉並記為完成,選單也會收起)
- [ ] 點提示卡以外的畫面遮罩區 → 導覽**不會**被關閉,仍停留於當前步驟



## 6. 重跑導覽

- [ ] 管理員後台右上角頭像展開的選單,由上至下順序為：新手導覽、修改密碼、登出
- [ ] 員工前台右上角頭像展開的選單,順序同上
- [ ] 管理員選單點「新手導覽」→ 導頁到儀表板 → 開場後自動跳到「帳戶設定」開始第 1 步
- [ ] 員工選單點「新手導覽」→ 導頁到首頁 → 開場後自動跳到「新增代墊款」開始第 1 步
- [ ] 管理員在「人員管理」頁點「新手導覽」→ 會先跳回儀表板才啟動,不是原地啟動
- [ ] 管理員已在儀表板時點「新手導覽」→ 不會因為 remount 疊出兩層遮罩或兩張提示卡
- [ ] 員工已在首頁時點「新手導覽」→ 同上,不會疊層



## 7. Per-user 隔離

- [ ] 管理員 A 完成導覽後登出 → 換 B 帳號登入 → B 仍會被觸發導覽
- [x] 員工 X 完成導覽後登出 → 換另一位員工 Y 登入 → Y 仍會被觸發導覽
- [x] 管理員完成後台導覽 → 之後以員工帳號登入前台 → 員工仍會被觸發前台導覽(兩種角色的完成狀態互不干擾)



## 8. 損毀資料容錯

- [x] 用開發者工具把 localStorage `quickey.onboarding.v1` 改成非法內容(例如 `not-json`)→ 重新載入不會白畫面,導覽會被視為未完成
- [x] 以隱私模式(不允許 localStorage)登入 → 導覽仍會彈出、按完可正常關閉、但下次瀏覽器重開又會彈(此為預期行為)



## 9. 桌機版驗收（1440px 或更寬）

- [ ] 執行管理員 11 步 → 每步 target 被完整打亮,提示卡不重疊主內容
- [ ] 執行員工 4 步 → 每步 target 被完整打亮,提示卡不重疊主內容
- [ ] 提示卡側邊自動選擇合適方向(有時在上、有時在下),不會固定死於單一方向
- [ ] 尾步(第 11 / 4 步)使用者選單展開時,選單本身處於灰色遮罩下,只有「新手導覽」項目被挖亮

> 使用 Chrome DevTools 切裝置模擬 → 選 iPhone SE (375px) 或類似機型；若手邊有 iOS 裝置,另以真實 Safari 走一次。
