# QA Checklist — 資料匯出模組

> **驗證對象**：管理員在支出、收入、請款記錄三個列表匯出紀錄成 CSV（有圖檔時另附圖檔 ZIP），並透過 Email 連結下載；員工看不到也用不到。規格依據：產品規格文件第 24 條。
> **前置**：
> - 一家公司有管理員（王管理）、員工（陳小明）；另備**另一家公司**的管理員帳號用於權限驗證。
> - 支出、收入、請款各備：有圖檔與沒有圖檔的紀錄、超過一頁的筆數、不同分頁標籤與類別的紀錄；支出與收入另備已移入垃圾桶的紀錄。
> - 請款備：簽核中、駁回、已核銷、已發放、已作廢各至少一筆，其中至少一筆已核准並產生支出（共用同一張圖檔）。
> - 管理員信箱可收信（測試站請確認寄信可用）。
> **不在本清單範圍**：用量頁面的匯出入口、訂閱到期後停用。
> **注意**：只驗功能流程與規則；顏色、字級、按鈕樣式等 UI 細節不在此列。

---

## 1. 入口與權限

- [ ] 管理員進支出、收入、請款記錄列表 → 頁首都有「匯出」按鈕，展開只有「已選項目（N 筆）」與「全部支出／全部收入／全部請款」兩個選項（三頁各驗一次）
- [ ] 管理員打開支出或收入的明細、請款詳情（請款記錄頁與審核頁皆同）→ 都有「匯出」（單筆）
- [ ] 支出、收入列表每列右側的「⋯」選單有「匯出」
- [ ] 員工登入前台 → 任何頁面都沒有匯出功能
- [ ] 垃圾桶內的紀錄明細（唯讀）→ 不能匯出，需先還原

## 2. 單筆匯出

- [ ] 在明細按「匯出」或在列表「⋯」選單按「匯出」→ 先跳確認視窗，寫「匯出選取的 1 筆支出／收入／請款」，不列篩選條件（支出、收入、請款各驗一次）

## 3. 勾選匯出

- [ ] 支出、收入、請款記錄列表每一列都可以勾選（不限狀態），表頭勾選框為「本頁全選」（三頁各驗一次）
- [ ] 勾選後出現選取列 → 只顯示已選幾筆，不顯示合計金額（三頁各驗一次）
- [ ] 按選取列的「匯出」，或頁首「匯出」→「已選項目（N 筆）」→ 先跳確認視窗，寫「匯出選取的 N 筆…」，N 與勾選數相同；按視窗內「匯出」才匯出，且只匯出勾選的那幾筆（三頁各驗一次）
- [ ] 沒有勾選任何一筆 → 頁首「匯出」的「已選項目」不可選
- [ ] 勾選後換頁、改每頁筆數、切換分頁標籤、變更篩選或輸入關鍵字 → 選取清空
- [ ] 支出「待付款」的既有勾選動作（調整應付日期、標記已付款）照常可用，與匯出互不影響

## 4. 「全部」匯出（依目前分頁標籤與篩選）

- [ ] 頁首「匯出」→「全部…」→ 不需選日期、沒有勾選也可以按；沒有任何篩選就是該列表全部紀錄
- [ ] 在某個分頁標籤（如支出「待付款」、請款「已核銷」）或設定類別、來源、狀態、發生日期、關鍵字、「未填發票號碼」等篩選後匯出 → 匯出的就是列表上篩出來的那些，不多不少（三頁各驗一次）
- [ ] 符合條件的紀錄超過一頁 → 匯出包含所有頁，不是只有目前這一頁
- [ ] 有勾選的情況下按「全部」→ 仍匯出目前篩選的全部，不受勾選影響
- [ ] 目前篩選沒有任何紀錄 → 不能匯出

## 5. 確認視窗

- [ ] 選「全部」→ 先跳確認視窗，寫「匯出全部支出／收入／請款，共 N 筆」，N 與列表顯示的總數一致（三頁各驗一次）
- [ ] 選「全部」且列表有設定篩選 → 視窗下方小字列出這次會套用的篩選條件，只列有設定的項目，內容與實際匯出的紀錄一致
- [ ] 選「全部」且列表沒有任何篩選 → 視窗下方說明目前沒有篩選，會匯出這個列表的全部紀錄
- [ ] 選「已選項目」→ 視窗不顯示篩選條件說明
- [ ] 確認視窗按「取消」（勾選、全部、單筆都適用）→ 沒有匯出：沒有下載、沒有寄信提示、稽核日誌不新增，勾選與篩選維持原樣

## 6. 範圍只限當前列表

- [ ] 在支出、收入、請款記錄頁匯出（勾選、全部、單筆）→ CSV 與 ZIP 只有該列表的紀錄，不會混入其他類型；請款核准後產生的支出不會出現在請款頁的匯出裡（三頁各驗一次）
- [ ] 每次匯出只有一份 CSV

## 7. 不匯出的紀錄

- [ ] 垃圾桶內的支出、收入 → 任何方式匯出都不含
- [ ] 請款草稿（列表上看不到的）→ 匯出也不會有；簽核中、駁回、已核銷、已發放、已作廢在列表上看得到的，匯出都有

## 8. CSV 內容

- [ ] 用 Excel 直接開啟 CSV → 中文不亂碼；一筆紀錄一列，多個品項合併在同一欄，不會變成多列
- [ ] 支出 CSV 欄位依序為：發生日期、發票日期、應付日期、實付日期、文件類型、賣方、統一編號、發票號碼、類別、帳戶、稅別、未稅金額、稅額、含稅金額、付款狀態、來源、說明、品項、圖檔；收入 CSV 欄位相同，但為應收日期、實收日期、客戶、收款狀態，且沒有「來源」
- [ ] 請款 CSV 有申請人、說明、類別、金額、發生日期、發票日期、狀態、建立時間、品項與圖檔欄，內容與畫面一致；有填品項的請款，品項合併在同一欄、不會變成多列；沒填品項的該欄空白
- [ ] 金額與畫面上的明細一致；類別、帳戶顯示名稱而不是代碼；支出的「來源」能區分一般支出、代墊款、固定、移轉手續費

## 9. 圖檔 ZIP

- [ ] 圖檔檔名格式為「發生日期_賣方（或客戶、申請人）_原始檔名」，檔名含空白、中文等特殊字元也能正常解壓，檔案不遺失
- [ ] CSV 的「圖檔」欄列出的檔名在 ZIP 內都找得到；一筆多張圖以「；」分隔、ZIP 內每張都在；沒有圖檔的紀錄該欄空白
- [ ] ZIP 內的圖檔打開後是原始圖檔（不是縮圖、不是壓縮過的版本）
- [ ] 請款與其核准後產生的支出共用圖檔 → 從支出頁匯出該支出、從請款頁匯出該請款，兩邊都帶得到圖檔

## 10. 背景產生與通知

- [ ] 匯出的紀錄（勾選、全部、單筆都適用）都沒有圖檔 → 當下直接下載 CSV，沒有寄信提示，也不寄信；只要有一筆有圖檔 → 整批背景產生（不會拆開），畫面提示「匯出完成後會寄信通知」，可繼續使用系統
- [ ] 完成後發起人信箱收到信，信中有下載連結與失效時間；通知中心多一則「資料匯出完成」，點擊前往該次匯出的下載頁
- [ ] 通知與信只給發起匯出的管理員，其他人看不到

## 11. 下載頁與失效

- [ ] 點信中連結，已登入的本公司管理員 → 看到下載頁，顯示匯出範圍、筆數、產生時間、失效時間；有「下載 CSV」，有圖檔時另有「下載 ZIP」
- [ ] 7 天內可重複下載，每次都能取得完整檔案
- [ ] 未登入點連結 → 先導向登入頁；登入後自動回到該下載頁
- [ ] 員工帳號點連結 → 無法下載
- [ ] 其他公司的管理員點連結，或竄改連結中的編號 → 無法下載，看不到任何匯出資訊
- [ ] 超過 7 天 → 下載頁顯示「下載連結已失效，請重新匯出」，沒有下載按鈕

## 12. 稽核日誌

- [ ] 每次發起匯出，稽核日誌新增一筆（不是每筆紀錄各一筆），對象為「資料匯出」，動作為「匯出」，操作人與時間正確
- [ ] 日誌顯示範圍與筆數：單筆（筆數 1）、勾選（例如勾 5 筆顯示 5）、全部，並區分支出、收入、請款；內容含使用的篩選條件與是否含圖檔
- [ ] 沒有圖檔、當下下載的匯出，同樣寫一筆稽核日誌

## 13. 其他影響確認

- [ ] 支出、收入、請款記錄列表既有的篩選、分頁、排序、批次操作，在加入勾選與匯出後仍正常
