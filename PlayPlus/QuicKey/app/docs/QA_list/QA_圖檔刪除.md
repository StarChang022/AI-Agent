# QA Checklist — 圖檔刪除（憑證圖檔）

> **驗證對象**：管理員在支出、收入、資金移轉的編輯頁刪除憑證圖檔，以及圖檔跟著紀錄進垃圾桶、還原、永久刪除、取消新增時的行為；員工提交代墊款與查看圖檔不受影響。
> **前置**：以管理員身分登入後台；另備員工帳號（陳小明、張大同）。每筆紀錄最多 5 張，單檔 5 MB，格式 JPG／PNG／PDF。
> **規格來源**：`docs/資料模型.md` §2.4、§4.3「刪除圖檔」列、PRD 規則 18、`docs/後續擴充規格.md` §9。
> **標註 🔧**：「計入儲存空間」「釋放空間」目前沒有畫面可看，由工程師以後端自動化測試確認，**不是**使用者操作步驟，QA 人工驗證時略過。
> **注意**：本清單只驗證「功能流程與規則」，畫面樣式不在此列。

---

## 1. 編輯時刪除已儲存的圖檔（支出／收入／資金移轉）

> 以下三種紀錄規則相同，請各做一遍。

- [ ] 打開一筆已有圖檔的紀錄進入編輯 → 每張已儲存的圖檔都能看到刪除的入口
- [ ] 點刪除 → 跳出二次確認，說明會永久刪除；按「取消」→ 圖檔還在，什麼都沒變
- [ ] 確認刪除 → 該張圖檔立即消失，**不必按儲存**；關掉編輯頁再打開，圖檔確實已不在
- [ ] 刪除後直接按「取消」離開編輯（不儲存）→ 重新打開，圖檔**不會恢復**
- [ ] 刪除其中一張 → 其他圖檔不受影響，仍可正常打開查看
- [ ] 把一筆紀錄的圖檔全部刪完 → 紀錄仍正常存在，只是沒有憑證；之後可再上傳新圖檔
- [ ] 刪除圖檔後，同時改了金額等其他欄位但按「取消」→ 其他欄位維持原樣，只有圖檔已被刪除
- [ ] 到「稽核日誌」查看該紀錄 → 多一筆「修改」，變更前後可看到圖檔檔名的差異（刪除前有、刪除後沒有）
- [ ] 稽核日誌只看得到檔名，**看不到圖檔本身**
- [ ] 刪除 3 張圖檔 → 稽核日誌每次刪除都有記錄，檔名對得上

### 1.1 特殊情況

- [ ] 手續費支出（由資金移轉自動產生）不能編輯，看不到刪圖入口；要刪憑證請到來源的資金移轉編輯頁
- [ ] 垃圾桶內的紀錄 → 無法進入編輯，因此看不到任何刪圖入口

## 2. 新增時的暫存圖檔（未儲存）

- [ ] 新增支出時選擇圖檔 → 圖檔立即顯示在表單中
- [ ] 移除這張尚未儲存的圖檔 → 直接移除，**不出現二次確認**
- [ ] 新增時上傳圖檔後按「取消」或關閉視窗 → 不建立紀錄，圖檔也不會留下（重新開啟新增表單看不到先前的圖檔）
- [ ] 上傳圖檔後直接關閉瀏覽器分頁 → 重新登入，這些圖檔不會出現在任何紀錄裡
- [ ] 新增並儲存 → 圖檔掛在新紀錄上，打開可正常查看
- [ ] 編輯既有紀錄時**新增**一張圖檔，未儲存就按「取消」→ 該張新圖檔不會留在紀錄上；原本已儲存的圖檔不受影響
- [ ] 編輯時新增圖檔後，移除該張（尚未儲存的）→ 不需確認，直接移除
- [ ] 同一次編輯中，混合「刪除已儲存的圖檔（需確認）」與「移除剛選的圖檔（不需確認）」→ 兩種規則各自正確
- [ ] 以上在收入、資金移轉新增頁各做一遍，結果相同
- [ ] 一筆紀錄已有 5 張時，再選第 6 張 → 被擋下並提示張數上限；刪除其中一張後即可再上傳
- [ ] 上傳超過 5 MB 或非 JPG／PNG／PDF 的檔案 → 被擋下並提示原因

## 3. 批次匯入憑證與 OCR 帶出的圖檔

- [ ] 用「批次匯入憑證」上傳多張憑證 → 每張辨識結果對應的圖檔都顯示在對應的待確認項目
- [ ] 在待確認項目中移除某張圖檔 → 不需二次確認，直接移除
- [ ] 全部確認匯入後 → 每筆新紀錄都帶著對應圖檔，打開可正常查看
- [ ] 批次匯入中途取消（未確認匯入的項目）→ 這些圖檔不會出現在任何紀錄上
- [ ] 新增支出時用拍照／上傳辨識（OCR）→ 辨識後圖檔留在表單，儲存後掛在紀錄上
- [ ] OCR 辨識後取消新增 → 不建立紀錄，圖檔不會留下
- [ ] 編輯既有紀錄時，已儲存的憑證預設**沒有勾**「要辨識」；新上傳的憑證預設有勾
- [ ] 編輯時勾選已儲存的憑證後開始辨識 → 可正常辨識，並照常扣辨識次數
- [ ] 辨識完成後 → 該憑證仍在紀錄上，沒有被移除，也沒有出現重複的同一張圖
- [ ] 辨識後不儲存就離開 → 紀錄上的憑證數量與辨識前相同
- [ ] 批次匯入或 OCR 建立的紀錄，之後在編輯頁刪圖 → 行為與第 1 節一致，需二次確認且寫入稽核日誌

## 4. 紀錄進垃圾桶與還原

- [ ] 把一筆有圖檔的支出移到垃圾桶 → 到垃圾桶打開該筆，圖檔仍可查看
- [ ] 從垃圾桶還原該筆支出 → 回到列表，打開後圖檔數量與內容與刪除前一致
- [ ] 先在編輯頁刪掉其中一張再移到垃圾桶、還原 → 還原後只有剩下的圖檔，被刪的不會回來
- [ ] 收入、資金移轉各做一遍進垃圾桶與還原 → 結果相同
- [ ] 資金移轉移到垃圾桶再還原 → 移轉的憑證回來，手續費支出也一併還原
- [ ] 🔧 紀錄在垃圾桶期間，圖檔仍計入公司儲存空間（工程師以自動化測試確認）
- [ ] 🔧 還原後儲存空間用量不變（工程師以自動化測試確認）

## 5. 永久刪除

- [ ] 在垃圾桶永久刪除一筆有圖檔的紀錄 → 紀錄與圖檔都不能再被看到
- [ ] 永久刪除後，到稽核日誌查看該筆 → 仍有刪除記錄，完整內容只列檔名、類型、大小，沒有圖檔本身
- [ ] 永久刪除一筆有憑證的資金移轉 → 移轉的圖檔不能再查看，連帶的手續費支出也一併永久刪除
- [ ] 🔧 永久刪除後實體檔案確實被刪除、儲存空間用量釋放（工程師以自動化測試確認）

## 6. 代墊款（只改存法，功能不變）

> 本節確認「圖檔改存法」後，代墊款相關流程沒有壞掉，並且與支出共用圖檔時互不影響。

### 6.1 員工提交與查看

- [ ] 員工提交代墊款時上傳憑證 → 送出成功，在「我的請款」打開可看到憑證
- [ ] 員工儲存草稿後再回來編輯 → 先前上傳的憑證仍在
- [ ] 員工提交時上傳憑證後按取消或關閉 → 不建立請款，憑證不會留下
- [ ] 員工在草稿或被駁回的請款中移除**已儲存**的憑證 → 不需二次確認（與支出、收入、移轉編輯頁不同），且要按「儲存」或「送出」才會生效
- [ ] 移除已儲存的憑證後**不儲存就離開** → 再進來原圖還在
- [ ] 移除憑證後按儲存或送出 → 再打開，該憑證已不在
- [ ] 員工提交後被駁回、重新編輯重送 → 未移除的憑證仍在，可再增刪
- [ ] 員工只看得到**自己**請款的憑證；無法打開別人（例如另一位員工）請款的憑證

### 6.2 管理員查看與核准

- [ ] 管理員在審核頁打開任一員工的請款 → 憑證可正常查看
- [ ] 管理員核准請款 → 產生的支出上看得到同一份憑證
- [ ] 核准後，管理員在請款記錄打開該筆 → 憑證仍可查看

### 6.3 從支出刪圖或刪除支出，代墊款原圖仍保留

- [ ] 在核准產生的支出編輯頁刪除某張憑證（二次確認）→ 該支出上不再有這張憑證
- [ ] 同一時間，員工與管理員從請款記錄打開該代墊款 → **原圖仍然看得到**
- [ ] 把核准產生的支出移到垃圾桶、再永久刪除 → 到請款記錄打開來源代墊款，原圖仍可查看
- [ ] 若永久刪除支出時一併作廢代墊款 → 作廢後的代墊款仍可看到原圖（保留簽核證據）
- [ ] 代墊款本身不能被刪除，只能作廢；作廢後圖檔仍可查看
- [ ] 🔧 代墊款與其支出共用同一份檔案，只計一次儲存空間；兩邊都不再使用時才刪除實體檔案（工程師以自動化測試確認）

## 7. 權限與資料隔離

- [ ] 管理員可查看公司內所有紀錄的圖檔
- [ ] 員工在前台只看得到自己代墊款的圖檔，打不開別人的請款
- [ ] 員工無法進入後台，因此看不到、也刪不了支出／收入／資金移轉的圖檔
- [ ] 另一家公司的管理員查不到、也打不開本公司的紀錄，所以拿不到圖檔
- [ ] 複製圖檔網址，過 2 小時後再開 → 打不開
- [ ] 圖檔被刪除後，用原本的網址打開 → 打不開
- [ ] 刪除圖檔的操作只能由管理員進行；其他公司的管理員無法刪除本公司紀錄的圖檔

## 8. 既有舊紀錄（上線轉檔後）

> 上線前已存在的紀錄，其圖檔由系統一次性轉成新的存法。轉檔前請工程師備份資料庫，上線後逐項抽驗。

- [ ] 上線前就有圖檔的支出、收入、資金移轉 → 上線後打開，圖檔數量、檔名、內容與上線前相同，可正常查看
- [ ] 上線前就有憑證的代墊款（草稿、簽核中、駁回、已核准、已發放、已作廢各抽一筆）→ 上線後憑證都正常顯示
- [ ] 舊紀錄上的圖檔可以像新圖檔一樣被刪除（二次確認、寫稽核日誌）
- [ ] 舊紀錄移到垃圾桶、還原、永久刪除 → 行為與第 4、5 節一致
- [ ] 上線前已在垃圾桶的舊紀錄 → 上線後垃圾桶內仍看得到圖檔，還原後正常
- [ ] 上線前已核准的代墊款與其支出（原本各自存一份）→ 上線後兩邊都看得到圖檔；在支出刪圖後代墊款仍可查看
- [ ] 沒有任何圖檔的舊紀錄 → 轉檔後仍正常，不會多出空白圖檔
- [ ] 轉檔本身不會在稽核日誌多出任何記錄
- [ ] 🔧 轉檔筆數與轉檔前一致、全部可讀取後才移除舊資料（工程師確認轉檔報告）
