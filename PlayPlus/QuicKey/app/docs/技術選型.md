### 6. OCR（發票辨識）

| 建議 | 優點 | 缺點 | 成本 |
|---|---|---|---|
| **Vertex AI — Gemini 3.1 Flash-Lite（`gemini-3.1-flash-lite`）**（2026-10-29 採用） | 直接讀圖片／PDF 並依指定格式回傳欄位 JSON，手寫收據的賣方名稱、品項比規則準；沿用現有 GCP service account 與帳單；資料不拿去訓練 | 沒有逐欄信心度；模型可能編造欄位內容，仍需電子發票 QR 優先、使用者核對；計費改為按 token；此模型只開放 global／us／eu 端點，無台灣區域 | 輸入 $0.25／1M token、輸出（含思考）$1.50／1M token；粗估約 US$0.0014／張（待實測） |
| ~~Google Document AI — Enterprise Document OCR + 後端規則~~（2026-10-29 停用） | 讀中文全文準、比 Invoice Parser 快；欄位用台灣憑證格式規則抽 | 規則要自己維護，手寫收據的賣方名稱、品項抓不準 | 免費 1000 頁/月，超過 $1.5/1000 頁 |
| ~~Google Document AI — Invoice Parser~~（2026-10-27 棄用） | 有發票欄位模型 | **官方支援語言不含中文**，台灣憑證幾乎抽不到欄位 | 每份 $0.10（約 $100/1000 張） |
| **假 OCR（先做 UI）** | 零成本、先驗證流程 | 上線前必補真 OCR | 免費 |

**Gemini 串接決策（2026-10-29）**

- **入口**：走 Vertex AI，不走 Gemini API（API key）。兩邊單價相同；Vertex AI 可沿用 Document AI 的 service account 與認證程式、同一張 GCP 帳單。此模型沒有台灣區域，端點用 `global`。Vertex AI 單價待在 GCP 帳單／計費目錄確認。
- **抽欄位**：以 `responseSchema` 要求模型直接回欄位 JSON；原本從全文抽欄位的規則退場，只保留格式檢查（例如統編 8 碼、發票字軌）。電子發票 QR 優先、多檔合併與衝突清單維持不變。
- **用量查詢**（2026-10-29 改）：系統內不記錄 token 用量。開發者要查時，用 OCR 的 service account（另加 `roles/monitoring.viewer`）讀 GCP Cloud Monitoring 的 `aiplatform.googleapis.com/publisher/online_serving/token_count`（依 input／output 分開），再以上表單價換算美金／台幣。數字是本機與正式站合計（同一個 GCP 專案），不出現在 API 回應或任何畫面。
- **對客戶的配額**：仍以「次數」計算（見 `docs/OCR辨識規格.md` §5），token 費用不轉嫁、不顯示給客戶。
- **對帳**：Monitoring 換算的費用是照價目表自算，實際費用以 GCP 帳單為準，每月核對一次。

### 7. 檔案儲存（憑證圖片／PDF）

以 Rails ActiveStorage 管理檔案。**2026-11-03 起開發與正式站都先存主機硬碟**（正式站為 `quickey_backend_storage` volume，備份需涵蓋此 volume）；之後主機空間不足或要把備份交給雲端時，再於 Google Cloud Storage / Cloudflare R2 二選一，屆時只改 ActiveStorage 設定並搬移既有檔案，程式不改。圖檔規則見 `docs/資料模型.md` §2.4。

| 建議 | 優點 | 缺點 | 成本 |
|---|---|---|---|
| **Google Cloud Storage（GCS）** | 與 Google Document AI 同一個 GCP 帳號好整合、簽名 URL 私有存取、lifecycle 自動清理 | 需綁 GCP、出網流量要錢 | 免費 5 GB／月；超過 ~$0.02/GB 儲存 + $0.12/GB 出網 |
| **Cloudflare R2** | S3 API 相容、**出網流量免費**（適合會下載附件的場景）、跟 Landing 用的 Cloudflare 帳號共用 | 沒有 OCR 直通、要自己接 S3 SDK | 免費 10 GB／月；超過 $0.015/GB 儲存、出網 $0 |
| 本機檔案系統 + Nginx 靜態伺服（僅開發） | 最簡單、無額外服務 | 難擴展、備份要自己排 | 免費 |

## 四、自架伺服器相關（部署 / 維運）

### 11. 伺服器作業系統

| 建議 | 說明 |
|---|---|
| **Ubuntu 22.04 LTS**（推薦） | Docker、Node、多數服務官方支援完整 |

### 12. 反向代理 / SSL

**選定：Nginx + Cloudflare 代理 SSL**（2026-10-06 決議）

| 方案 | 說明 | 備註 |
|---|---|---|
| ✅ **Nginx + Cloudflare 代理 SSL**（選定） | Nginx container 只處理 HTTP（port 80）：serve 前端靜態檔 + `/api/*` 反代後端。HTTPS 由 Cloudflare 代理（橘色雲）在前面擋 | 零維運憑證；順便吃到 DDoS 防護、CDN、WAF；要在 Nginx 加白名單只放行 Cloudflare 真實 IP 段，避免被繞過直攻 origin |
| ~~Caddy~~ | 一行設定自動 HTTPS | 原本為預設方案；改用 Nginx 沿用業界熟悉設定 |
| ~~Nginx + Certbot 容器~~ | 自主申請／續期 Let's Encrypt | 多一個 service + init 腳本；上線初期 Cloudflare 代理方案更輕 |

### 13. 容器化 / 部署

| 建議 | 優點 | 缺點 |
|---|---|---|
| **Docker + Docker Compose**（推薦） | 一份 compose 檔搞定 app + DB + MinIO + PostHog + GlitchTip；本機/正式環境一致 | 需學 Docker 基礎 |
| **PM2（Node 進程管理）** | 輕量、直接跑 Node app | 需分別安裝各服務、環境不一致風險 |

### 14. CI/CD（自動部署）

**選定：GitHub Actions + SSH deploy**（2026-10-06；**實作時機延後到搬 VPS 後**，搬 VPS 前先手動 `git pull && docker compose up -d --build`）

| 建議 | 說明 |
|---|---|
| ✅ **GitHub Actions + SSH deploy**（選定） | Push to main → Actions build → SSH 到伺服器 pull + docker compose up；免費 |
| ~~Coolify（自架 PaaS）~~ | 類 Vercel/Heroku 體驗、UI 部署；服務多時再考慮 |

### 15. 資料庫備份

| 建議 | 說明 |
|---|---|
| **每日 `pg_dump` + rsync 到異地**（推薦） | Cron 排程、備份到 Cloudflare R2 或另一台 VPS |
| **物件儲存 + 保留 30 天** | 自動輪替、災難復原可回溯 |

圖檔存在主機硬碟期間（§7），備份除了資料庫，也要涵蓋 `quickey_backend_storage` volume，兩者同時間點備份，還原時才不會有紀錄找不到圖檔。

### 16. 監控 / Log

| 建議 | 說明 |
|---|---|
| **Uptime Kuma（自架）**（推薦） | 服務健康監控、Line/Email 告警 |
| **Grafana + Loki + Prometheus** | 完整 log/metrics 儀表板（服務多再考慮） |

## 五、上線初期月成本估算（採推薦方案 + 自架伺服器）

| 項目 | 月成本 |
|---|---|
| 雲端伺服器（4 GB RAM，跑 app + DB + MinIO + PostHog + GlitchTip） | ~$20–40 |
| 網域 | ~$1（年繳分攤） |
| Email（Resend 免費 tier） | 0 |
| OCR（Vertex AI Gemini 3.1 Flash-Lite，按 token 計費；粗估每 1,000 張約 US$1.4） | ~$1–5 |
| 備份異地（R2） | ~$0–1 |
| **總計** | **~$25–45 / 月** |

> 使用者變多後（1000+），伺服器可能要升級或水平擴展，屆時月成本 $80–200。
