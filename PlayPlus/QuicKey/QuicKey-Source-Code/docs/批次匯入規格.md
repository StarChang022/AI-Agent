# 批次匯入規格

> 作者：Peggy｜2026-10-29 確認｜對象：PM 與團隊同仁｜技術細節見 `docs/資料模型.md` §5.4、§5.5

批次匯入讓管理員一次建立多筆支出或收入，分兩種：

| 方式 | 適合情境 | 是否扣 OCR 次數 | 時程 |
|---|---|---|---|
| Excel 匯入 | 搬移舊資料、已有整理好的帳 | 不扣 | 已完成 |
| 批次 PDF 匯入 | 一疊紙本收據掃描成檔案 | 扣 | 開發中（先做支出） |

---

## 一、Excel 匯入

### 範圍
- 支出列表、收入列表都可以匯入，只有管理員能用。
- 首版只接受**系統範本**，匯入視窗可以下載範本。之後會支援使用者自己的格式，不必先轉成範本。

### 操作流程
1. 下載範本並填寫
2. 上傳檔案
3. 預覽：每一筆會顯示「可匯入」「會補預設值」或「不匯入」，並說明原因
4. 處理找不到的類別（見下方說明）
5. 按「匯入 N 筆」，一次全部建立
6. 完成畫面：顯示成功筆數，並列出未匯入的列和補了預設值的列

匯入後要修改，到列表點開該筆編輯即可。

### 範本欄位（支出）

| 欄位 | 必填 | 說明 |
|---|---|---|
| 單據編號 | | 同一筆有多個品項時，每列填相同編號；只有一列可留空 |
| 日期 | ✔ | 西元或民國年都可以，例：2026/10/15、115/10/15 |
| 文件類型 | ✔ | 發票或收據 |
| 廠商 | ✔ | |
| 統一編號 | 發票必填 | 收據可不填 |
| 發票號碼 | 發票必填 | 例：AB-12345678；收據不填 |
| 類別 | ✔ | 填類別名稱 |
| 稅別 | | 應稅或免稅，沒填當應稅；收據一律免稅 |
| 未稅金額 | 二擇一 | 未稅、含稅至少填一個，另一個系統會算 |
| 稅額 | | 沒填由系統計算 |
| 含稅金額 | 二擇一 | 可寫 `NT$1,260`、`1,260 元` |
| 付款狀態 | | 待付款或已付款，沒填當待付款 |
| 付款日 | | 已付款時填 |
| 說明 | | |
| 品名、數量、單價、小計 | | 每列一個品項；沒有品項就留空。數量沒填當 1 |

收入範本相同，只是「日期」改為「開立日」、「廠商」改為「客戶」、付款改為收款。

### 填寫範例
**一列是一個品項；單據編號相同的列，會合併成同一筆。**日期、廠商這類資料只要填在第一列。

| 單據編號 | 日期 | 文件類型 | 廠商 | 統一編號 | 發票號碼 | 類別 | 稅別 | 未稅金額 | 稅額 | 含稅金額 | 付款狀態 | 付款日 | 說明 | 品名 | 數量 | 單價 | 小計 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 1 | 2026/10/15 | 發票 | 福華文具行 | 12345675 | AB-12345678 | 辦公用品 | 應稅 | | | 1,260 | 已付款 | 2026/10/20 | | A4 影印紙 | 3 | 200 | 600 |
| 1 | | | | | | | | | | | | | | 原子筆 | 30 | 22 | 660 |
| 2 | 2026/10/16 | 收據 | 台灣大車隊 | | | 交通費 | | | | 350 | | | 拜訪客戶 | | | | |
| | 2026/10/17 | 發票 | 全家便利商店 | 24536806 | CD-87654321 | 餐費 | | 114 | | | | | | 便當 | 2 | 60 | 120 |

- 第 1、2 列：同一張發票、2 個品項。只填含稅金額，系統算出未稅 1,200、稅額 60。
- 第 3 列：沒有品項的收據，不需要統一編號和發票號碼。
- 第 4 列：不填單據編號，這一列自己就是一筆。只填未稅金額，系統算出含稅 120。

### 有錯的列怎麼處理

| 情況 | 處理方式 |
|---|---|
| 必填欄位沒填或看不懂：日期、文件類型、廠商／客戶、金額（未稅、含稅都沒填）；發票另含統一編號、發票號碼 | **不匯入**，完成畫面列出 Excel 第幾列和原因，修正 Excel 後重新匯入這幾筆即可 |
| 類別沒填或找不到 | 預覽時讓使用者選擇對應（見下方） |
| 稅別、付款狀態等選填欄沒填 | 用預設值（應稅、待付款），屬正常用法，不列出 |
| 選填欄填了但看不懂 | 補上預設值後匯入，完成畫面列出 |
| 收據的統一編號格式不對 | 該欄留空後匯入，完成畫面列出 |
| 含稅金額跟品項加總不一致 | 照填的金額匯入，完成畫面提醒 |

同一筆單據裡只要有任何一列無法匯入，整筆都不匯入。

### 預覽時移除不要的項目
預覽表每一筆最右邊有「✕」按鈕，點了就把那一筆移出這次匯入，不會建立。移錯了可以復原。

### 類別找不到時
例如 Excel 寫「文具」，但公司只有「辦公用品」。預覽時每個找不到的名稱只問一次，使用者選擇：
- **對應到既有類別**（文具 → 辦公用品），或
- **新增此類別**（預設選項）

- 類別沒填的列會合併成一項「未填類別」，要選對應到哪個類別。
- 名稱跟已停用的類別相同時，可以選擇重新啟用該類別，或對應到其他類別。

### 限制
- 只接受 .xlsx，檔案最大 5 MB，最多 1,000 列
- 匯入的紀錄沒有憑證附件，之後可以在編輯時補上
- 首版不會檢查是否重複匯入
- 帳戶功能上線後，範本會加上「帳戶」欄

## 二、批次 PDF 匯入

### 要解決的問題
OCR 是按次數計費的。一頁上如果有 3 張收據，系統會辨識出 3 筆，如果只扣 1 次，等於使用者用 1 次拿到 3 次的結果。

### 做法：先找出張數，確認後才辨識和扣次
1. 上傳 PDF 或圖片（一頁可以有好幾張收據）
2. 系統先找出每頁有幾張憑證，**還不辨識內容**
3. 畫面顯示：「找到 7 張憑證，確認後最多扣 7 次（剩餘 43 次）」
4. 使用者按確認，系統才逐張辨識、扣次，並帶入新增頁讓使用者逐筆核對；取消就不扣次

### 扣次規則
- **辨識出內容的憑證，一張扣一次**。確認前顯示的是找到的張數；確認後如果有幾張辨識不出內容（例如框到的不是憑證），那幾張不扣，實際扣的次數可能比顯示的少
- 剩餘次數不夠時，可以**依頁**勾選要帶出哪幾頁（同一頁的憑證一起帶出），或先去加購
- 確認後扣的次數不退：之後在新增頁刪掉某一筆或整批不建立，都不退
- 收入的客戶帶憑證上的買方；憑證沒寫買方時客戶留空，要補上才能建立
- 單筆新增時的 OCR 扣次方式不變，維持每頁扣 1 次

### 限制
每次最多 5 頁、每頁最多 10 張、單檔 20 MB、最多 5 個檔案。

頁數上限定為 5 頁，是為了讓找張數和確認後的辨識都能一次做完：正式環境前面的 Cloudflare 最多只等 100 秒，5 頁、最多 50 張可以同時處理，最慢也在時限內。

### 其他規則
- 只有管理員可用。入口在支出列表、收入列表「⋯」選單「匯入 Excel」下面的「批次匯入憑證」。
- 每張憑證會裁成單張再辨識，比整頁一起辨識準確；附件仍附整頁。
- 電子發票有 QR Code 時，以 QR 的內容為準。
- 每一筆附上該張憑證所在的那一頁；同一頁有多張時，那幾筆附同一頁。單頁超過 5 MB 時不附，提醒使用者自己補。
- 找到的張數保留 30 分鐘，過期要重新上傳。
- 找張數、確認後的辨識各最多 90 秒，正常不會碰到，只在 Google 回應異常時才會用上。逾時的頁或憑證不扣次，畫面提醒使用者重新上傳那幾頁；重新上傳時，同一頁已帶出的憑證會再算一次，要在新增頁自己刪掉。
- 同一家公司同時只能有一批在辨識，第二批會看到「上一批憑證還在辨識中，請稍候再試」。

### 已知風險：取消不扣次，但找張數的費用已經發生
系統找張數時，Google 就已經向我們收費（每頁一次），使用者之後按確認或取消都一樣。如果有人一直上傳、看張數、再取消，使用者不用付次數，這部分的錢是我們出。逐張辨識要等使用者確認後才做，所以取消時的損失只有找張數這一步。

- **首版**：照規則做，取消不扣次，先不限制。
- **上線後觀察**：統計每家公司「辨識後取消」的次數和頁數，看有沒有異常。
- **需要時再加的限制**：每家公司每小時最多辨識幾次；或取消次數太多時，改成辨識前就先扣次。
