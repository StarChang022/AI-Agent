# QA Checklist — 批次匯入憑證（支出／收入）

> **驗證對象**：管理員把一疊掃描或拍照的憑證（PDF 或圖片）一次上傳，系統先找出張數、確認後才逐張辨識並扣次，再逐筆核對建立支出或收入。
> **前置**：以管理員身分登入後台；需要能調整公司「剩餘辨識次數」（請洽工程師）。測試檔放在共用的「批次匯入測試」資料夾，檔名與下方各條對應。
> **規格來源**：`docs/資料模型.md` §5.5、`docs/批次匯入規格.md` 第二節。
> **注意**：只驗證功能流程與規則，不寫 UI 細節。第 1～11 節以支出為例，收入共用同一套規則，收入才有的項目見第 12 節。
> **預期張數說明**：測試檔內的張數是製作時的設計值；實際辨識結果若與預期不同，請先確認是辨識誤差還是系統問題，再記錄。
> **次數記錄方法**：每一條涉及扣次的測試，請在測試前後各記一次「剩餘次數」。

## 1. 入口與權限

- [ ] 管理員在支出列表打開「⋯」選單 → 在「匯入 Excel」下方看到「批次匯入憑證」
- [ ] 點「批次匯入憑證」→ 出現上傳視窗
- [ ] 管理員在收入列表打開「⋯」選單 → 在「匯入 Excel」下方看到「批次匯入憑證」
- [ ] 員工登入前台 → 看不到任何批次匯入憑證的入口
- [ ] 員工直接輸入後台網址 → 被導回前台，無法使用
- [ ] 員工即使知道辦法硬送出請求 → 被拒絕，不會辨識也不會扣次（請工程師協助驗證）

## 2. 上傳檔案

### 2.1 可接受的檔案
- [ ] 上傳 A01（JPG 圖片）→ 可送出
- [ ] 上傳 A02（PDF）→ 可送出
- [ ] 上傳 D02（HEIC 照片）→ 可正常辨識，顯示 1 張；確認帶出後，該筆附上的憑證可正常開啟查看（已轉成一般圖片格式）
- [ ] 一次選多個檔案（例如 D05、D06、D07 三張）→ 全部列在上傳區，可一起送出
- [ ] 上傳前可移除已選的檔案；移除後不會被送出

### 2.2 數量與大小上限
- [ ] 選 E01 的 5 個檔案 → 可接受
- [ ] 選 E02 的 6 個檔案 → 提示最多 5 個檔案，不送出
- [ ] 上傳 D03（超過 20 MB）→ 提示單檔大小上限，不送出
- [ ] 上傳 C01（剛好 5 頁）→ 可接受
- [ ] 上傳 C02（6 頁）→ 提示每次合計最多 5 頁，不辨識、不扣次
- [ ] 同時上傳 C03 與 C04（合計 6 頁，各自都沒超過）→ 提示合計頁數超過上限，不辨識、不扣次
- [ ] 同時上傳 A03（2 頁）與 A05（3 頁），合計剛好 5 頁 → 可接受
- [ ] 圖片檔每個算 1 頁：選 5 張圖片（E01 資料夾）→ 可接受；選 6 張圖片 → 提示超過頁數上限（先出現「最多 5 個檔案」的提示也算正確）
- [ ] 上傳 D01（假 PDF）→ 提示無法讀取檔案，不會出現系統錯誤，不扣次

### 2.3 剩餘次數檢查
- [ ] 剩餘次數為 0 → 無法送出，並說明次數不足
- [ ] 剩餘次數為 1 → 可送出辨識（送出前只檢查至少 1 次）

## 3. 上傳後先只顯示張數

- [ ] 上傳 A02 → 畫面顯示「找到 2 張憑證，確認後最多扣 2 次（剩餘 M 次）」，M 為目前剩餘次數
- [ ] 此時畫面**不顯示**任何憑證內容（廠商、金額等），也沒有扣次（剩餘次數不變）
- [ ] 上傳 A05 → 畫面顯示每一頁的張數：第 1 頁 1 張、第 2 頁 2 張、第 3 頁 3 張，總計 6 張
- [ ] 上傳 A04 → 顯示 2 張、3 頁，空白頁標示為不扣次
- [ ] 上傳 A06（全部空白）→ 顯示找不到憑證、0 次；無法確認，也不扣次
- [ ] 上傳 A03（2 頁各 1 張）→ 顯示 2 張、各頁 1 張
- [ ] 同時上傳 D05、D06、D07 三個檔案 → 顯示合計 3 張，並能分辨各檔案／頁的張數

### 3.1 每頁與整批上限
- [ ] 上傳 B01（1 頁 10 張）→ 可接受，顯示 10 張
- [ ] 上傳 B02（1 頁 11 張）→ 提示該頁超過每頁上限，不可確認、不扣次
- [ ] 上傳 B03（5 頁各 10 張，共 50 張）→ 可接受，顯示 50 張
- [ ] 註：每次最多 5 頁、每頁最多 10 張，整批最多剛好 50 張，所以「整批超過 50 張」在正常上傳下碰不到，不另設測試檔

## 4. 確認與取消

### 4.1 確認後扣次
- [ ] 上傳 A02 後按「確認」→ 剩餘次數減少 2
- [ ] 上傳 A04 後按「確認」→ 剩餘次數減少 2（空白頁沒有扣）
- [ ] 確認後帶到新增支出頁，每一張憑證對應一個分頁，共 N 個
- [ ] 同一批確認只能扣一次：確認後返回、重新進入同一批的確認，不會再扣
- [ ] 按確認後顯示正在辨識，等待期間不能再按確認、也不能關閉視窗；辨識完才帶到新增支出頁
- [ ] 有某張辨識不出內容時 → 實際扣的次數比確認前顯示的少，並提示「X 張辨識不出內容，未扣次」
- [ ] 按確認時辨識服務暫時異常 → 提示這次沒有扣次，停在確認畫面，稍後再按確認可正常帶出（請工程師協助模擬）
- [ ] 上傳 F01_兩頁各三張.pdf 確認後 → 6 個分頁，印刷清楚的憑證（發票、銷貨明細表）都能帶出發票號碼與金額

### 4.2 取消不扣次
- [ ] 辨識後按「取消」→ 剩餘次數不變，不建立任何支出
- [ ] 辨識後直接關閉視窗 → 剩餘次數不變
- [ ] 取消後重新上傳同一個檔案 → 重新辨識，仍能正常確認

## 5. 次數不夠

> 準備：把剩餘次數調成 4，上傳 A05（共 6 張，分 3 頁）。

- [ ] 畫面顯示「找到 6 張，確認後最多扣 6 次（剩餘 4 次）」，並說明次數不足
- [ ] 畫面用文字說明「可先加購或減少勾選」；**沒有**加購連結或按鈕（加購頁尚未上線）
- [ ] 預設無法直接確認全部 6 張
- [ ] 每一頁可勾選是否帶出（第 1 頁 1 張、第 2 頁 2 張、第 3 頁 3 張），勾選的張數合計顯示在畫面
- [ ] 勾第 1 頁＋第 3 頁（合計 4 張）→ 可確認；確認後扣 4 次、只帶出這兩頁的 4 張
- [ ] 勾第 2 頁＋第 3 頁（合計 5 張，大於剩餘 4）→ 不可確認，提示次數不足
- [ ] 全部取消勾選 → 不可確認
- [ ] 勾選 4 張確認後，剩餘次數為 0
- [ ] 沒有勾選的頁不會被帶出，也不會扣次

## 6. 辨識結果的保留期限

- [ ] 辨識後 30 分鐘內按確認 → 正常帶出
- [ ] 辨識後超過 30 分鐘才按確認 → 提示結果已過期，請重新上傳；沒有扣次
- [ ] 已確認並帶出過的同一批，再次嘗試確認 → 提示需重新上傳，不會重複扣次
- [ ] 過期或已確認過後重新上傳 → 重新辨識，流程正常

## 7. 帶出到新增支出頁逐筆核對

- [ ] 確認後進入新增支出頁，每張憑證一個分頁，內容為辨識出的資料（廠商、日期、金額等），可逐筆修改
- [ ] 上傳 A03（2 頁各 1 張）→ 2 個分頁，各自附上自己那一頁的憑證檔案
- [ ] 上傳 A02（1 頁 2 張）→ 2 個分頁，兩筆都附**同一頁**的憑證檔案
- [ ] 上傳 A05 → 6 個分頁；第 1 頁那筆附第 1 頁、第 2 頁的 2 筆都附第 2 頁、第 3 頁的 3 筆都附第 3 頁
- [ ] 每個分頁只附一個憑證檔案，不會附上整份多頁 PDF
- [ ] 上傳 D04（單頁超過 5 MB）→ 該筆**不附檔案**，並提示使用者自己補上傳憑證
- [ ] 其他沒超過大小限制的筆仍正常附檔
- [ ] 逐筆核對、修改後建立 → 支出出現在列表，內容與核對後相同，憑證可在詳情中查看
- [ ] 確認後在新增頁按「移除這筆」並確認 → 該筆不建立，其他筆不受影響，**剩餘次數不退**；取消則不移除
- [ ] 確認後在新增頁整批放棄、一筆都不建立 → 剩餘次數仍維持已扣的結果，**不退次數**
- [ ] 未完成核對就離開新增頁 → 出現離開提醒；離開後未建立的筆不會自動建立
- [ ] 從批次匯入進到新增支出頁後，按瀏覽器重新整理或關閉分頁 → 瀏覽器先問「確定要離開嗎？」
- [ ] 選擇不離開 → 帶出的資料仍在，可繼續核對
- [ ] 選擇確定離開 → 帶出的資料全部消失，**剩餘次數不退**
- [ ] 手動新增支出（沒走批次匯入）時按重新整理或關閉分頁 → **不會**出現這個提示

## 8. 一次建立多筆失敗時

> 同時適用「批次匯入憑證」帶出的多筆，以及原本在新增支出頁手動開多個分頁一次建立的情況，兩者都要測。

- [ ] 準備 3 個分頁，其中第 2 筆故意缺必填欄位（或金額不合法）後一起送出 → 第 1 筆建立成功，第 2 筆失敗，第 3 筆依規則處理（記錄實際結果）
- [ ] 中間某筆失敗時，已建立的幾筆**從分頁移除**，畫面顯示「已建立幾筆」
- [ ] 失敗的筆與尚未處理的筆仍留在分頁，可修正
- [ ] 修正後再次送出 → 只建立剩下的筆，**已建立過的不會重複建立**
- [ ] 全部成功 → 顯示全部建立成功，分頁清空
- [ ] 全部失敗 → 沒有任何筆被建立，所有分頁保留
- [ ] 失敗後支出列表的筆數與畫面顯示的「已建立幾筆」一致
- [ ] 批次匯入憑證帶出的筆，失敗後修正再送出，附的憑證檔案仍然正確（沒有掉檔、沒有附錯頁）

## 9. 不影響既有功能

- [ ] 新增支出頁**單筆**上傳憑證做 OCR → 仍是每頁扣 1 次（例如上傳 1 頁 PDF 扣 1 次、3 頁扣 3 次）
- [ ] 單筆 OCR 的單張多收據圖片 → 仍視為同一張憑證、只帶出一筆，扣次方式不變
- [ ] 手動新增支出（不用 OCR）→ 不扣次，流程不變
- [ ] 編輯既有支出 → 不受影響
- [ ] Excel 匯入不扣辨識次數，流程不變
- [ ] 批次匯入憑證前後，儀表板、報表、類別預算對新增的支出的統計與手動新增一致

## 10. 剩餘次數的顯示與資料隔離

- [ ] 每次扣次後，畫面上剩餘次數即時更新，與 OCR 設定／次數顯示處一致
- [ ] 別家公司的管理員拿不到、也確認不了這批辨識結果（請工程師協助驗證）

## 11. 手機瀏覽

- [ ] 手機上可上傳檔案（含相簿選取照片）、看張數與每頁張數、勾選頁面、確認或取消
- [ ] 手機上帶出後可逐筆核對並建立

## 12. 收入

- [ ] 收入列表還沒有資料時 → 空畫面也有「批次匯入憑證」
- [ ] 從收入列表開啟的上傳視窗 → 說明寫的是帶到新增收入頁
- [ ] 上傳開給客戶的發票並確認 → 帶到新增收入頁，每張一個分頁，客戶與買方統編帶憑證上的買方，不是自己公司
- [ ] 上傳沒有寫買方的憑證 → 客戶是空的，要補上才能建立
- [ ] 帶出的每一筆預設為待收款，類別要逐筆選擇
- [ ] 換到其他筆再換回來 → 剛才改的內容還在
- [ ] 其中一筆缺必填欄位時按建立 → 停在那一筆並標示缺什麼，一筆都不會建立
- [ ] 按「移除這筆」並確認 → 這筆消失、其他筆不受影響，剩餘次數不退；取消則不移除
- [ ] 逐筆建立完成 → 收入出現在列表，憑證可在詳情查看，且只有自己那一頁
- [ ] 建立途中某一筆失敗 → 已建立的從分頁移除並顯示筆數，修正後再送出不會重複建立
- [ ] 從批次匯入進到新增收入頁，按重新整理或關閉分頁 → 瀏覽器先問是否離開；手動新增收入時不會出現
- [ ] 批次匯入的新增收入頁沒有「清除所有欄位」與辨識按鈕，不會重複扣次
- [ ] 手動新增收入、單筆辨識、編輯收入 → 流程不變
- [ ] 同月支出與收入批次匯入共用同一份剩餘次數
