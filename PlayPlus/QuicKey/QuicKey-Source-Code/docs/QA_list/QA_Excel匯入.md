# QA Checklist — Excel 匯入（支出／收入）

> **驗證對象**：管理員在「支出」與「收入」列表用 Excel 一次建立多筆紀錄時，各種情境下的行為與規則是否正確。
> **前置**：以管理員身分登入後台。準備好下載的範本，以及幾份自己改過的測試檔（缺標題、日期亂填、類別名稱不存在等）。
> **規格來源**：`docs/資料模型.md` §5.4。> **注意**：本清單只驗證「功能流程與規則」；按鈕樣式、顏色、字級等 UI 細節由設計規範統一把關，不在此列。
> **適用範圍**：除特別標註「支出」或「收入」外，兩邊規則相同，請各跑一次。收入的「開立日」「客戶」對應支出的「日期」「廠商」；收入的「收款」對應支出的「付款」。

---

## 1. 入口與權限

- [ ] 管理員在支出列表看得到「匯入 Excel」→ 點開後出現匯入視窗
- [ ] 管理員在收入列表看得到「匯入 Excel」→ 點開後出現匯入視窗
- [ ] 員工登入前台 → 找不到任何匯入 Excel 的入口
- [ ] 員工直接輸入後台網址 → 被導回前台，無法使用匯入
- [ ] 匯入視窗內可「下載範本」；上傳區說明只收 .xlsx

## 2. 下載範本

- [ ] 在支出的匯入視窗按「下載範本」→ 取得 Excel 檔，標題依序為：單據編號、日期、文件類型、廠商、統一編號、發票號碼、類別、稅別、未稅金額、稅額、含稅金額、付款狀態、付款日、說明，以及品名、數量、單價、小計
- [ ] 在收入的匯入視窗按「下載範本」→ 標題依序為：單據編號、開立日、文件類型、客戶、統一編號、發票號碼、類別、稅別、未稅金額、稅額、含稅金額、收款狀態、收款日、說明，以及品名、數量、單價、小計
- [ ] 必填欄位（日期／開立日、文件類型、廠商／客戶、類別）在標題上有 * 標示；統一編號、發票號碼標示為「發票必填」；未稅金額、含稅金額標示為「至少填一個」
- [ ] 範本內另有「填寫說明」工作表，示範三種寫法：多品項、無品項、不填單據編號
- [ ] 不修改範本直接上傳 → 不會因標題問題被退回

## 3. 標準格式匯入（最基本流程）

- [ ] 照範本填 3 筆資料（各自不同日期、類別、金額）→ 上傳後先看到預覽表，列出每筆的 Excel 列號、內容摘要與狀態，此時**列表上還沒有新資料**
- [ ] 預覽表狀態皆為「可匯入」→ 按鈕顯示「匯入 3 筆」
- [ ] 按「匯入 3 筆」→ 完成畫面顯示成功匯入 3 筆，沒有未匯入的列
- [ ] 關閉完成畫面 → 列表出現這 3 筆，內容（日期、廠商／客戶、類別、金額、說明）與 Excel 一致
- [ ] 匯入的紀錄**沒有憑證附件**；點開編輯可以補上傳
- [ ] 在預覽畫面按取消或關閉視窗 → 不建立任何紀錄
- [ ] 打開任一筆匯入紀錄的歷程 → 看得到建立動作，且來源標示為 Excel 匯入
- [ ] 匯入後的紀錄計入儀表板、報表與類別預算的統計（與手動新增一致）
- [ ] 預計付款日等自動帶出的日期，與手動新增同條件的結果一致
- [ ] 完成畫面關閉後，列表上**沒有**「待確認」之類的特殊標記，匯入的紀錄與一般紀錄看起來一樣
- [ ] 重複上傳同一份檔案並匯入兩次 → 會建立兩批相同紀錄（首版不偵測重複）

## 4. 單據編號與品項

### 4.1 多品項
- [ ] 同一單據編號填 3 列，每列各一個品項（品名、數量、單價）→ 預覽顯示為 1 筆，品項 3 個
- [ ] 匯入後開啟該筆 → 看到 3 個品項，品名、數量、單價與 Excel 一致
- [ ] 同一單據編號的 3 列**不相鄰**（中間夾著其他單據）→ 仍合併為同一筆
- [ ] 同一單據的基本資料（日期、廠商、類別、金額等）只填在第一列 → 後面的列留空不會造成錯誤
- [ ] 品項小計留空、有數量與單價 → 小計 = 數量 × 單價
- [ ] 品項只填小計、數量與單價留空 → 數量視為 1、單價 = 小計
- [ ] 品項數量留空 → 數量視為 1

### 4.2 無品項
- [ ] 單據只填基本資料與金額、品項欄全空 → 匯入後該筆沒有品項，金額為填寫的金額

### 4.3 不填單據編號
- [ ] 單據編號整欄留空、各列分別是不同的紀錄 → 每一列各自成一筆，不會被合併
- [ ] 單據編號有填的與沒填的混合在同一份檔案 → 有填的依編號合併，沒填的各自成一筆
- [ ] 匯入後的紀錄**看不到**單據編號（編號只用來分組，不會存入系統）

### 4.4 同單據各列資料不一致
- [ ] 同一單據編號的第二列也填了日期／類別等，且與第一列不同 → 以第一列為準；完成畫面列出該單據有此狀況

## 5. 欄位順序與標題

- [ ] 把範本的欄位順序打亂（例如金額挪到最前面）後上傳 → 仍能正確讀到每個欄位的資料
- [ ] 檔案多出自己加的欄位（如「備註2」「部門」）→ 多出的欄位被忽略，不影響匯入，也不報錯
- [ ] 標題前後有空白、或標題帶 * 號 → 仍可辨識
- [ ] 檔案有多個工作表 → 只讀第一個工作表
- [ ] 缺少以下任一標題 → **整份退回**，顯示「找不到『○○』欄，請使用範本」類型的提示，不進入預覽：日期（收入為開立日）、文件類型、廠商（收入為客戶）、統一編號、發票號碼、類別、未稅金額、含稅金額（請逐一各刪一欄測試）
- [ ] 標題都在，但某欄的格子全部留空 → 不因標題問題退回，依各欄必填規則逐筆判斷
- [ ] 缺少其他標題（稅別、稅額、付款狀態、付款日、說明、品名、數量、單價、小計、單據編號）→ 不退回，視為該欄全空

## 6. 必填欄位與該筆「不匯入」

> 不匯入 = 該筆不會建立，其他正常的筆照常匯入；完成畫面列出 Excel 列號與原因。必填欄位空白或無效不會自動補值。

### 6.1 日期
- [ ] 日期（收入為開立日）留空 → 該筆不匯入，預覽顯示「不匯入」與原因
- [ ] 日期寫成讀不出的文字（如「下週」）→ 該筆不匯入
- [ ] 日期年份早於 2000 年，或晚於明年 → 該筆不匯入
- [ ] 日期接受以下寫法並正確讀出：Excel 日期格式、`2026/10/29`、`2026-10-29`、民國 `115/10/29`

### 6.2 文件類型
- [ ] 文件類型填「發票」或「收據」→ 正常讀取
- [ ] 文件類型留空 → 該筆不匯入（即使有填發票號碼也不會自動當成發票）
- [ ] 文件類型填其他文字（如「單據」）→ 該筆不匯入

### 6.3 廠商／客戶
- [ ] **支出**：廠商留空 → 該筆不匯入
- [ ] **收入**：客戶留空 → 該筆不匯入

### 6.4 發票的統一編號與發票號碼
- [ ] 發票，統一編號留空 → 該筆不匯入（**不會**改成收據）
- [ ] 發票，統一編號不是 8 碼數字或檢查碼不通過 → 該筆不匯入
- [ ] 發票，發票號碼留空 → 該筆不匯入
- [ ] 發票，發票號碼格式不符（不是 2 碼英文 + 8 碼數字）→ 該筆不匯入
- [ ] 發票號碼寫成 `AB-12345678` 與 `AB12345678` → 兩種都能接受
- [ ] 發票，統一編號與發票號碼都正確 → 可匯入
- [ ] 收據，統一編號與發票號碼都留空 → 可匯入，不列出

### 6.5 金額
- [ ] 未稅金額、含稅金額兩個都留空 → 該筆不匯入
- [ ] 兩個都留空，但有填品項 → 仍然不匯入（不會以品項加總代替）
- [ ] 未稅或含稅其中一個有填但看不懂（例如寫「一千」），即使另一個正確 → 整筆不匯入，不會拿另一個推算
- [ ] 金額為文字（如「很多」）或負數 → 該筆不匯入
- [ ] 金額寫成 `NT$1,200`、`$1,200`、`1,200元`、` 1200 ` → 都能讀成 1200
- [ ] 金額填超過 99 億 → 該筆不匯入，完成畫面列出原因
- [ ] 金額帶 2 位小數（如 100.55）→ 可匯入；超過 2 位小數 → 該筆不匯入
- [ ] 應稅發票，未稅金額大於含稅金額 → 該筆不匯入

### 6.6 多品項與整體
- [ ] 多品項單據中**任何一列**造成不匯入（例如第二列日期錯誤）→ 整張單據都不匯入，不會只匯入一部分
- [ ] 完成畫面的「未匯入」清單：每一列都有 Excel 列號與原因，列號與 Excel 上看到的行號一致（含標題列算第 1 列）
- [ ] 所有單據本來就都是「不匯入」（可匯入 0 筆）→ 「匯入」按鈕不可按，提示沒有可匯入的資料、請修正 Excel 後重新選檔，不會建立任何紀錄（與第 11 節「使用者全部移除」是不同情況，提示不同）

## 7. 金額推算

- [ ] 只填含稅金額（應稅發票）→ 自動算出未稅金額與稅額，結果與手動新增同樣金額一致（5% 拆算）
- [ ] 只填未稅金額（應稅發票）→ 系統自動算出稅額與含稅金額，結果與手動新增一致
- [ ] 未稅、含稅兩個都填 → 照填寫的值
- [ ] 應稅發票未稅、含稅都填，但不符合 5% 稅率（例如未稅 100、含稅 500）→ 照填匯入，完成畫面列出「不符合 5% 稅率，請確認」
- [ ] 應稅發票未稅、含稅都填且符合 5% 稅率 → 不出現稅率提醒
- [ ] 稅額留空 → 應稅發票為含稅減未稅；免稅或收據為 0
- [ ] 稅額有填，但與系統推算結果不符 → 以推算結果為準，完成畫面列出
- [ ] 免稅發票，未稅與含稅兩個都填但不相等 → 以含稅為準，完成畫面列出
- [ ] 收據，未稅與含稅兩個都填但不相等 → 以含稅為準，完成畫面列出
- [ ] 收據（任何情況）→ 一律免稅，不拆稅額（未稅＝含稅、稅額為 0），與手動新增選收據時一致
- [ ] 收據填了應稅 → 改成免稅，完成畫面列出
- [ ] 收據稅別留空 → 免稅，不列出

## 8. 補預設值與提醒（照匯入並列出）

> 以下情況該筆照常匯入。**只有「有填但看不懂」才會在完成畫面的「需要留意」清單列出 Excel 列號與說明；欄位留空而套用預設值屬正常，不列出。** 例外：已付款／已收款但付款日／收款日留空，仍要列出。

### 8.1 稅別
- [ ] 稅別填「應稅」「應稅5%」「5%」→ 皆視為應稅；填「免稅」「0%」→ 視為免稅
- [ ] 發票的稅別留空 → 視為應稅，**不列出**
- [ ] 發票的稅別填讀不出的字 → 視為應稅，並列出

### 8.2 收據的發票資訊
- [ ] 收據填了發票號碼 → 發票號碼不帶入，並列出
- [ ] 收據的統一編號無效 → 統一編號留空，並列出
- [ ] 收據的統一編號有效 → 照帶入

### 8.3 付款／收款狀態與日期
- [ ] 狀態留空 → 支出視為待付款、收入視為待收款，**不列出**
- [ ] 狀態填「已付款」／「已收款」→ 匯入後為已付款／已收款；填「待付款」／「待收款」→ 為待付款／待收款
- [ ] 狀態填讀不出的字 → 視為待付款／待收款，並列出
- [ ] 狀態為已付款／已收款但付款日／收款日留空 → 以日期（收入為開立日）代入，並列出
- [ ] 付款日／收款日填讀不出的內容 → 以日期代入，並列出
- [ ] 狀態為待付款／待收款，卻填了付款日／收款日 → 日期不帶入，並列出
- [ ] 付款日／收款日接受與日期欄相同的各種寫法

### 8.4 品項
- [ ] 品項數量填 0 或負數 → 該品項不匯入，該筆其他內容照匯入，完成畫面列出
- [ ] 品項的品名空白 → 該品項不匯入，但主檔那筆照匯入，並列出
- [ ] 品項算不出小計（無小計、也缺數量或單價）→ 該品項不匯入，主檔照匯入，並列出

### 8.5 多項提醒
- [ ] 某筆同時有多項提醒 → 完成畫面該列的說明把各項都列出，不會只列其中一項

## 9. 金額與品項加總不一致

- [ ] 含稅金額填 1,000、但品項小計加總為 900 → 照匯入，金額以填寫的 1,000 為準，並於完成畫面提醒不一致
- [ ] 匯入後開啟該筆 → 金額為 1,000、品項保持 Excel 上寫的內容，沒有被自動改掉
- [ ] 品項加總等於含稅金額 → 不出現不一致提醒
- [ ] 品項加總等於未稅金額（例如發票品項以未稅列示）→ 不提醒
- [ ] 品項加總與未稅、含稅都不相等 → 才提醒

## 10. 類別對應

### 10.1 類別名稱正好存在
- [ ] Excel 的類別名稱與公司「使用中」的同類型類別完全相同（支出對支出類別、收入對收入類別）→ 預覽時不問，直接對應，匯入後該筆歸在該類別
- [ ] 類別名稱前後有空白、英文大小寫不同 → 仍視為同一類別

### 10.2 類別名稱找不到
- [ ] Excel 有公司內不存在的類別名稱 → 預覽畫面出現「類別對應」區，列出所有找不到的名稱
- [ ] 同一個找不到的名稱在檔案中出現很多次 → 只列一次、只問一次，所有該名稱的資料套用同一個選擇
- [ ] 每個找不到的名稱預設選項為「新增此類別」
- [ ] 保持預設直接匯入 → 公司多出該名稱的新類別，匯入的紀錄歸在其下；到類別管理頁看得到新類別
- [ ] 改選「對應到既有類別」並選一個類別 → 匯入的紀錄歸在選定的類別，且**不會**新增類別
- [ ] 同時有 2 個以上找不到的名稱，各自選不同處理方式（一個新增、一個對應既有）→ 各自依選擇生效
- [ ] 多筆類別欄位留空 → 對應區合併成一項「（未填類別）」，只問一次；該項只能對應到既有類別，**沒有「新增」選項**；選擇後這些筆依選擇匯入
- [ ] 「（未填類別）」尚未選擇既有類別 → 無法按匯入
- [ ] 「對應到既有類別」的下拉選單只列出「使用中」的類別，不含已停用者

- [ ] 某個找不到的類別名稱只被「不匯入」的單據用到 → 不出現在類別對應區、不用選擇，匯入後公司也不會新增該類別

### 10.3 類別名稱過長
- [ ] Excel 的類別名稱超過 50 字且公司內找不到 → 預覽時該名稱**不能選「新增此類別」**，只能對應到既有類別；未選前無法按匯入

### 10.4 停用的類別
- [ ] 公司有一個已停用的類別「餐費」，Excel 填「餐費」→ 視為找不到，出現在類別對應區（不會被自動歸入已停用類別）
- [ ] 該名稱的選項**沒有「新增此類別」**，只有「重新啟用此類別」（預設）與「對應到既有類別」
- [ ] 保持預設匯入 → 該停用類別被重新啟用（回到類別管理的「使用中」），匯入的紀錄歸在其下，不會產生兩個同名類別
- [ ] 選「對應到既有類別」→ 可改選其他使用中類別，原停用類別維持停用

### 10.5 支出與收入類別分開
- [ ] 在收入匯入時填寫只存在於支出類別的名稱 → 視為找不到（兩邊類別不互通）
- [ ] 在支出匯入時新增的類別，只出現在支出類別，不會出現在收入類別

### 10.6 公司隔離
- [ ] 類別對應的下拉選單只看得到**本公司**的類別，看不到其他公司的類別
- [ ] 以另一家公司的管理員匯入相同名稱的類別 → 只與該公司自己的類別比對，不受其他公司影響

## 11. 預覽時移除

- [ ] 預覽表中每一筆「可匯入」的單據，最右側有可移除的按鈕
- [ ] 「不匯入」的列**沒有**移除按鈕
- [ ] 多品項的單據在預覽中只算一筆，只有一個移除按鈕；移除後該單據所有品項都不會匯入
- [ ] 點移除一筆 → 該筆從本次匯入移出；預覽上方顯示「已移除 1 筆」
- [ ] 移除後，按鈕上的匯入筆數即時減少（例如「匯入 5 筆」→「匯入 4 筆」）
- [ ] 按「復原」→ 被移除的單據回到本次匯入，已移除數量歸零，匯入筆數恢復
- [ ] 移除多筆後，已移除數量與匯入筆數都正確；可分別復原
- [ ] 某個找不到的類別名稱，所有使用它的單據都被移除 → 該名稱從類別對應區消失；匯入後公司**不會**多出這個類別
- [ ] 某個找不到的類別名稱，仍有其他單據在使用 → 保留在類別對應區，被移除的單據不影響其選擇
- [ ] 「（未填類別）」的單據全部被移除 → 該項從對應區消失，不再要求選擇
- [ ] 把所有可匯入的單據都移除 → 匯入按鈕不可按，提示可以按「全部復原」
- [ ] 按「全部復原」→ 所有被移除的單據回到本次匯入，匯入按鈕恢復可按
- [ ] 移除一筆後按匯入 → 列表只新增剩下的筆數；被移除的單據確實**沒有**建立（到列表以日期、廠商／客戶搜尋確認）
- [ ] 完成畫面顯示「使用者移除 N 筆」，且與預覽移除的筆數一致；沒有移除時不顯示該項
- [ ] 被移除的單據不會出現在「未匯入」或「需要留意」清單
- [ ] 移除後重新上傳檔案 → 移除紀錄清空，從頭開始

## 12. 整批寫入的完整性

- [ ] 預覽顯示 N 筆可匯入 → 按匯入後，列表恰好新增 N 筆（品項多的單據算 1 筆）
- [ ] 匯入過程中若發生錯誤（如網路中斷、伺服器錯誤）→ 顯示失敗訊息，**一筆都沒建立**；重新匯入可正常成功
- [ ] 預覽後、按匯入前，在別處把某個要對應的既有類別停用或刪除 → 按匯入時整次不匯入，提示「類別已變更，請重新預覽」，一筆都沒建立；重新預覽後可正常匯入
- [ ] 匯入進行中重複點擊「匯入」按鈕 → 只建立一批，不會重複寫入
- [ ] 匯入後類別的「使用筆數」增加正確

## 13. 檔案限制

- [ ] 上傳 .xls、.csv、.pdf、圖片等非 .xlsx 檔案 → 被拒絕並提示只收 .xlsx，不進入預覽
- [ ] 上傳超過 5 MB 的檔案 → 被拒絕並提示大小上限
- [ ] 上傳剛好 1,000 列資料的檔案 → 可正常預覽與匯入
- [ ] 上傳 1,001 列以上 → 被整份拒絕並提示列數上限（標題列不計入）
- [ ] 上傳只有標題、沒有任何資料列的檔案 → 整份退回，提示沒有可匯入的資料
- [ ] 上傳完全空白的檔案 → 提示無法讀取或沒有資料，不會當機
- [ ] 上傳損毀、或不是真正 Excel 而只是改副檔名成 .xlsx 的檔案 → 顯示「無法讀取檔案」的提示，不會出現系統錯誤，也不會進入預覽
- [ ] 1,000 列的檔案處理期間有明確的處理中提示，完成前不能重複送出
- [ ] 預覽畫面上傳新檔案取代舊檔案 → 預覽與類別對應全部以新檔案為準，不殘留舊資料

## 14. 完成畫面

- [ ] 有不匯入的列時，顯示清單：Excel 列號 + 原因；沒有時不顯示該區
- [ ] 有補預設值或需留意的列時，顯示清單：Excel 列號 + 說明；沒有時不顯示該區
- [ ] 同時存在「不匯入」與「需留意」→ 兩份清單分開呈現，不混在一起
- [ ] 有在預覽移除單據時，顯示「使用者移除 N 筆」（詳見第 11 節）
