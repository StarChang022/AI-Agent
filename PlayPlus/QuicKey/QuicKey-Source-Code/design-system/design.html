Quickey Design System

代墊款管理工具（Quickey）設計系統。主色為品牌綠 #00B39F（取自 Logo），實心底/文字強調走 WCAG 合格的 #008072。前台採 mobile-first 大圓角卡片語言，後台繼承相同 tokens。

設計理念

  • 主色克制：品牌綠只用在主要動作按鈕、選中分頁、Logo。頁面主體以中性灰階為主，表頭/卡片/背景不鋪主色。
  • 狀態語意化，且與主色脫鉤：6 種請款狀態各有專屬顏色，一眼可辨。主色不可挪用當狀態色——「已核銷」已改成固定紫色，不再借用 primary，避免未來主色再換色時撞色。
  • 數字第一：金額使用 currency 文字樣式 + tabular-nums 等寬對齊。
  • 視覺清晰優先：資訊層級一眼可辨（標題 → 數字 → 說明），任何裝飾都不能干擾閱讀。
  • 間距有邏輯：只用間距 tokens（4/8/12/16/20/24/32/40），關係越近間距越小；同層級元素間距一致，不為單一畫面微調。
  • 對齊：同一區塊的文字、圖示、欄位共用對齊線；文字靠左、金額數字靠右。
  • 一致：同一種元件在每一頁長得一樣，同一種狀態永遠用同一組顏色與圖示。
  • 同列等高：並排在同一列的元件高度一致（按鈕與輸入框、KPI 卡、內容卡片），內容長短不同時由容器撐齊，不讓卡片高低不一。
  • 重要動作要有存在感：多數元件走克制路線，但憑證上傳這種流程關鍵動作，改用比一般 input 更明顯的拖放區樣式。

排版原則

同一個畫面的文字樣式越少越好，層級靠粗細與顏色區分，避免視覺疲勞。詳情抽屜、卡片、表單都適用。

  • 字級上限 4 種：頁面或抽屜標題、區塊標題、內文 16px、輔助文字 14px。金額這類關鍵數字是唯一例外。
  • 用粗細與顏色分層級：區塊標題 16px 粗體黑色；欄位名稱 16px 一般字重灰色（muted）；欄位值 16px 黑色（ink）。不再為了分層級多加一種字級。
  • 顏色只有三種用途：文字只用黑、灰兩色；綠色（primary-text）只給可以點的東西；狀態色只出現在 Status Badge / Tag 裡。
  • 預設狀態不顯示，只標示例外：系統自動排程、預設值不另外標註；需要讓人注意的狀況才用 Tag 標示。
  • 不用括號補充說明：需要提示時改用 Tag，或直接刪掉；括號會讓一行文字變長、層級變亂。
  • 用卡片與間距分組，不加分隔線：相關資訊放進同一張卡片或白底小格，不用細線切開。
  • 並列資訊用直線分隔：兩段資訊並排時用 .sep（淺灰細直線，左右 8px），不用「·」或「/」。
  • 低頻資訊收起來：建立者、建立時間、最後更新這類紀錄，放在詳情最下方的「紀錄」區塊，預設收合，點標題列在原地展開；不用浮層或 tooltip。
  • 不用純黑，文字只用 4 階色：ink、slate、muted、muted-soft，同一藍灰色相；詳見色彩頁「文字色階」。
  • 文字最小 12px：附件檔名、圖表標示等小字也不得小於 12px。

前台 vs 後台密度差異

面向前台（員工）後台（財務/管理員）
響應式優先手機（375px+）桌面（1280px+）
Layout 寬度max-w-3xl 置中側邊 sidebar + flex-1 內容區
資訊密度低（一次一件事）高（表格、篩選、批次操作）
字級基準較大（16–20px）較小（14px 為主）
導覽底部 tab bar側邊 sidebar

手機版（<640px）文字上限 14px（含 modal、button、input、卡片內文）；桌機版（≥1024px）原本 12px 的內文一律放大到 14px（狀態徽章、類別 chip、icon 除外）。
