側邊導覽 — side-nav

分組項目說明
主選單儀表板套用「首頁（儀表板）」
支出管理公司所有支出（一般支出＋核准後轉入的代墊款）；新增/編輯用整頁表單
請款請款記錄員工送出的代墊款請款單
簽核待管理員簽核的請款單；右側徽章顯示待簽核筆數
系統類別管理費用類別與對應的會計科目（多個類別可共用一個科目）；新增、編輯、停用
預算管理每個類別的月預算或年預算、基本預算設定
人員管理邀請、編輯、重設密碼、刪除人員；邀請 3 天內有效
—個人設定不放側邊導覽，從頂欄右上角頭像選單進入

名詞與分組以後台前端為準：首頁 → 儀表板、支出紀錄 → 支出管理、請款紀錄 → 請款記錄、審核 → 簽核、類別與預算 → 拆成類別管理與預算管理；付款／發放狀態整合在支出管理與請款明細裡，不另設「發放」側邊導覽項。分組為「主選單/請款/系統」。介面文字、按鈕、提示訊息都用新名詞。徽章數字為 0 時不顯示。

頂欄 — topbar

陳

由左到右固定為：漢堡按鈕（收合側邊導覽）→ 全域搜尋 → 通知鈴（有未讀時右上紅點）→ 頭像。全域搜尋找的是整個系統的請款單與支出，結果以下拉清單顯示，點選直接開明細；列表頁「自己的」篩選搜尋放在頁面工具列，不用頂欄搜尋。頭像選單：個人設定、切換到員工前台、登出。

收合 — nav-collapsed

  • 點頂欄漢堡按鈕收合/展開，側邊導覽用寬度滑入滑出（0.24s），主內容跟著變寬；系統設定「減少動態效果」時不播動畫。
  • 可用寬度不足（範本內容區 < 960px）時預設收合，初次載入不播動畫。
  • 按鈕加 aria-expanded 與 aria-controls，說明文字在「收合/展開側邊選單」之間切換；收合時側邊導覽設為 inert，Tab 鍵不會跳進去。

頁首 — page-head

支出管理
  • 左側：頁面標題（跟側邊導覽名稱一致），不放副標題/說明文字；頁面用途靠標題、分頁與空狀態說清楚。
  • 右側：頁面層級的動作，主要動作（新增、套用）用實心主按鈕、只能有一個；次要動作（匯出、匯入）用外框按鈕放在它左邊。
  • 不常用的設定類動作（例如預算管理的「基本預算設定」）不另外佔一顆按鈕，收進主要動作右邊的「⋯ 更多動作」選單，讓主次一眼分明。
  • 只影響部分資料的動作（批次核准、批次刪除）不放頁首，放在列表的批次操作列。
