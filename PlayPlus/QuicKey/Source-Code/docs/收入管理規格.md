**功能內容**

1. **收入管理**
    - 欄位與支出對齊：發票或收據、客戶、統一編號、發票號碼、金額、稅率與稅額、開立日、收入類別、收入科目（選填）、附件、備註
    - 品項明細（IncomeItem）：品名、數量、單價、小計，類別放在整筆收入，品項不分類
    - 輸入方式：拍照 OCR、文件上傳（可辨識電子發票）、Excel 匯入、手動建立
    - 收款狀態：待收款／已收款，收款日
    - 支出類別與收入類別分開管理，預算只綁支出類別
    - 收入類別草稿：銷售收入、服務收入、利息收入、其他收入
2. **類別管理**（後台「系統」群組）
    - 同一頁分頁：「支出類別」「收入類別」
    - 支出類別供支出登錄與代墊款請款選擇；收入類別供收入登錄選擇
3. **收支統一規則（收入與支出相同）**
    - 刪除：待收款、待付款才能刪除，進入垃圾桶；已收款、已付款需先切回才能刪除
    - 垃圾桶：可還原或永久刪除，不計入統計，不可編輯
    - 編輯：任何時候可改，含已收款、已付款，保留變更前後內容
    - 狀態切換：任何時候可切換，日期可填，不需原因。切換時不清空任何資料；待收款、待付款時畫面隱藏實際收款日（支出另隱藏實際付款日與付款人），只顯示預計日期。資料保留，可在稽核日誌查看
    - 稽核日誌：上述所有動作皆記錄，只能新增
4. **報表**（側邊欄兩項）
    - **損益報表**：以發生日計。收入為開立日，支出為費用日期（發票或收據上的日期、實際消費日），不是匯款日。12 個月收支表與年度合計，含預算執行率
    - **現金流報表**：以收付日計。收入為收款日，支出為實際付款日。12 個月收付表與年度合計，含待收款、待付款清單與到期日
    - 共同：預設以年為期間，可切換月、季、自訂區間，可匯出 Excel
5. **儀表板（後台）**
    - 本月收入、本月支出、淨額（收入－支出）
    - 待收款
    - 待付款（一般支出與未結清代墊款，待付款金額加總）
    - 待簽核
    - 近 12 個月收支趨勢（大圖，收入與支出並列）
    - 移除：預算使用率（移至預算管理頁）、最近請款（待簽核已涵蓋）

**需工程師處理**

- `incomes` 資料表與模型（§2.6），欄位與 `expenses` 對齊；`incomeItems`（§2.6.1）
- Category 新增 `kind`（支出／收入），收入類別可選填 `accountCode`（§3.4）
- **支出現有缺口**
    - `expenses#destroy` 為硬刪除，改為軟刪除並進垃圾桶
    - `revert_pay` 會清空付款日與付款人，改為保留資料，只調整畫面顯示
- 收入的 OCR、Excel 匯入，與支出共用流程
- 年度彙總查詢（§六）
    - 損益：收入以開立日、支出以費用日期分組
    - 現金流：收入以收款日、支出以實際付款日分組
    - 皆排除垃圾桶
- 儀表板 KPI 與趨勢改由後端計算
- 稽核日誌（§2.7）：只新增，後台「系統」群組唯讀檢視

**後續延伸（本版不做）**：退回、收入目標、客戶主檔、多筆收款、報表多維度篩選與進階分析、結帳與期間鎖定

**驗收**

- 收入與支出的刪除、垃圾桶、還原、編輯、狀態切換行為一致
- 已收款、已付款的紀錄無法直接刪除，切回待收款、待付款後可刪除
- 切換狀態時資料全部保留；待收款、待付款時畫面隱藏實際日期與人員，只顯示預計日期
- 收入可用 OCR、Excel 匯入、手動建立，品項小計正確
- 支出類別與收入類別分開，預算只綁支出類別
- 損益報表與現金流報表，同一筆紀錄分別落在開立月與收付月
- 報表預設為本年 12 個月，匯出 Excel 與畫面數字一致
- 垃圾桶內的紀錄不計入統計、不可編輯
- 稽核日誌只能新增，任何介面都無法修改或刪除
- 前台儀表板維持原樣，包含「最近幾筆請款」
