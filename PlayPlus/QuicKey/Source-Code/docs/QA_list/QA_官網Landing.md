# QA 清單：官網（Landing）

以下為使用者情境的核對清單，開發完成後由團隊依序人工確認。

## 首頁

- [ ] 打開首頁 → 看到標題「每一筆收支，都有交代」與「免費開始」按鈕
- [ ] 點「免費開始」→ 前往註冊頁面
- [ ] 首頁的人物插圖會持續做輕微動作
- [ ] 系統設定開啟「減少動態效果」時 → 人物與背景都不會動
- [ ] 往下捲動 → 依序看到：痛點、服務介紹、數據、知識文章、聯絡我們、行動呼籲
- [ ] 「為什麼用 QUICKEY」的數字旁都標示「目標」，並附註說明為設計目標

## 痛點說明

- [ ] 看到三種情境（行政、老闆、員工），每種都有一句話描述煩惱

## 服務介紹

- [ ] 看到三個服務：記下收支、輕鬆請款、預算看得見，標題皆為四個字以內
- [ ] 每個服務標題下方有一兩句簡短說明

## 知識文章

- [ ] 看到三張文章卡，都標示「即將推出」
- [ ] 點「看更多文章」→ 前往部落格頁面

## 聯絡我們與 LINE

- [ ] 點「加入 LINE」→ 開啟 LINE 官方帳號頁面（目前為示範連結）
- [ ] 點 Email → 開啟信件編寫視窗，收件人為示範信箱

## 導覽列

- [ ] 電腦版 → 看到四個選單項目與「免費開始」按鈕，點選後前往對應頁面
- [ ] 手機版 → 點選單按鈕展開選單，再點一次收合；點選頁面後選單自動收合
- [ ] 目前所在頁面的選單項目有明顯標示

## 關於我們

- [ ] 看到公司理念與三個核心價值

## 常見問題

- [ ] 點任一問題 → 展開答案；再點一次 → 收合
- [ ] 「可以取代會計師或報稅嗎？」→ 答案說明 QUICKEY 專注於公司內部收支管理，報稅與正式帳務可交由專業人員處理

## 聯絡我們

- [ ] 看到 LINE 與 Email 兩種聯絡方式

## 部落格

- [ ] 看到「即將推出」的說明與三張文章佔位卡

## 隱私權政策／服務條款

- [ ] 從頁尾點選「隱私權政策」或「服務條款」→ 開啟對應頁面
- [ ] 頁面上方標示「草稿・待審閱」
- [ ] 條文涵蓋：資料蒐集、使用目的、保存與安全、分享、使用者權利、服務內容、費用、責任範圍

## 找不到頁面

- [ ] 輸入不存在的網址 → 看到「找不到這個頁面」與回首頁按鈕

## 手機版

- [ ] 所有頁面在手機寬度下都不出現左右捲動
- [ ] 按鈕與選單項目容易點選
- [ ] 文字在手機上可以正常閱讀
