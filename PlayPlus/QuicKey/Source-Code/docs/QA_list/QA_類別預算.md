# QA Checklist — 類別預算模組

> **驗證對象**：管理員操作類別預算功能時，各種情境下的行為與規則是否正確。
> **前置**：以管理員身分登入後台，進入「類別預算」頁面。若要從全新狀態測試，請洽工程師協助清空 localStorage。
> **注意**：本清單只驗證「功能流程與規則」；顏色、字級、按鈕樣式等 UI 細節由設計規範統一把關，不在此列。

---

## 1. 頁面總覽

- [ ] 頁面標題為「類別預算」，右上角有「基本預算設定」按鈕
- [ ] 頁面上方控制列由左至右為：週期切換（月預算／年預算）、期間切換組、「套用基本預算」按鈕
- [ ] 進入頁面時預設停在「月預算」，期間為**今天所屬的月份**（例如 2026-09-17 進入時顯示「2026 年 9 月」）
- [ ] 表格列出目前所有使用中類別（含尚未設定過任何預算的類別，每個類別佔一列）
- [ ] 已停用的類別**通常不出現**在表格中；例外：若某過往期間曾為該類別設過預算，切到該期間時該類別會出現在使用中類別之後，並在名稱旁顯示「已停用」tag（詳見第 9 節「類別停用連動」與新增的「歷史預算查閱」）
- [ ] 若沒有任何使用中類別、且當前檢視期間也沒有任何已停用類別的歷史預算 → 顯示引導訊息與「前往類別管理」按鈕；點按鈕會直接導向「類別管理」頁

## 2. 週期切換（月預算／年預算）

- [ ] 點「月預算」／「年預算」→ 表格內容立即更新為對應週期的資料
- [ ] 切到「年預算」後，期間切換器變成以「年」為單位（例如「2026 年」）；週期標題也對應變化
- [ ] 每次切換週期時，期間自動重置為今日對應期間（例如從 2026 年 8 月的月檢視切到年 → 期間變成 2026 年）
- [ ] 同一類別的月預算與年預算是**互相獨立**的兩筆資料（月的預算金額不會影響年的預算金額，反之亦然）
- [ ] 週期切換不影響已儲存的資料（切走再切回，設定的金額仍在）

## 3. 期間切換與快速返回

- [ ] 月預算檢視下：點左箭頭 → 期間變成前一個月；點右箭頭 → 前進一個月
- [ ] 年預算檢視下：點左箭頭 → 期間變成前一年；點右箭頭 → 前進一年
- [ ] 點期間標籤（例如「2026 年 9 月」或「2026 年」）→ 彈出月份／年份選擇器；月預算檢視下開的是月份選擇器、年預算檢視下開的是年份選擇器
- [ ] 於選擇器中點某月份／年份 → 期間直接跳到該月份／年份，選擇器自動關閉
- [ ] 月份選擇器的月份標籤以純數字顯示（1、2、3…12），NOT 顯示英文縮寫（Jan/Feb/Mar…）
- [ ] 期間切換後，表格內容立即更新為該期間的預算金額與該期間內的實際支出加總
- [ ] 期間可回顧任意過去月份／年份，也可切到未來月份／年份
- [ ] 當前檢視期間**不等於**今日期間時 → 在期間切換組的左邊出現快速返回按鈕（月檢視為「本月」、年檢視為「今年」）
- [ ] 當前檢視期間**等於**今日期間時 → 快速返回按鈕不出現
- [ ] 點快速返回按鈕 → 期間立刻回到今日對應期間，按鈕消失

## 4. 表格內容（各欄位語意）

**類別欄**
- [ ] 顯示類別名稱；若類別有設定會計科目代碼，於名稱下方以小字顯示

**預算欄**
- [ ] 尚未設定預算的類別 → 顯示「＋ 設定預算」文字按鈕
- [ ] 已設定預算的類別 → 顯示金額 + 鉛筆 icon（整區可點）
- [ ] 進入編輯狀態時，顯示金額輸入框 + 右側「儲存」（✓）與「取消」（✕）兩個 icon 按鈕

**實際支出欄**
- [ ] 顯示該類別於當前期間內所有支出的加總（含一般支出 + 已核銷代墊款；不論已付款或待付款皆計入）
- [ ] 某類別在此期間無支出時 → 顯示 $0

**剩餘欄（進度條 + 百分比 + 超支標籤）**
- [ ] 無支出時：進度條為滿、百分比顯示 100%
- [ ] 有支出但未超支：進度條依剩餘比例縮短、百分比顯示對應剩餘百分比
- [ ] 剩餘 > 20% → 進度條顯示正常色；剩餘 1–20% → 進度條顯示警示色（黃）；剩餘 ≤ 0% → 進度條為空、顯示紅色 + 出現「超支」文字標籤
- [ ] 尚未設定預算的類別 → 進度條為灰底、百分比顯示「—」、不出現超支標籤

**餘額欄**
- [ ] 顯示「預算 − 實際」的金額
- [ ] 正值 → 一般樣式顯示（例如 $600）
- [ ] 負值（超支）→ 紅色警示樣式 + 金額前綴 `−`（例如 −$200）
- [ ] 尚未設定預算的類別 → 顯示「—」

## 5. 新增／修改預算（inline 編輯）

**進入編輯**
- [ ] 未設定預算的列點「＋ 設定預算」→ 預算欄變成金額輸入框 + 右側儲存／取消按鈕、輸入框自動 focus
- [ ] 已設定預算的列點金額或鉛筆 → 進入編輯狀態、輸入框帶入原本金額並全選

**儲存**
- [ ] 輸入金額後點「儲存」（✓）或按 Enter → 儲存成功、出現對應提示（新增：「已設定預算」／修改：「已更新預算」）
- [ ] 儲存後剩餘、餘額、進度條立即依新金額重新計算

**取消**
- [ ] 點「取消」（✕）或按 Esc → 放棄變更、恢復編輯前狀態
- [ ] 編輯過程中滑鼠焦點離開輸入框（例如點頁面別處、切到別的視窗）→ **不會**自動儲存也**不會**自動取消，編輯狀態保留

**驗證**
- [ ] 金額欄留空按儲存 → 出現「請填寫金額」提示、不儲存
- [ ] 輸入負數按儲存 → 出現「金額不得為負數」提示、不儲存
- [ ] 修改後金額與原本相同 → 靜默結束編輯、不跳提示（視為無變更）

**設為 0 = 取消預算**
- [ ] 已設定預算的列，改為 0 並儲存 → 出現「已取消預算」提示、該列變回「＋ 設定預算」未設定狀態
- [ ] 取消預算只影響當前檢視的類別與期間；同一類別於其他期間、其他週期（月／年）的預算不受影響

## 6. 基本預算設定（Dialog）

**開啟**
- [ ] 點頁面右上角「基本預算設定」按鈕 → 彈出 Dialog
- [ ] Dialog 標題依當前週期顯示：月檢視下為「基本月預算」、年檢視下為「基本年預算」
- [ ] Dialog 上方有明確說明：「儲存基本預算不會自動改動任何月／年預算，需點『套用基本預算』才會套用到當前檢視期間。金額設為 0 = 不設此類別的基本預算。」
- [ ] Dialog 列出所有使用中類別、每列一個金額輸入框；已有基本預算的類別預填既有金額、其餘顯示 0
- [ ] 若沒有任何使用中類別 → Dialog 內容改為引導訊息與「前往類別管理」按鈕（Footer 的儲存／取消按鈕也不出現）；點按鈕直接關閉 Dialog 並導向「類別管理」頁

**儲存**
- [ ] 修改金額後點「儲存」→ 出現「已儲存基本預算」提示、Dialog 關閉
- [ ] 儲存後**任何期間的月／年預算金額、剩餘、餘額、進度條都不會變**（明確不影響當期）
- [ ] 某類別金額設為 0 儲存 → 該類別的基本預算被清除（下次開 Dialog 顯示 0）
- [ ] 某類別輸入負數按儲存 → 出現該類別對應的「金額不得為負數」提示、Dialog 保持開啟不關閉

**取消**
- [ ] 點「取消」或按 Esc 或點擊 Dialog 外遮罩 → 放棄變更、Dialog 關閉、資料不變

**月／年獨立**
- [ ] 於月檢視下編輯的基本預算，切到年檢視再開 Dialog 看到的是**另一組**基本年預算資料（不會被月的值汙染）
- [ ] 重新整理頁面 / 關瀏覽器再打開 → 基本預算仍存在

## 7. 套用基本預算

- [ ] 「套用基本預算」按鈕位於期間切換組的右邊，永遠可點（不受基本預算數量影響）
- [ ] 點按鈕 → 出現確認視窗，訊息包含當前期間名稱（例如「將以『基本月預算』覆寫當前期間（2026 年 9 月）所有類別的預算金額，是否繼續？」）
- [ ] 點「取消」→ 關閉視窗、當期預算不受影響
- [ ] 點「確認套用」→ 出現「已套用基本預算到 {當前期間}」提示
- [ ] 套用語意 = **當期預算完整鏡射基本預算**：
  - 基本預算 > 0 的類別 → 該期間預算金額被覆寫為基本預算的值（即使該期間原本已有不同金額）
  - 基本預算為 0（或未設）的類別 → 該期間預算被**清除**（等同「取消預算」，回到未設定狀態；若本來就未設定，則不變）
- [ ] 套用只影響「當前檢視期間」：例如在 2026 年 9 月月預算檢視下套用 → 2026 年 8 月、10 月、年預算都不受影響
- [ ] 週期隔離：於月檢視下套用只用月的基本預算；於年檢視下套用只用年的基本預算

## 8. 資料保留

- [ ] 新增／修改／取消預算後重新整理頁面 → 設定仍在
- [ ] 儲存基本預算後重新整理頁面 → 基本預算仍在
- [ ] 關閉瀏覽器再重新打開 → 所有預算與基本預算仍在
- [ ] 不同期間的預算是**完全獨立**的記錄（在 9 月設定的預算不會自動複製到 10 月；需以「套用基本預算」明確套用）

## 9. 跨模組連動

**類別停用連動**
- [ ] 到「類別管理」把某類別停用 → 回到類別預算頁面，該類別在**當期與未來期間**的預算列都消失
- [ ] 停用時，該類別的基本預算（月/年皆是）會被清除
- [ ] 停用時，該類別當期與未來期間的預算金額會被清除（例：今天在 9 月停用 → 9 月、10 月... 該類別預算都消失）
- [ ] 該類別過往已結束期間的預算金額**保留**（例：8 月的預算金額不會被動）
- [ ] 該類別解除停用後 → 再次出現在使用中類別列表；但基本預算與當期/未來預算需**重新設定**（不會自動恢復；先前設定過的金額不會回來）

**歷史預算查閱（已停用類別）**
- [ ] 將期間切到某已停用類別**曾設過預算**的過往期間 → 該類別會出現在表格中，排在使用中類別之後
- [ ] 已停用類別的列，類別名稱旁顯示「已停用」tag，讓使用者清楚辨識
- [ ] 已停用類別的預算欄**只顯示金額**，沒有鉛筆 icon、沒有「＋ 設定預算」按鈕，點擊無反應（歷史金額不允許編輯）
- [ ] 已停用類別的實際支出、剩餘進度條、餘額欄仍正常計算與顯示（歷史數據應保持一致）
- [ ] 將期間切到該類別**沒設過預算**的過往期間 → 該類別不會出現（沒資料就不顯示，避免整排 —）
- [ ] 若當前檢視的過往期間內只有已停用類別的歷史預算（沒有任何使用中類別）→ 表格照常顯示這些歷史列，不會顯示空狀態畫面

**支出新增／刪除連動**
- [ ] 新增一筆一般支出 → 對應類別 + 該期間的「實際」+N、剩餘 −N、餘額 −N、進度條即時更新
- [ ] 刪除一筆支出 → 對應類別 + 該期間的「實際」−N、剩餘 +N、餘額 +N、進度條即時更新
- [ ] 代墊款被審核通過並轉為一般支出 → 該類別的實際即時 +N（同上）
- [ ] 標記為已付款不影響實際加總（無論待付款或已付款皆計入）

## 10. 手機瀏覽

- [ ] 手機開啟頁面 → 表格改為卡片式呈現，每張卡片顯示一個類別（名稱、預算、實際、剩餘進度條、餘額；有超支時顯示「超支」標籤）
- [ ] 週期切換、期間切換、快速返回、套用基本預算、基本預算設定 Dialog 在手機上仍可完整操作
- [ ] 基本預算 Dialog 於手機上 → 每個類別的 label 與金額輸入框改為**上下排列**（label 在上、輸入框佔滿寬度）
- [ ] 手機版控制列元件排列：週期切換 → 期間切換器 → **本月／今年**（在期間切換器右邊）→ 套用基本預算
- [ ] 手機版**修改預算不是 inline**，改為彈出 Dialog：點卡片內的「＋ 設定」或金額 → 彈出 Dialog（含類別名稱標題、金額輸入框、儲存／取消）
- [ ] Dialog 內按 Enter 或點「儲存」→ 儲存成功、Dialog 關閉、卡片刷新
- [ ] Dialog 內金額輸入 0 儲存 → 取消當期該類別預算（同桌面 inline 版行為）
- [ ] 卡片式的預算編輯可正常完成（設定、修改、取消、設 0 取消預算）
