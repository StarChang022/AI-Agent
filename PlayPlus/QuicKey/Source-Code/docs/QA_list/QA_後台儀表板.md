# QA Checklist — 後台儀表板

> **驗證對象**：管理員登入後台後看到的儀表板頁面。
> **前置**：以管理員身分登入（`admin@example.com` / `password123`），停在後台首頁（也就是儀表板）。
> **注意**：本清單只驗證「功能流程與規則」；顏色、字級、卡片留白等 UI 細節由設計規範統一把關，不在此列。
> **定義**：
>
> - **本月**＝以電腦當下日期所在的自然月為準（1 號到月底）
> - **支出**＝支出列表中的所有支出（核准前的代墊款尚未成立支出，不會出現在支出列表）
> - **未結清代墊款**＝所有狀態為「已核銷（待發放）」的代墊款金額加總（與撥款頁「待發放」清單完全一致）

---

## 1. 進入儀表板

- [x] 登入管理員帳號後直接停在儀表板（網址列尾巴是 `/admin` 或 `/admin/dashboard`）
- [x] 頁面主標題顯示「儀表板」
- [x] 從左側選單點「儀表板」也能回到本頁

## 2. 本月支出總計卡片

- [x] 卡片顯示「本月支出」的**金額合計**與**筆數**
- [x] 金額 = 支出列表中「日期在當月」的所有支出金額總和
- [x] 筆數 = 同上條件下的支出筆數
- [ ] 支出無論已付款或待付款都計入（此卡片看的是「這個月花了多少」，不是「這個月已付了多少」）
- [ ] 本月完全沒有任何支出 → 卡片顯示金額 `NT$0`、筆數 `0 筆`，畫面不會空白或崩潰
- [ ] 卡片可以點擊 → 導向「支出管理」頁（後續可自行套用日期篩選查看細節）



## 3. 未結清代墊款卡片

- [ ] 卡片顯示「未結清代墊款」的**金額合計**與**筆數**
- [ ] 金額與筆數必須**跟「撥款」頁的「待發放」清單完全一致**（同一筆代墊款不會這邊算 0 筆、那邊列 3 筆）
- [ ] 一般支出（不論已付款或待付款）**不計入**此卡片
- [ ] 已撥款完成（狀態變為已發放）的代墊款 → **不計入**
- [ ] 仍在簽核中、被駁回、被作廢、或還是草稿的代墊款 → **不計入**
- [ ] 已核准的代墊款不論有沒有在支出列表成立對應支出、對應支出的付款狀態是待付款或已付款，只要代墊款本身還在「已核銷」狀態 → **一律計入**（因為撥款頁還會列出，還沒完成撥款動作）
- [ ] 目前沒有任何未結清的代墊款 → 卡片顯示 `NT$0` 與 `0 筆`
- [ ] 卡片可以點擊 → 導向「撥款」頁



## 4. 支出趨勢圖

- [ ] 預設顯示「近一年」（12 個月）的支出金額柱狀圖
- [ ] 標題旁有三個區間快選：**近三個月 / 近六個月 / 近一年**，點擊立即切換柱子數量
- [ ] 快選按鈕右邊有一個「自訂月份區間」的日期選擇器，可選起始月份與結束月份（月份精度，不含日期）
- [ ] 選好自訂區間後 → 圖表立即依該區間重算，快選按鈕的高亮消失（表示現在是自訂模式）
- [ ] 再次點三個快選任一個 → 自訂區間會被清空，回到該預設區間
- [ ] 每根柱子的月份標籤從最舊到最新（左 → 右），最右邊那根若是本月，會有明顯高亮（顏色較深）
- [ ] 每個月的金額 = 該月份所有支出金額總和（資料源同支出列表）
- [ ] 該月沒有任何支出 → 該月柱子高度為 0（不會缺一根）
- [ ] 滑鼠移到柱子上（或手機點擊柱子）→ 出現 tooltip，顯示該月份的金額與筆數
- [ ] 圖表下方或旁邊有「區間合計」，顯示目前選定區間內所有月份的加總金額
- [ ] 全站尚無任何支出資料 → 圖表區改顯示空狀態訊息（例：「尚無支出資料」），不會顯示破圖



## 5. 費用類別分佈圓餅圖

- [ ] 圓餅圖依「費用類別」分組，資料源與支出列表一致
- [ ] 圖表上方有三個區間快選：**近三個月 / 近六個月 / 近一年**（預設近六個月）
- [ ] 快選右邊有「自訂月份區間」日期選擇器，行為與趨勢圖相同（選了後快選高亮消失、再點快選會回到該預設）
- [ ] 甜甜圈中心顯示「合計」與該區間內所有支出的加總金額
- [ ] 圖表下方有類別清單，依金額大小由高到低排序；每項顯示顏色、類別名稱、佔比百分比、金額
- [ ] 滑鼠移到某片扇形上 → tooltip 顯示該類別名稱、金額、佔比
- [ ] 若某筆支出的類別已被停用 → 仍會出現在圖表上（顯示當時的類別名稱）
- [ ] 若某筆支出的類別找不到（資料異常）→ 用類別 id 字串顯示，不會整段消失
- [ ] 該區間內沒有任何支出 → 圓餅圖區顯示「此區間內尚無支出資料」空狀態，不會出現空的圓
- [ ] 類別多於顏色 palette 時 → 顏色會循環套用，仍能區分



## 6. 資料連動

- [ ] 新增一筆一般支出後回到儀表板 → 本月支出卡片、趨勢圖、類別分佈立即反映新資料
- [ ] 代墊款簽核通過並產生支出 → 本月支出卡片、趨勢圖、類別分佈立即反映；未結清代墊款卡片 +1 筆
- [ ] 撥款頁按下「標記已發放」→ 對應支出付款狀態轉為已付款；未結清代墊款卡片 -1 筆
- [ ] 刪除一筆支出 → 相關卡片與圖表立即回退
- [ ] 在類別管理頁改類別名稱 → 儀表板圖例、圓餅圖 tooltip 立即反映新名稱
- [ ] 重新整理頁面 → 數字仍然正確



## 7. 行動裝置檢視

- [ ] 使用手機開啟儀表板 → 卡片改為單欄堆疊，不會橫向捲動
- [ ] 趨勢圖與圓餅圖在手機上仍可正常顯示；柱子標籤過密時會自動略縮
- [ ] Tooltip 在手機上點一下柱子/扇形可顯示
- [ ] 區間快選按鈕在手機上仍可點擊；自訂日期選擇器可正常展開



## 8. 資料保留

- [ ] 新增支出、代墊款核准、撥款等動作結束後重新整理頁面 → 儀表板數字仍反映最新結果
- [ ] 關閉瀏覽器再重新打開 → 儀表板數字仍在
- [ ] 區間快選狀態**不會**保留（重新整理後回到預設：趨勢圖近一年、類別分佈近六個月）



## 9. 極端情境

- [ ] 支出日期為未來（例如今天是 9/18、支出日期填 12/31）→ 該筆不會出現在「本月支出」；會出現在對應月份的趨勢柱子上（若該月落在目前區間內）
- [ ] 支出日期早於目前趨勢圖區間 → 不會出現在趨勢圖或圓餅圖上（但仍會出現在支出列表）
- [ ] 代墊款產生的支出長期未撥款 → 只要付款狀態一直是「待付款」就會一直計入「未結清代墊款」
- [ ] 自訂區間只選單一月份 → 圖表顯示該單月資料
