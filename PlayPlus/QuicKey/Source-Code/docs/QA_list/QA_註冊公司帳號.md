# QA Checklist — 註冊公司帳號

> **驗證對象**：新公司從後台登入頁自行註冊（只填 Email 與密碼）、完成 Email 驗證、首次進後台填寫姓名與公司資訊；以及公司資訊的後續修改與邀請員工前的提醒。
> **前置**：未登入狀態，開啟後台登入頁（`/admin/login`）。若要重複測試同一個 Email，請洽工程師協助清空 localStorage。
> **注意**：本清單只驗證「功能流程與規則」；顏色、字級、按鈕樣式等 UI 細節由設計規範統一把關，不在此列。
> **Prototype 限制**：
> - 尚未串接寄信，驗證信以「模擬點擊驗證連結」按鈕代替。
> - 新註冊的管理員會看到與測試帳號相同的示範資料（支出、人員、預算），尚未依公司區隔。

---

## 1. 進入註冊頁

- [ ] 後台登入頁點「註冊公司帳號」→ 進入「註冊公司帳號」頁
- [ ] 註冊頁點「已有帳號？登入後台」→ 回到後台登入頁
- [ ] 前台登入頁的「註冊帳號」仍提示「請向公司管理員索取邀請連結」，不會進入公司註冊頁
- [ ] 已登入狀態下開啟註冊頁 → 顯示「目前已登入為 xxx，請先登出」，看不到註冊表單；點「登出目前身分」後出現表單

## 2. 填寫與檢查

- [ ] 註冊表單只有 Email、密碼、再次輸入密碼、同意條款，沒有姓名與公司資訊
- [ ] 什麼都不填直接送出 → Email、密碼、再次輸入密碼、同意條款各自顯示錯誤，不會送出
- [ ] Email 格式錯誤（例如 `abc`、`abc@`）→ 顯示「Email 格式不正確」
- [ ] 密碼少於 8 碼 → 顯示「密碼長度至少 8 碼」
- [ ] 兩次密碼不同 → 顯示「兩次輸入的密碼不同」
- [ ] 沒勾選同意服務條款與隱私權政策 → 顯示「請先同意服務條款與隱私權政策」
- [ ] 點條款中的「服務條款」「隱私權政策」→ 以新分頁開啟對應頁面，註冊頁內容不會遺失
- [ ] 修改有錯誤的欄位 → 該欄錯誤訊息消失
- [ ] Email 與既有帳號相同（例如 `admin@example.com`、`ming@example.com`，大小寫不同也算）→ 顯示「此 Email 已註冊，請直接登入」，點「登入」可前往後台登入頁

## 3. 驗證信

- [ ] 資料正確送出 → 進入「請到信箱完成驗證」頁，顯示剛填的 Email 與「請在 24 小時內點擊信中的連結完成註冊」
- [ ] 此時用剛註冊的 Email 與密碼到後台登入 → 登入失敗（尚未驗證不能登入）
- [ ] 點「重新寄送」→ 提示「已重新寄送驗證信，先前寄出的驗證連結已失效」
- [ ] 重新寄送後，使用「舊的」驗證連結 → 顯示「此驗證連結已失效，請使用最新一封驗證信中的連結」，不會建立帳號
- [ ] 點「Email 填錯了，重新註冊」→ 回到註冊頁；改用另一個 Email 重新送出 → 新 Email 收到驗證信
- [ ] 同一個 Email 重新註冊一次 → 前一次的驗證連結失效，只有最新一次有效

## 4. 完成驗證

- [ ] 點「模擬點擊驗證連結」→ 自動登入，提示「註冊完成，歡迎使用 Quickey」，並進入「歡迎使用 Quickey」設定頁
- [ ] 同一個驗證連結再開一次 → 顯示「此 Email 已完成驗證，請直接登入」，並提供「前往登入」
- [ ] 已登入其他帳號時開啟驗證連結 → 顯示「目前已登入為 xxx，請先登出」；點「登出並繼續驗證」後完成驗證
- [ ] 開啟不完整或亂打的驗證連結 → 顯示「驗證連結無效」，並提供「重新註冊」
- [ ] 驗證連結超過 24 小時才開啟 → 顯示「驗證連結已過期」，並提供「重新註冊」（需工程師協助調整時間測試）

## 5. 歡迎設定（首次進後台）

- [ ] 設定頁有「你的姓名」（必填）與「公司資訊」（公司名稱、統一編號，選填）
- [ ] 姓名空白按「開始使用」→ 顯示「請輸入姓名」，停留在設定頁
- [ ] 統一編號填了但不是 8 位數字 → 顯示「統一編號為 8 位數字」
- [ ] 只填姓名、公司資訊留空 → 可正常進入後台儀表板，並自動開始新手導覽
- [ ] 還沒完成設定就直接輸入其他後台網址（例如支出管理）→ 仍會回到設定頁
- [ ] 設定期間登出，再以該帳號登入 → 仍會先回到設定頁
- [ ] 完成設定後再開啟設定頁網址 → 直接進入儀表板，不會再看到設定頁
- [ ] 完成設定後右上角頭像顯示剛填的姓名
- [ ] 登出後，以註冊時的 Email 與密碼到後台登入 → 登入成功，直接進儀表板
- [ ] 以註冊的 Email 到前台登入 → 提示需至後台登入（管理員身分）

## 6. 公司資訊與邀請員工

- [ ] 個人設定頁有「公司資訊」區塊，顯示設定頁填過的公司名稱與統一編號，可修改後儲存
- [ ] 個人設定的統一編號填錯格式 → 顯示「統一編號為 8 位數字」，不會儲存
- [ ] 一般人員的個人設定看不到「公司資訊」區塊
- [ ] 公司名稱未填時，在人員管理按「邀請人員」→ 跳出「請先填寫公司名稱」提示，不會開啟邀請表單
- [ ] 在提示中按「前往填寫」→ 進入個人設定，游標直接停在公司名稱欄
- [ ] 按「取消」→ 提示關閉，停留在人員管理
- [ ] 填好公司名稱後再按「邀請人員」→ 正常開啟邀請表單
- [ ] 員工開啟邀請連結 → 頁面顯示「接受邀請並加入「公司名稱」」
- [ ] 測試帳號 admin@example.com 已預設公司名稱「Quickey 示範公司」，可直接邀請
