Button

對應 PrimeVue <Button>（顏色已由 presets/quickey.ts 對齊）。這頁定義 Quickey 裡每種按鈕的用途、狀態、尺寸與排列方式。

種類與狀態 — btn-primary / secondary / danger / text / success / info

種類與用途
預設
Hover
Focus（鍵盤）
Disabled
Primary.btn-primary每個畫面最主要的一個動作：送出、儲存、新增。一個區塊最多一個。
Secondary.btn-secondary次要動作：取消、返回、匯出。常與 Primary 並排。
Danger.btn-danger破壞性動作：駁回、作廢、刪除。外框樣式，執行前需確認。
Text.btn-text低強調動作：清除、查看全部、取消選取。
Success.btn-success明確的正向確認：核准。只在審核情境使用。
Success 外框.btn-outlined.btn-success同一列已有 Primary 時的次要正向動作。
Info.btn-info資訊類動作：標記已讀、查看說明。
Info 外框.btn-outlined.btn-infoInfo 的低強調版本。

所有按鈕同一高度（44px）、圓角 full、14px 600，外框統一 1.5px（實心按鈕用同色外框補齊，並排時不會高低不一）。危險動作用外框樣式而不是實心紅底，維持整體克制感。Disabled 一律改成 surface-soft 底＋muted-soft 字，不用降低透明度（跟 Input 的 disabled 規則一致，也避免跟 Loading 混淆）。鍵盤聚焦時外加 2px 主色外框，滑鼠點擊不出現。

尺寸 — btn / btn-sm

預設 44px
預設 44px・Secondary
小尺寸 44px btn-sm
小尺寸 44px・Secondary

預設與 btn-sm 都維持 44px 高；btn-sm 只收斂左右 padding，用在表格工具列、批次操作列這類密度高的地方。卡片標題列若需要和 18px 標題同列對齊，使用 36px 的 compact Select / period-picker，不用把文字按鈕縮到 36px。

圖示按鈕 — btn-icon-only

圖示＋文字
圖示＋文字・Secondary
只有圖示 44×44
只有圖示 44×44・btn-sm

圖示在文字左側、間距 6px，顏色跟隨文字（currentColor）。只有圖示的按鈕是 44×44 正方形；表格列動作需維持正圓。次要按鈕（有文字或只有圖示）外框一律用 primary-300（hover 加深到 primary-400），字與圖示維持主色；比實心主要按鈕輕，層級更分明。一定要加 aria-label，並配合 tooltip 說明用途。

組合 — btn-group / btn-split / is-loading

按鈕群組 btn-group
分裂按鈕 btn-split
Loading is-loading

按鈕群組用在互斥的切換（日/週/月），選中項用較深的 primary-600；分裂按鈕用在「一個主要動作＋其他相關動作」（儲存/另存草稿）。Loading 時按鈕停用、文字改成進行中的說法（處理中…），寬度不變。

排列 — button-bar

一般（Dialog/表單底部）
含危險動作

並排按鈕間距 8px、靠右對齊，主要動作放最右邊（Dialog、Drawer、表單底部都一樣）。有危險動作時放最左邊，跟其他按鈕拉開距離，避免誤按。
