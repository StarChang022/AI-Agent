primary-500（#00b39f）跟白字對比只有 2.64:1，未達 WCAG AA 4.5:1，所以按鈕實心底、選中分頁、連結文字一律走語意別名 primary-solid / primary-text（都等於 primary-700 #008072，對比 4.85:1，過關）。primary-500 保留給不疊文字對比的場合：icon、分頁下方指示條、圖表點狀標記。

文字色階

文字只用這 4 階，都是同一個藍灰色相、只差明度；不使用純黑 #000。PrimeVue 元件的預設文字色也指定為 ink／muted，避免出現第二套黑色。

色票用途白底對比
ink #2a3140標題、內文、欄位值、金額數字13:1
slate #485266表頭、側邊導覽、次要文字7.9:1
muted #646d80欄位名稱、說明文字、時間等輔助資訊（灰底卡片上 4.8:1）5.2:1
muted-soft #a6acb8placeholder、停用狀態；不可用於需要閱讀的內容2.3:1

背景與線條：canvas 白底、surface 灰底卡片、surface-soft 停用與 hover、hairline 邊框、hairline-strong hover 邊框與直線分隔 .sep。
