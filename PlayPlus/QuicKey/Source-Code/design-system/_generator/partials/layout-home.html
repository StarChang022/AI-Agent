KPI 列 — stat-card

  • 固定順序：核心金額（本月支出）→ 待處理數量（待簽核）→ 比率（預算使用率）→ 需要留意的金額（下次預計付款）。
  • 數字下方一行說明計算依據，右側放筆數或基準，例如「依費用發生日期　8 筆」「本月月預算　NT$ 2,900」。
  • 顏色跟語意走：品牌綠＝核心指標、琥珀＝待處理（同「簽核中」）、藍＝比率、紅＝需要留意。不為了好看換色。
  • 每張卡都可以點：本月支出 → 支出管理、待簽核 → 簽核、預算使用率 → 預算管理、下次預計付款 → 支出管理（待付款）。
  • 數字用 24px 粗體、tabular-nums；金額一律「NT$ 12,340」格式。

圖表列 — chart panel

  • 兩張圖共用期間選擇（period-picker）：右上角用 compact 尺寸（36px）和圖卡標題同一行；選項保持單純（本日/本週/本月/近三個月/近六個月/近一年/自訂日期區間）。實際起訖日固定顯示在展開選單底部的「目前區間」資訊列，不顯示在圖卡外。選自訂時在同一位置打開區間月曆（可選到日），按鈕仍顯示「自訂日期區間」；選到非預設期間時，「目前區間」資訊列右側提供小型「重設」操作。支出趨勢右上顯示「區間合計」金額；類別分佈的合計只放在圓環中央。預設：兩張圖皆為本月。
  • 支出趨勢：本日、本週、本月逐日加總，近三個月以上分月加總；自訂區間在 31 天以內時逐日加總，超過 31 天按月、頭尾月份只算區間內的日子。不要在圖卡標題下再顯示「依費用發生日逐日加總」這類說明。要有座標軸：Y 軸刻度以 k 為單位、4 格等距（實線基線＋虛線格線）；X 軸標月份，跨年時改「yy/m」。本月長條用深色，其餘用淺色。
  • 只畫單一數列，不放去年同期比較；右上角顯示「區間合計」。長條 hover 或鍵盤聚焦時顯示「月份＋金額＋筆數」。沒有資料時顯示空狀態說明。
  • 費用類別分佈：圓環中央顯示合計；下方清單依金額排序，列出每個類別的占比與金額，hover 任一邊會同步標示。
  • 類別顏色沿用前端的 16 色類別色盤，依類別排序循環套用，新增類別也一定有顏色。

清單列 — recent list

  • 首頁的清單只放最近 5 筆，右上角「查看全部」連到對應的列表頁（最近請款 → 請款記錄、待簽核 → 簽核）。清單內容與標題列的間距比一般 panel 稍緊；內嵌表格上方保留 1px 分隔線。待處理清單的金額固定靠右、不可換行，左側描述過長時截斷。
  • 點任一列開明細 Drawer，可以直接在首頁處理（核准、駁回），不必跳頁。
  • 沒有資料時顯示一行說明（例如「目前沒有待簽核的請款」），不留空白。
