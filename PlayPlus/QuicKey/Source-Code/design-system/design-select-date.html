選項多的選單（例如類別管理的會計科目）加 PrimeVue filter：面板頂端固定一個搜尋框，打開就自動聚焦，可輸入代碼或名稱即時篩選，沒有符合時顯示「找不到符合的選項」；↓ 從搜尋框移到第一個選項，Enter 直接選第一個符合的選項。

對應 PrimeVue <Select>，實作一律用 PrimeVue，不用原生 <select>（原生選單的展開樣式由作業系統決定，無法套用 tokens）。觸發框同一般 Input：高 44px、hairline 1.5px 外框、圓角 16px，展開或 focus 時主色外框＋光暈；右側箭頭展開時轉 180°。選單面板白底、圓角 16px、shadow-float，選項 hover 用 surface-soft，已選項目用 primary-50 底＋primary-text 粗體（跟 MultiSelect、AutoComplete 一致）。鍵盤：↑↓ 移動、Enter 選取、Esc 關閉。選項超過 8 個時開啟 PrimeVue 的 filter 搜尋。

尺寸分兩級：一般 Select / DatePicker 高 44px，用在表單與篩選列；卡片標題列右上角的 compact 篩選高 36px、15px 字、左右內距 12px，用在儀表板圖卡這類要和 18px 標題同列對齊的地方。需要自訂區間時改用下方的「期間選擇」。

SelectButton（分段切換） — segmented

兩個選項
三個選項

對應 PrimeVue <SelectButton>（加 :allow-empty="false"，永遠有一個被選中）。用在 2～4 個互斥選項、而且切換的是「整個檢視」的地方，例如預算管理的月預算／年預算：選項全部攤開，點一下就切換。選項超過 4 個，或只是篩選條件時，改用 Select。

外觀：不包灰底軌道，選項各自是全圓角膠囊（高 40px、16px 字，與按鈕同字級，置於 44px 列高中）。選中那顆 primary-50 淡綠底＋primary-text 600；未選中只有文字 muted，hover 才出現 surface-soft 淺灰底。不用主色實心，避免跟主要按鈕搶視覺。列表頁的狀態分頁也用同一個樣式（TabBar variant="segmented"），選項多時也不會顯得被框住。

切換時淡綠底會從原本的選項滑到新選項（0.25s，系統設定「減少動態效果」時直接跳）。前端用 SlideSelectButton（包 PrimeVue SelectButton）與膠囊式 TabBar，共用 useSlideIndicator。

DatePicker（日期選擇） — date-picker

對應 PrimeVue <DatePicker>：日期區間用 selection-mode="range"，月份區間加 view="month"。不要用原生 <input type="date">（各瀏覽器外觀不同，也無法套用 tokens）。顯示格式 yyyy/mm/dd，區間用「–」連接。月曆面板：今天用 primary-text 粗體加淺框；已選日期 primary-solid 實心圓；區間起訖實心、中間 primary-50 底；選區間時第一次點起日、第二次點迄日，未完成前底部提示「請選擇結束日期」；底部固定「清除/今天」。鍵盤：方向鍵移動日期、PageUp/PageDown 切換月份、Enter 選取、Esc 關閉。

只需要選到月份或年份時（例如預算管理的期間），用 view="month"（格式 yy 年 m 月）或 view="year"（格式 yy 年），面板直接列出 12 個月或 10 個年份，點一下就跳到該期間；兩側可保留上一期/下一期按鈕做相鄰切換。這種放在工具列、當「目前期間」標示用的選擇器採簡約樣式：不顯示日曆 icon，平常看起來是置中的粗體文字，hover 才出現淡框、開啟時主色框。

圖表卡片標題列右上角的期間篩選，把「預設期間 Select」和「自訂區間 DatePicker」合成一個控制項，不另外多一個輸入框，並和圖卡標題同一行。period-picker 有 md（40px）與 sm（36px）兩種尺寸；儀表板圖卡用 sm 對齊 18px 標題。展開後列出預設期間（本日、本週、本月、近三個月、近六個月、近一年），選項本身保持單純，不在每個選項右側顯示起訖日；最後一項是「自訂日期區間」（右側 › 表示會進入月曆，不用「…」），且上方不加分隔線。選它會在同一位置打開區間月曆（可選到日），選完後按鈕仍顯示「自訂日期區間」。實際起訖日固定顯示在展開選單底部的「目前區間」資訊列，不顯示在圖卡外；選到非預設期間時，「目前區間」資訊列右側提供小型「重設」操作。

實作：PrimeVue <Select> 的 value 插槽顯示期間文字，選到自訂時用 <DatePicker selection-mode="range" inline> 放在 <Popover> 裡並對齊同一個按鈕；按 Esc 或選完都把焦點還給按鈕。
