## 1. 股市統計優勢的基石：記憶性價格結構與正期望值識別

### 1.1 導論：為何多數股市參與者最終走向本金歸零？
在現代股票市場與量化資產配置體系中，識別並嚴格驗證「真實的統計優勢（Statistical Edge）」是確保資本長期安全與實現對數複利增長的戰略起點。多數散戶投資人與未受過系統化訓練的交易員，習慣依賴主觀直覺、消息面聽聞或未經統計驗證的技術指標進行買賣。然而，在高度競爭且充滿隨機雜訊的股票市場中，若交易系統缺乏真實的正期望值，任何頻繁換股、當沖博弈與融資槓桿操作，本質上都只是在加速支付交易摩擦成本（手續費、證交稅與買賣價差滑價）並消耗資本。盲目相信未經檢驗的直覺，極易因「波動拖累（Volatility Drag）」而引發本金永久性重創的毀滅性風險。

要建構具備極限防禦力的股市交易體系，首要任務是釐清市場不同階段底層的機率分佈結構。從隨機過程與市場微觀結構的角度來看，股市交易環境可分為「無記憶性雜訊區」與「記憶性結構區」兩類：

* **無記憶性雜訊區（Random Walk Noise Regime）**：
    當大盤或個股處於無量能配合、無基本面催化的隨機震盪期，其短期價格跳動近似於「獨立同分佈（i.i.d.）」的隨機漫步（如同美式輪盤）。在扣除交易稅費與滑價成本（設單筆來回摩擦成本率為 $c_{\text{fric}}$）後，在雜訊區進行頻繁交易的單次期望值恆為負值：
    $$E[X] = (b_{\text{raw}} \times p) - (a_{\text{raw}} \times q) - c_{\text{fric}} < 0$$
    更致命的是，許多股市交易員在虧損後習慣採用「向下攤平（Averaging Down）」策略——本質上就是賭場中的「馬丁格爾加倍投注法（Martingale System）」。在負期望值或趨勢反轉的環境下，向下攤平只是將多次小額停損掩蓋起來，轉化為一次低機率但足以讓帳戶斷頭歸零的極端尾部事件，完全無法扭轉數學期望值為負的本質。

* **記憶性結構區（Memory Structure & Price Dislocation）**：
    相對地，股票市場在特定條件下會展現出強烈的「記憶性結構」（類似 21 點牌局中已發出卡牌改變剩餘牌組的條件機率）。這種記憶性源於**機構法人建倉的時間延續性、投資人行為偏誤（處置效應與錨定效應）、籌碼供需失衡以及波動率聚集效應（Volatility Clustering）**。當個股經歷長期籌碼沉澱（浮額清洗完畢）並伴隨催化劑放量突破時，條件勝率（$p$）與潛在盈虧比（$B$）將暫時且顯著地轉向有利於交易者的一方。

| 系統維度 | 股市無記憶性雜訊區（例：無序盤整期頻繁當沖） | 股市記憶性結構區（例：波段趨勢突破 / 定價偏離套利） |
| :--- | :--- | :--- |
| **機率分佈特性** | 近似獨立同分佈（i.i.d.）隨機漫步，多空機率接近 50/50 | 具狀態轉移記憶性（Markov 過程），籌碼與動能改變條件機率 |
| **部位策略效用** | 向下攤平（馬丁格爾）僅重排虧損分佈，終將導致重倉套牢或斷頭 | 可透過環境濾網與型態追蹤，識別正期望值（Alpha）爆發窗口 |
| **長期期望值 ($E[R]$)** | 恆為負值（受手續費、交易稅與滑價持續侵蝕） | 經由條件篩選與停損截斷，可建構顯著正期望值（$+0.25R \sim +0.80R$） |
| **實戰交易啟示** | 無統計優勢時應保持空手（Cash is a Position），拒絕過度交易 | 耐心等待大盤順風、籌碼沉澱與型態突破共振時，方可動用風險預算 |

### 1.2 條件機率空間：從索普算牌邏輯到股市「環境濾網與型態識別」
量化先驅愛德華·索普（Edward Thorp）在 21 點研究中透過 IBM 704 主機進行數百萬次模擬，證明了**「當牌組中的四張 5 號小牌被剔除時，玩家的統計優勢將從 $-0.6\%$ 逆轉為 $+3.13\%$ 的正期望值」**。其底層邏輯在於：小牌是莊家在 12～16 點脆弱區安全補牌的盟友，而大牌（10、J、Q、K、A）則是讓莊家爆牌、且讓玩家獲得 1.5 倍 Blackjack 溢價的不對稱武器。

將索普的算牌哲學映射至股票市場，即可得出**波段交易與量化選股的核心認知**：

```
+-----------------------------------------------------------------------+
|                【核心認知：股市「算牌策略」的實戰本質】                |
|                                                                       |
| 股市交易既非預測明天每一根 K 線的精確漲跌，亦非盲目死守單一技術指標。 |
| 交易的本質是：實時評估市場的「條件機率空間（Conditional Probability   |
| Space）」，在供給枯竭、大盤順風、盈虧比極度不對稱的窗口下注。         |
+-----------------------------------------------------------------------+
```

在股市實戰中，我們透過以下三個維度來計算市場的「累計計數（Running Count）」與「真實計數（True Count, $TC$）」：

1. **大盤位階與市場寬度（Market Breadth）＝ 牌組的大牌密度**：
    當大盤指數位於均線多頭排列、中小型股（櫃買指數）與法人籌碼同步擴張時，相當於 21 點牌組中剩餘的大牌密度極高（$TC > +2$）。此時順勢做多波段突破的條件勝率（$p$）與平均獲利幅度（$b$）大幅提升；反之，當大盤處於空頭排列或流動性緊縮時，做多勝率急劇衰退，強行進場等同於在負期望值牌局中頂風作案。
2. **籌碼沉澱與波動率壓縮（如 VCP 型態 / 量縮整理）＝ 剔除莊家的「5 號牌」**：
    在 21 點中，5 號牌會幫助莊家化解危機；在股市中，「上方套牢賣壓與短線融資浮額」就是阻礙股價上漲的 5 號牌。當一檔股票經歷數週至數月的波動率收縮（價格振幅遞減、成交量極度萎縮、融資退場而法人吸籌），代表場內潛在賣壓（供給）已被徹底清洗剔除。此時只要有邊際買盤（需求）點火突破關鍵樞紐點（Pivot Point），股價便會因上方無阻力而產生非線性的波段噴出。
3. **停損截斷與移動停利 ＝ 玩家的「自由選擇權與 1.5 倍溢價」**：
    在 21 點中，莊家必須遵守 16 點補牌、17 點停牌的死規則，而玩家擁有加倍下注（Double Down）、分牌與拿到 Blackjack 獲賠 1.5 倍的不對稱權利。在股市中，散戶與被動基金往往受制於情緒或固定章程，而專業交易員則擁有**「隨時小額停損離場（截斷左尾）」**與**「順勢移動停利抱牢波段（延伸右尾，創造 $2.5:1$ 甚至 $5:1$ 的盈虧比溢價）」**的策略選擇權。

### 1.3 股市 Alpha 的兩大收割範式與基礎期望值數學模型

#### 範式一：方向性波段交易（Directional Swing Trading —— 創造正偏態損益）
波段交易承認單筆方向預測必然伴隨雜訊，因此不追求極端高勝率，而是追求**「條件勝率提升 ＋ 損益不對稱性（Positive Asymmetry）」**。
* **單筆交易摩擦成本率（$c_{\text{fric}}$）精確定義**：
    設買進價為 $P_{\text{entry}}$、最小跳動單位為 $\text{Tick}(P_{\text{entry}})$、單邊法定手續費率 $r_{\text{comm}} = 0.1425\%$、券商手續費折扣係數為 $d_{\text{disc}}$（預設為 $1.0$ 無折扣保守值；若為 6 折則代入 $0.6$）、賣出證交稅率 $r_{\text{tax}} = 0.30\%$，進出各預估 1 個 Tick 滑價，則單筆來回摩擦成本率為：
    $$c_{\text{fric}} = (2 \times r_{\text{comm}} \times d_{\text{disc}}) + r_{\text{tax}} + \frac{2 \times \text{Tick}(P_{\text{entry}})}{P_{\text{entry}}}$$
    *(註：在標準無特殊滑價情境下，台股普通股預設採用保守常數基準 $c_{\text{fric}} = 0.00585$，即 $0.585\%$)*。
* **單位風險期望值公式（以單位風險 $1R$ 表示）**：
    設由第 2 章引擎計算得出之條件勝率為 $p$，敗率為 $q = 1 - p$，計入摩擦成本後的實質停損幅度為 $a$，實質目標獲利幅度為 $b$，淨盈虧比為 $B = \frac{b}{a}$。則每承擔 1 單位初始停損風險（$1R$）的數學期望值為：
    $$E[R] = (p \times B) - (q \times 1) = (p \times B) - (1 - p)$$
    換算為單筆投入資金之算術期望淨報酬率為：
    $$E[X] = (p \times b) - (q \times a) = a \times E[R]$$
    例如：條件勝率 $p = 45.0\%$，敗率 $q = 55.0\%$，實質停損幅度 $a = 5.0\%$，波段目標淨獲利幅度 $b = 12.5\%$，實現盈虧比 $B = \frac{12.5\%}{5.0\%} = 2.50$。其單筆交易期望值為：
    $$E[R] = (0.45 \times 2.50) - (0.55 \times 1) = +1.125R - 0.550R = +0.575R$$
    這意味著每冒 1 元的停損風險，長期平均可創造 $0.575$ 元的淨統計優勢。

#### 範式二：結構性定價偏離與動態對沖（Dynamic Hedging —— 消除方向性 Beta）
源於索普在《打敗市場》（*Beat the Market*）中開創的權證與可轉債套利邏輯：**「不預測股票漲跌方向，僅收割市場定價偏離的結構性溢價。」**
* 當可轉換公司債（CB）、認股權證或雙重上市股票出現顯著偏離理論價值的折溢價時，同時建立多空對沖部位，配比取決於衍生品價格 $C$ 對標的股價 $S$ 的偏微分（Delta 避險比率）：
    $$\Delta = \frac{\partial C}{\partial S}$$
* 無論大盤暴漲或暴跌，多空部位的損益互相抵消（組合保持 Delta 中性），隨時間推進或價差收斂，將結構性溢價轉化為低波動 Alpha。

## 2. 導航與訊號引擎：條件勝率 ($p$) 與盈虧比 ($B$) 的精確數學模型

本章為整套交易體系的**「導航與引擎核心」**。為徹底消除人為主觀臆測，確保每次計算皆具備完全相同的勝率與盈虧比基準，以下定義從「大盤與個股客觀數據」推導至「索普真實計數 $TC$」、「條件勝率 $p$」與「淨盈虧比 $B$」的唯一確定數學算式。

> **【符號與資料讀取規範】**：
> 1. **指標函數（Indicator Function）$\mathbb{I}(\text{條件})$**：當括號內之數學不等式成立時，$\mathbb{I}(\cdot) = 1$；不成立時，$\mathbb{I}(\cdot) = 0$。
> 2. **時間下標與區間極值定義**：下標 $t$ 代表最新一個交易日（T 日收盤），$t-k$ 代表往前第 $k$ 個交易日。包含當日之近 $k$ 日最高／最低價定義為 $H_{k,t} = \max_{0 \le i < k} H_{t-i}$、$L_{k,t} = \min_{0 \le i < k} L_{t-i}$；**不包含當日**（即前一日 $t-1$ 起算往前 $k$ 日）之區間最高／最低價定義為 $H_{k,t-1} = \max_{1 \le i \le k} H_{t-i}$、$L_{k,t-1} = \min_{1 \le i \le k} L_{t-i}$。
> 3. **單位與缺值防呆規範**：
>    * 台股日 K 檔案中，成交量、均量（$\text{MV}_{5\sim 20,t}$）、三大法人買賣超與融資融券餘額之數值單位均以**「張（千股）」**計。
>    * 讀取融資餘額 $M_t$ 時，若當日尚未結算而顯示為 `0`，自動向前選取最近一筆 $M_{t^*} > 0$ 之有效交易日 $t^*$，並以往前 5 個有效交易日 $t^*-5$ 計算 $\Delta M_5 = M_{t^*} - M_{t^*-5}$。
>    * 讀取季財報時，若最新季度欄位為 `-`（尚未公告），自動向後順延選取**第一筆已公告有效季度**作為最新季 $q$，並往前推 4 個季度作為去年同季 $q-4$。

### 2.1 導航系統：大盤環境計數（Market Regime Score, $S_{\text{mkt}}$）
以台灣加權指數（`TAIEX`）為主、櫃買指數（`TPEx`）為輔，讀取 T 日收盤價 $I_t$、20 日均線 $\text{MA}_{20,t}$、60 日均線 $\text{MA}_{60,t}$、240 日均線 $\text{MA}_{240,t}$ 與三大法人合計買賣超 $F_{I,t}$，依序計算四項環境子分數：

1. **大盤均線位階分（$m_1 \in \{-2, 0, +2\}$）**：
    $$m_1 = \begin{cases} +2, & \text{若 } I_t > \text{MA}_{20,t} \text{ 且 } I_t > \text{MA}_{60,t} \\ -2, & \text{若 } I_t < \text{MA}_{20,t} \text{ 且 } I_t < \text{MA}_{60,t} \\ 0, & \text{其他（指數夾於月季線之間）} \end{cases}$$
2. **大盤均線斜率動能分（$m_2 \in \{-1, 0, +1, +2\}$）**：
    $$m_2 = \mathbb{I}(\text{MA}_{20,t} \ge \text{MA}_{20,t-1}) + \mathbb{I}(\text{MA}_{60,t} \ge \text{MA}_{60,t-1}) - \mathbb{I}(\text{MA}_{20,t} < \text{MA}_{20,t-1} \land \text{MA}_{60,t} < \text{MA}_{60,t-1})$$
3. **年線長牛保護分（$m_3 \in \{-1, +1\}$）**：
    $$m_3 = \begin{cases} +1, & \text{若 } I_t > \text{MA}_{240,t} \\ -1, & \text{若 } I_t \le \text{MA}_{240,t} \end{cases}$$
4. **市場寬度（櫃買共振）與法人資金流向分（$m_4 \in \{-1, 0, +1\}$）**：
    $$m_4 = \mathbb{I}\!\left(\sum_{j=0}^{2} F_{I,t-j} > 0\right) + \mathbb{I}\!\left(I_{\text{TPEx},t} > \text{MA}_{20,\text{TPEx},t}\right) - 1$$

將四項相加，得出**大盤環境累計計數（$S_{\text{mkt}}$）**：
$$S_{\text{mkt}} = m_1 + m_2 + m_3 + m_4 \quad \in [-5, +6]$$

#### 大盤三態判定與風險預算調節乘數（$\kappa_{\text{regime}}$）
根據 $S_{\text{mkt}}$ 數值，系統自動鎖定當前市場狀態與帳戶總在險資金上限（Max Portfolio Heat, $H_{\max}$）：

| 大盤導航狀態 | 數學判定區間 | 環境調節乘數 ($\kappa_{\text{regime}}$) | 帳戶總在險資金上限 ($H_{\max}$) | 戰略導航指令 |
| :--- | :--- | :---: | :---: | :--- |
| **🟢 順風攻擊期 (Risk-On)** | $S_{\text{mkt}} \ge +3$ | **$1.00$** | **$6.0\%$** | 大牌密度高，全額動用分數凱利風險預算積極做多 |
| **🟡 震盪盤整期 (Neutral)** | $0 \le S_{\text{mkt}} \le +2$ | **$0.50$** | **$3.0\%$** | 勝率結構中性，單筆凱利風險與總曝險強制減半 |
| **🔴 逆風防禦期 (Risk-Off)** | $S_{\text{mkt}} < 0$ | **$0.00$** | **$0.0\%$** | 期望值轉負，全面禁止開立新多單，既有持股收緊防守 |

### 2.2 選股與計數引擎：個股結構評分（$S_{\text{stock}}$）與索普真實計數（$TC$）
針對任一目標個股，讀取其日 K 數據（開盤 $O_t$、最高 $H_t$、最低 $L_t$、收盤 $C_t$、成交量 $V_t$、均線 $\text{MA}_{5\sim 240,t}$、均量 $\text{MV}_{5\sim 20,t}$、外資 $F_{\text{foreign},t}$、投信 $F_{\text{trust},t}$、法人合計 $F_{\text{inst},t}$、融資餘額 $M_t$）、月營收數據（年增率 $g_{\text{rev},t}$）與季財報數據（單季 $\text{EPS}_q$、營業利益率 $\text{OPM}_q$），以 **100 分制**精確核算四大維度分數：

#### 維度一：趨勢排列與位階結構分（$S_{\text{trend}} \in [0, 30]$）
設近 240 日最高價為 $H_{240,t} = \max_{0 \le i < 240} H_{t-i}$：
1. **短中長均線多頭排列（$0 \sim 10$ 分）**：
    $$s_{t1} = 10 \cdot \mathbb{I}(C_t > \text{MA}_{20,t} \land \text{MA}_{20,t} > \text{MA}_{60,t}) + 5 \cdot \mathbb{I}(C_t > \text{MA}_{20,t} \land \text{MA}_{20,t} \le \text{MA}_{60,t} \land C_t > \text{MA}_{60,t})$$
2. **長線生命線支撐（$0 \sim 8$ 分）**：
    $$s_{t2} = 8 \cdot \mathbb{I}(C_t > \text{MA}_{240,t} \land \text{MA}_{60,t} > \text{MA}_{240,t}) + 4 \cdot \mathbb{I}(C_t > \text{MA}_{240,t} \land \text{MA}_{60,t} \le \text{MA}_{240,t})$$
3. **均線助漲斜率（$0 \sim 6$ 分）**：
    $$s_{t3} = 3 \cdot \mathbb{I}(\text{MA}_{10,t} \ge \text{MA}_{10,t-1}) + 3 \cdot \mathbb{I}(\text{MA}_{20,t} \ge \text{MA}_{20,t-1})$$
4. **強勢位階且未過度乖離（$0 \sim 6$ 分）**：
    股價距一年高點在 $25\%$ 以內（上方套牢輕），且與季線正乖離率 $\text{BIAS}_{60,t} = \frac{C_t - \text{MA}_{60,t}}{\text{MA}_{60,t}} \le 30\%$（未進入末升段超買區）：
    $$s_{t4} = 6 \cdot \mathbb{I}\!\left(C_t \ge 0.75 \cdot H_{240,t} \land 0 \le \frac{C_t - \text{MA}_{60,t}}{\text{MA}_{60,t}} \le 0.30\right)$$
$$S_{\text{trend}} = s_{t1} + s_{t2} + s_{t3} + s_{t4}$$

#### 維度二：波動率收縮與量價共振分（$S_{\text{vol}} \in [0, 25]$，對應「剔除 5 號牌」）
定義近 5 日對近 20 日之**價格振幅壓縮比（Compression Ratio, $\rho_{\text{range}}$）**（若 T 日為帶量突破前 10 日高點之點火日，自動取突破前一日 $t-1$ 之振幅比以真實反映突破前收縮品質）：
$$\rho_{\text{range}} = \begin{cases} \dfrac{H_{5,t-1} - L_{5,t-1}}{H_{20,t-1} - L_{20,t-1} + 10^{-6}}, & \text{若 } C_t > H_{10,t-1} \land V_t \ge 1.30 \cdot \text{MV}_{20,t} \\[8pt] \dfrac{H_{5,t} - L_{5,t}}{H_{20,t} - L_{20,t} + 10^{-6}}, & \text{其他情形} \end{cases}$$
1. **波動收縮緊湊度（$0 \sim 15$ 分）**：
    $$s_{v1} = \begin{cases} 15, & \text{若 } \rho_{\text{range}} \le 0.45 \text{（極度緊湊收縮）} \\ 10, & \text{若 } 0.45 < \rho_{\text{range}} \le 0.65 \text{（標準波動收斂）} \\ 5, & \text{若 } 0.65 < \rho_{\text{range}} \le 0.80 \text{（溫和整理）} \\ 0, & \text{若 } \rho_{\text{range}} > 0.80 \text{（波動發散未收斂）} \end{cases}$$
2. **量價共振訊號（$0 \sim 10$ 分）**：
    $$s_{v2} = \begin{cases} 10, & \text{【點火突破】} C_t > H_{10,t-1} \land V_t \ge 1.30 \cdot \text{MV}_{20,t} \land \frac{C_t - L_t}{H_t - L_t + 10^{-6}} \ge 0.60 \\ 10, & \text{【量縮洗盤止跌】} V_t \le 0.65 \cdot \text{MV}_{20,t} \land C_t \ge \text{MA}_{20,t} \land (C_t \ge O_t \lor \frac{\min(O_t,C_t)-L_t}{H_t-L_t+10^{-6}} \ge 0.50) \\ 5, & \text{【溫和守穩】} C_t \ge \text{MA}_{20,t} \land \text{未出現價跌量增（即非 } C_t < C_{t-1} \land V_t > 1.20 \cdot \text{MV}_{20,t}\text{）} \\ 0, & \text{【量價背離／出貨】其他情形} \end{cases}$$
$$S_{\text{vol}} = s_{v1} + s_{v2}$$

#### 維度三：法人籌碼認養與融資清洗分（$S_{\text{chip}} \in [0, 25]$）
設近 5 日法人累計買賣超為 $F_{5} = \sum_{i=0}^{4} F_{\text{inst},t-i}$、近 3 日投信累計買賣超為 $F_{\text{trust},3} = \sum_{i=0}^{2} F_{\text{trust},t-i}$、近 3 日外資累計買賣超為 $F_{\text{foreign},3} = \sum_{i=0}^{2} F_{\text{foreign},t-i}$。
取最新一筆融資餘額非零之有效交易日 $t^*$，計算近 5 日融資餘額變化量 $\Delta M_5 = M_{t^*} - M_{t^*-5}$：
1. **三大法人買盤動能（$0 \sim 15$ 分）**：
    $$s_{c1} = 8 \cdot \mathbb{I}(F_{5} > 0) + 4 \cdot \mathbb{I}(F_{\text{trust},3} > 0) + 3 \cdot \mathbb{I}(F_{\text{foreign},3} > 0)$$
2. **籌碼沉澱度（資減法人買 ＝ 籌碼由散戶流向大戶，$0 \sim 10$ 分）**：
    $$s_{c2} = \begin{cases} 10, & \text{若 } \Delta M_5 \le 0 \text{ 且 } F_{5} > 0 \text{（標準資減法人買）} \\ 6, & \text{若 } \Delta M_5 \le 0 \text{ 且 } F_{5} \le 0 \text{（浮額自然退場）} \\ 5, & \text{若 } \Delta M_5 > 0 \text{ 且 } F_{5} > 0 \text{（法人與人氣同步進駐）} \\ 0, & \text{若 } \Delta M_5 > 0 \text{ 且 } F_{5} \le 0 \text{（法人倒貨、散戶融資接刀）} \end{cases}$$
$$S_{\text{chip}} = s_{c1} + s_{c2}$$

#### 維度四：基本面催化動能分（$S_{\text{fund}} \in [0, 20]$）
讀取最新月份營收年增率 $g_{\text{rev},t}$ 與上月營收年增率 $g_{\text{rev},t-1}$；讀取最新已公布有效季度 $\text{EPS}_q$、去年同季 $\text{EPS}_{q-4}$、最新營業利益率 $\text{OPM}_q$ 與去年同季 $\text{OPM}_{q-4}$：
1. **月營收成長與加速度（$0 \sim 8$ 分）**：
    $$s_{f1} = 5 \cdot \mathbb{I}(g_{\text{rev},t} \ge 15.0\%) + 3 \cdot \mathbb{I}(g_{\text{rev},t} - g_{\text{rev},t-1} \ge 5.0\% \lor (g_{\text{rev},t} > 0 \land g_{\text{rev},t-1} < 0))$$
2. **季盈餘成長動能（$0 \sim 6$ 分）**：
    定義單季盈餘年增率 $\text{YoY}_{\text{EPS}} = \frac{\text{EPS}_q - \text{EPS}_{q-4}}{|\text{EPS}_{q-4}| + 10^{-6}}$：
    $$s_{f2} = 6 \cdot \mathbb{I}\big(\text{EPS}_q > 0 \land (\text{YoY}_{\text{EPS}} \ge 15.0\% \lor \text{EPS}_{q-4} \le 0)\big) + 3 \cdot \mathbb{I}\big(\text{EPS}_q > 0 \land \text{EPS}_{q-4} > 0 \land 0\% \le \text{YoY}_{\text{EPS}} < 15.0\%\big)$$
3. **本業獲利能力擴張（$0 \sim 6$ 分）**：
    $$s_{f3} = \begin{cases} 6 \cdot \mathbb{I}(\text{OPM}_q > \text{OPM}_{q-4} \land \text{OPM}_q > 0) + 3 \cdot \mathbb{I}(\text{OPM}_q \le \text{OPM}_{q-4} \land \text{OPM}_q \ge 10.0\%), & \text{若 } \text{OPM}_q \text{ 有數值（一般產業）} \\ 6 \cdot \mathbb{I}(\text{EPS}_q \ge \text{EPS}_{q-1} \land \text{EPS}_q > 0) + 3 \cdot \mathbb{I}(0 < \text{EPS}_q < \text{EPS}_{q-1}), & \text{若 } \text{OPM}_q \text{ 為 }\text{`-`}\text{（如金融保險業 28xx）} \end{cases}$$
$$S_{\text{fund}} = s_{f1} + s_{f2} + s_{f3}$$
*(註：若評估標的為指數型 ETF 如 `0050` 無月營收與季財報欄位，則固定取中性基準值 $S_{\text{fund}} = 12$)*。

### 2.3 條件勝率（$p$）的唯一確定轉換公式與嚴格優先判定樹

1. **計算個股結構總分（$S_{\text{stock}} \in [0, 100]$）**：
    $$S_{\text{stock}} = S_{\text{trend}} + S_{\text{vol}} + S_{\text{chip}} + S_{\text{fund}}$$
2. **換算索普真實計數（Thorp True Count, $TC \in [-7.5, +8.0]$）**：
    將個股結構總分（以 $50$ 分為中性基準，每 $10$ 分為 $1$ 個計數單位）與大盤環境計數 $S_{\text{mkt}}$（權重 $0.5$）線性合成：
    $$TC = \frac{S_{\text{stock}} - 50}{10} + (0.5 \times S_{\text{mkt}})$$
3. **計算條件勝率（$p$）與條件敗率（$q$）**：
    為確保全市場任何個股在任何交易日皆有**唯一且互斥（Mutually Exclusive & Collectively Exhaustive）**的策略型態歸類與基準勝率 $p_0$，系統嚴格依下表之**「由上而下優先級順序（Priority 1 $\rightarrow$ Priority 5）」**進行唯一歸類，每 $+1.0$ 單位的真實計數 $TC$ 賦予 $+2.5\%$（即 $\gamma = 0.025$）的條件勝率邊際加成，並透過上下界截斷函數鎖定於 $[p_{\min}, p_{\max}]$：
    $$p_{\text{model}}(TC) = \min\Big(p_{\max}, \; \max\big(p_{\min}, \; p_0 + 0.025 \times TC\big)\Big)$$

| 判定優先級 | 策略型態代碼與名稱 | 嚴格互斥識別條件（由上而下依序檢驗，符合即鎖定） | 基準勝率 ($p_0$) | 勝率上下界 ($[p_{\min}, p_{\max}]$) |
| :---: | :--- | :--- | :---: | :---: |
| **優先級 1** | **Setup D：可轉債/統計配對套利**<br>*(多空 Delta 中性對沖)* | 明確指定為衍生品與現股配對交易，同時建立 $\Delta = \partial C / \partial S$ 中性部位 | **$65.0\%$**<br>*(0.650)* | $[50.0\%, 78.0\%]$ |
| **優先級 2** | **Setup C：財報/事件催化動能**<br>*(跳空缺口或爆量長紅延續)* | 非 Setup D，且 T 日向上跳空（$L_t > H_{t-1}$）或單日漲幅 $\frac{C_t - C_{t-1}}{C_{t-1}} \ge 4.0\%$，同時 $V_t \ge 1.5 \cdot \text{MV}_{20,t}$ 且 $(s_{f1} \ge 5 \lor s_{f2} = 6)$ | **$45.0\%$**<br>*(0.450)* | $[30.0\%, 62.0\%]$ |
| **優先級 3** | **Setup A：順勢動能突破波段**<br>*(VCP / 樞紐創高突破)* | 非 Setup D/C，且 $C_t > \text{MA}_{20,t} \land C_t > \text{MA}_{60,t}$，同時創近 10 日新高（$C_t \ge H_{10,t-1}$）或距 20 日高點 $\le 3.0\%$（$\frac{H_{20,t}-C_t}{H_{20,t}} \le 0.03$） | **$42.0\%$**<br>*(0.420)* | $[28.0\%, 60.0\%]$ |
| **優先級 4** | **Setup B：強勢股拉回支撐波段**<br>*(MA10 / MA20 量縮回測買點)* | 非 Setup D/C/A，且長線趨勢向上（$C_t > \text{MA}_{60,t}$），股價處於自高點拉回測試支撐區（$C_t < 0.97 \cdot H_{20,t}$） | **$50.0\%$**<br>*(0.500)* | $[35.0\%, 65.0\%]$ |
| **優先級 5**<br>*(保底歸類)* | **Setup N：逆勢／無序整理區**<br>*(未滿足多頭結構之標的)* | 凡不滿足上述優先級 1～4 之所有其他標的（如 $C_t \le \text{MA}_{60,t}$ 中期空頭或弱勢箱型） | **$35.0\%$**<br>*(0.350)* | $[20.0\%, 50.0\%]$ |

> **【貝氏實盤樣本校準公式（Bayesian Calibration，選用）】**：
> 若系統已累積該型態 $n$ 筆實盤獨立交易紀錄（其中獲勝 $k$ 筆），則以先驗權重 $N_0 = 20$ 將模型條件勝率 $p_{\text{model}}(TC)$ 與實盤勝率合成，得出最終勝率 $p$：
> $$p = \frac{20 \cdot p_{\text{model}}(TC) + k}{20 + n}, \qquad q = 1 - p$$
> 當無額外歷史交易統計輸入時（即 $n = 0, k = 0$），**$p \equiv p_{\text{model}}(TC) = \text{clip}(p_0 + 0.025 \times TC, \; p_{\min}, \; p_{\max})$**，確保每次單獨針對個股數據進行評估時，勝率計算結果 100% 唯一且可重現。

### 2.4 價格定錨引擎：進場價 ($P_{\text{entry}}$)、停損價 ($P_{\text{stop}}$)、目標價 ($P_{\text{target}}$) 與盈虧比 ($B$)

為確保凱利公式分母中的停損幅度 $a$ 與分子中的盈虧比 $B = \frac{b}{a}$ 完全客觀、不因人而異，必須先以 14 日平均真實波幅（$\text{ATR}_{14,t}$）與 K 線結構定錨三個關鍵價位。

#### 1. 真實波幅 $\text{ATR}_{14,t}$ 與台股最小跳動單位 $\text{Tick}(P)$
* **當日真實波幅（True Range, $\text{TR}_t$）與 14 日均值**：
    $$\text{TR}_t = \max\Big(H_t - L_t, \; |H_t - C_{t-1}|, \; |L_t - C_{t-1}|\Big), \qquad \text{ATR}_{14,t} = \frac{1}{14}\sum_{i=0}^{13} \text{TR}_{t-i}$$
* **台股法定最小跳動單位函數 $\text{Tick}(P)$**：
    $$\text{Tick}(P) = \begin{cases} 0.01, & P < 10 \\ 0.05, & 10 \le P < 50 \\ 0.10, & 50 \le P < 100 \\ 0.50, & 100 \le P < 500 \\ 1.00, & 500 \le P < 1000 \\ 5.00, & P \ge 1000 \end{cases}$$
    設 $\text{RoundTick}_{\downarrow}(P)$ 為依價格級距向下取整至合法報價單位，$\text{RoundTick}_{\uparrow}(P)$ 為向上取整至合法報價單位。

#### 2. 進場基準價（$P_{\text{entry}}$）與原始結構停損價（$P_{\text{stop, raw}}$）
* **進場基準價 $P_{\text{entry}}$**：
    * **盤後評估現價／已觸發訊號模式（預設）**：直接以 T 日收盤價定錨 $P_{\text{entry}} = C_t$。
    * **次日突破預掛觸價單模式（若股價尚在樞紐點 $P_{\text{pivot}}$ 之下蓄勢）**：定錨於樞紐高點加 1 個 Tick，即 $P_{\text{entry}} = P_{\text{pivot}} + \text{Tick}(P_{\text{pivot}})$（且次日最大追價上限為 $P_{\text{limit}} = \text{RoundTick}_{\downarrow}(P_{\text{entry}} \times 1.03)$，跳空開高超過 $3\%$ 則放棄不追）。
* **各型態之原始結構停損價 $P_{\text{stop, raw}}$**：
    * **Setup A（順勢突破）**：取近 5 日最低價 $L_{5,t}$ 與月線 $\text{MA}_{20,t}$ 之較高支撐（若高於 $P_{\text{entry}}$ 則改取 $\min(L_{5,t}, \text{MA}_{20,t})$）再減 1 個 Tick：
        $$P_{\text{support, A}} = \begin{cases} \max(L_{5,t}, \text{MA}_{20,t}), & \text{若 } \max(L_{5,t}, \text{MA}_{20,t}) < P_{\text{entry}} \\ \min(L_{5,t}, \text{MA}_{20,t}), & \text{其他} \end{cases}$$
        $$P_{\text{stop, raw}} = \text{RoundTick}_{\downarrow}\big(P_{\text{support, A}} - \text{Tick}(P_{\text{support, A}})\big)$$
    * **Setup B（拉回支撐）**：取近 10 日回檔低點 $L_{10,t}$ 與 $\text{MA}_{20,t}$ 之較低結構點減 1 個 Tick：
        $$P_{\text{stop, raw}} = \text{RoundTick}_{\downarrow}\big(\min(L_{10,t}, \text{MA}_{20,t}) - \text{Tick}(\text{MA}_{20,t})\big)$$
    * **Setup C（催化動能）**：取催化突破長紅 K 當日低點 $L_t$ 減 1 個 Tick：
        $$P_{\text{stop, raw}} = \text{RoundTick}_{\downarrow}\big(L_t - \text{Tick}(L_t)\big)$$
    * **Setup N（逆勢／無序整理保底）**：取近 10 日最低價 $L_{10,t}$ 減 1 個 Tick：
        $$P_{\text{stop, raw}} = \text{RoundTick}_{\downarrow}\big(L_{10,t} - \text{Tick}(L_{10,t})\big)$$

#### 3. ATR 波動雜訊夾擠校正與實質停損幅度（$a$）
為避免停損設於日常隨機雜訊內（過窄易被洗盤），同時嚴禁停損超過 $8.0\%$ 硬上限（過寬傷及本金），將原始停損距離 $D_{\text{raw}} = P_{\text{entry}} - P_{\text{stop, raw}}$ 以 $\text{ATR}_{14,t}$ 進行夾擠校正：
* **最小防雜訊距離**：$D_{\min} = 1.0 \times \text{ATR}_{14,t}$
* **最大允許停損距離**：$D_{\max} = \min\big(2.0 \times \text{ATR}_{14,t}, \; 0.08 \times P_{\text{entry}}\big)$
* **最終核定停損價 $P_{\text{stop}}$**：
    $$P_{\text{stop}} = \text{RoundTick}_{\downarrow}\!\Big(P_{\text{entry}} - \max\big(D_{\min}, \; \min(D_{\text{raw}}, \; D_{\max})\big)\Big)$$
    *(註：若原始結構停損幅度 $\frac{D_{\text{raw}}}{P_{\text{entry}}} > 8.0\%$，代表技術防守點過遠，系統標記為 `ERR_STOP_TOO_WIDE` 並拒絕開立新倉；若為既有持股分析，則以 $P_{\text{stop, raw}}$ 如實反映結構風險)*。
* **計入摩擦成本之實質停損幅度 $a$**：
    $$a = \frac{P_{\text{entry}} - P_{\text{stop}}}{P_{\text{entry}}} + c_{\text{fric}}$$

#### 4. 波段目標價（$P_{\text{target}}$）、實質獲利幅度（$b$）與淨盈虧比（$B$）
設近 20 日箱型高低差為 $\Delta H_{20} = H_{20,t} - L_{20,t}$，近 60 日前波高點為 $H_{60,t}$：
* **計數動能延伸係數 $\lambda(TC)$**：
    $$\lambda(TC) = \min\Big(1.50, \; \max\big(0.85, \; 1.00 + 0.08 \times TC\big)\Big)$$
* **波段結構目標價 $P_{\text{target}}$**：
    結合箱型等幅測距（$\Delta H_{20}$）、波動率波段倍數（$3.5 \times \text{ATR}_{14,t}$）與前高空間（$H_{60,t} - P_{\text{entry}}$）取結構目標：
    $$P_{\text{target}} = \text{RoundTick}_{\uparrow}\!\Big(P_{\text{entry}} + \lambda(TC) \times \max\big(\Delta H_{20}, \; 3.5 \times \text{ATR}_{14,t}, \; H_{60,t} - P_{\text{entry}}\big)\Big)$$
* **計入摩擦成本之實質淨獲利幅度 $b$ 與淨盈虧比 $B$**：
    $$b = \frac{P_{\text{target}} - P_{\text{entry}}}{P_{\text{entry}}} - c_{\text{fric}}, \qquad B = \frac{b}{a}$$

## 3. 股市凱利公式與倉位管理：消除波動拖累與實現對數複利

### 3.1 導論：為何「高勝率波段策略」仍會因重倉與槓桿而破產？
在股市中，擁有正期望值的選股或波段策略僅是獲利的「必要條件」，而非「充分條件」。無數掌握優秀技術型態或基本面研究能力的交易者，最終仍舊在股市中傾家蕩產，關鍵原因在於忽略了**「獲利與虧損在幾何複利上的嚴重不對稱性」**。

100 萬本金若虧損 $50\%$ 剩下 50 萬，下一筆交易必須獲利 $+100\%$ 才能回到原點；若虧損 $80\%$ 剩下 20 萬，則需要 $+400\%$ 的驚人報酬才能回本。這種因部位過大導致資產淨值在震盪中不斷縮水的現象，稱為**「波動拖累（Volatility Drag）」**。

為具體展示倉位大小對長期資金曲線的決定性影響，假設某交易員擁有一個極為優異的短波段系統：每次交易勝率高達 $p = 60\%$，敗率 $q = 40\%$，為簡化對比，假設每次投入固定比例風險資金，獲勝時該筆風險資金翻倍（$1:1$ 賠率），連續執行 $N = 100$ 筆獨立交易，初始總本金 $W_0 = 100\text{ 萬元}$：

1. **全押梭哈策略（單筆承受 100% 本金風險）**：
    單次算術期望值高達 $1.2$ 倍，100 次後的理論算術期望值雖為 $1.2^{100} \approx 8.28 \times 10^7$ 倍的天文數字，但在真實的「單一時間線（Single Time-line）」上，只要在 100 次交易中遇到**任何 1 次**停損（機率為 $1 - 0.6^{100} \approx 100\%$），帳戶本金即刻歸零出局。這體現了金融市場中的**「遍歷性破缺（Ergodicity Breakdown）」**——平行宇宙的算術平均數（Ensemble Average）對單一交易員毫無意義，因為你沒有第二次生命。
2. **過度重倉策略（單筆承受 40% 本金風險）**：
    在 100 筆交易中，最典型的結果是贏 60 筆、輸 40 筆。獲利時總資產乘以 $1.4$，虧損時總資產乘以 $0.6$。100 筆交易後的最終財富倍數為：
    $$1.4^{60} \times 0.6^{40} \approx (5.67 \times 10^8) \times (1.34 \times 10^{-9}) \approx 0.78 \text{ 倍}$$
    **這是一個令所有重倉交易者震驚的數學事實**：即便你的選股勝率高達 $60\%$，100 次出手贏了 60 次、只輸 40 次，但因為單筆承受了 $40\%$ 的過度風險，100 萬本金最終反而縮水剩 **78 萬元（累計虧損 $22\%$）**！
3. **凱利最佳值策略（單筆承受 20% 本金風險）**：
    獲利時總資產乘以 $1.2$，虧損時乘以 $0.8$。100 筆交易後的典型財富倍數為：
    $$1.2^{60} \times 0.8^{40} \approx (5.63 \times 10^4) \times (1.33 \times 10^{-4}) \approx 7.50 \text{ 倍}$$
    初始 100 萬元本金成長至 **750 萬元**，達到單一時間線上對數幾何增長率（Logarithmic Growth Rate）的理論極大值。
4. **半凱利防禦策略（單筆承受 10% 本金風險）**：
    獲利時總資產乘以 $1.1$，虧損時乘以 $0.9$。典型財富倍數為：
    $$1.1^{60} \times 0.9^{40} \approx 304.48 \times 0.01478 \approx 4.50 \text{ 倍}$$
    本金穩健成長至 **450 萬元**。雖然單筆風險砍半，卻依然保留了全凱利約 $75\%$ 的長期對數成長率，且將期間最大回撤（MDD）與心理崩潰風險大幅降低。

| 倉位策略類型 | 單筆風險暴露比例 | 100 筆交易後典型資金倍數 | 破產/斷頭機率 | 資金曲線特徵與最大回撤 (MDD) |
| :--- | :--- | :--- | :--- | :--- |
| **梭哈全押（All-in）** | 100% | $0.00$ 倍（必然歸零） | $\approx 100.0\%$ | 單次看錯或黑天鵝即永久踢出市場 |
| **過度重倉（Overbetting）** | 40% | $\approx 0.78$ 倍（本金倒賠 22%） | 極高（實質慢性破產） | 劇烈暴漲暴跌，被波動拖累侵蝕本金 |
| **全凱利配置（Full Kelly）** | 20% | $\approx 7.50$ 倍（成長至 750 萬） | $0.0\%$（理想模型下） | 幾何增長最快，但連敗期回撤仍偏大 |
| **半凱利配置（Half Kelly）** | 10% | $\approx 4.50$ 倍（成長至 450 萬） | $0.0\%$（高安全邊際） | 曲線平滑、回撤受控，兼具複利與存活 |

### 3.2 股市版廣義凱利公式：嚴格數學推導與雙核心公式
賭場與股市最大的結構差異在於：**在賭場中，輸掉一局通常是賠光 $100\%$ 下注籌碼（即 $a = 1$，基礎凱利公式為 $f^* = \frac{bp - q}{b}$）；而在股市交易中，我們設有「停損點（Stop-Loss）」，單筆虧損幅度為 $a$（例如 $5\% \sim 7\%$），獲利幅度為 $b$（例如 $12\% \sim 20\%$）。**

#### 1. 離散型股市廣義凱利公式推導
設交易員將總資金比例 $f$ 買進某檔股票，獲勝機率為 $p$（報酬率 $+b$），失敗機率為 $q = 1 - p$（報酬率 $-a$）。單筆交易後的預期對數財富增長率（Expected Log-Growth Rate）$g(f)$ 為：
$$g(f) = E[\ln(1 + R_{\text{portfolio}})] = p \ln(1 + f \cdot b) + q \ln(1 - f \cdot a)$$
為求極大化對數複利增長率之最佳倉位 $f^*$，將 $g(f)$ 對 $f$ 求一階導數並令其為 $0$：
$$\frac{\partial g(f)}{\partial f} = \frac{p \cdot b}{1 + f^* \cdot b} - \frac{q \cdot a}{1 - f^* \cdot a} = 0$$
通分整理後可得：
$$p \cdot b (1 - f^* \cdot a) = q \cdot a (1 + f^* \cdot b) \implies p \cdot b - q \cdot a = f^* \cdot a \cdot b (p + q)$$
由於 $p + q = 1$，移項即導出**股市廣義凱利雙核心公式**：

1. **第一步：計算「理論凱利風險金上限（$r^*$）」**（單筆停損理論上最多可賠總資金的幾 %）：
    $$r^* = p - \frac{q \cdot a}{b} = p - \frac{q}{B} = \frac{B \cdot p - q}{B} = \frac{E[R]}{B}$$
2. **第二步：反推「理論全凱利買進倉位比例（$f^*$）」**（理論上該買進總資金幾 % 的股票市值）：
    $$f^* = \frac{p}{a} - \frac{q}{b} = \frac{r^*}{a}$$

> **【公式物理意義解析】**：
> 為什麼理論買進倉位 $f^* = \frac{r^*}{a}$？因為當你買進佔總資金 $f^*$ 比例的股票，且在下跌 $a\%$ 時嚴格執行停損，這筆交易對總資金造成的實際虧損正好就是 $f^* \times a = r^*$！這將「勝率與盈虧比決定風險金 $r^*$」與「停損距離決定買進市值 $f^*$」完美解耦。

#### 2. 連續時間金融近似公式（基於預期報酬與波動率變異數）
在中長線資產配置或動態調整持倉中，當股價服從幾何布朗運動（GBM）且追求對數效用函數 $U(W) = \ln(W)$ 極大化時，凱利公式與諾貝爾獎得主默頓的資產配置模型（Merton's Portfolio Problem）完全同構：
$$f^* \approx \frac{\text{超額期望報酬 (Edge)}}{\text{報酬率變異數 (Variance)}} = \frac{\mu - r_f}{\sigma^2}$$
* $\mu$：標的或策略之預期年化報酬率
* $r_f$：無風險利率（如公債殖利率或資金借貸成本）
* $\sigma^2$：標的或策略報酬率之年化變異數（即年化波動率 $\sigma$ 的平方）

此公式揭示了股市倉位管理的黃金法則：**最佳部位與「預期超額報酬」成正比，但與「波動率的平方（$\sigma^2$）」成反比**。當市場進入高波動期（例如 VIX 飆升或個股 ATR 放大 2 倍），變異數 $\sigma^2$ 會放大為 $4$ 倍，此時即便預期報酬不變，凱利最佳持股倉位也必須強制縮減至原本的 **$\frac{1}{4}$**！

### 3.3 股市三大致命陷阱：為何必須強制執行「分數凱利（Fractional Kelly）」？
如果直接把公式算出的「全凱利倉位（$f^*$）」套用到股市實盤，幾乎必然會遭遇災難性的資產回撤甚至斷頭。原因在於股市存在三大賭場沒有的結構性風險：

#### 陷阱一：市況轉換與參數高估風險（Regime Shift & Parameter Uncertainty）
模型算出的勝率 $p$ 與盈虧比 $B$ 屬於有限樣本下的統計估計，而非物理常數。在多頭順風期（Bull Regime），波段突破策略勝率可能高達 $70\%$；一旦市場無預警轉入黏著盤整期（Choppy Regime），真實勝率往往驟降。

我們以嚴格的**期望對數財富成長公式（Expected Log-Wealth Growth）**證明參數高估的毀滅性：
假設某交易員根據多頭回測，認為某高波動策略有 $p = 70\%$ 機率獲利 $b = 30\%$，有 $q = 30\%$ 機率虧損 $a = 50\%$：
* **交易員自認的最佳全凱利倉位**：
    $$f^* = \frac{p}{a} - \frac{q}{b} = \frac{0.7}{0.5} - \frac{0.3}{0.3} = 1.4 - 1.0 = 40\% \text{ 倉位}$$
* **市場轉換後的殘酷真相**：
    當市場進入震盪期，真實勝率由 $70\%$ 下滑至 $60\%$（敗率升至 $40\%$），此時真實算術期望值已轉為負值（$0.6 \times 30\% - 0.4 \times 50\% = -2\%$）。若交易員仍不知情地按照 $f = 40\%$ 倉位持續進場，其單筆交易的期望對數財富變化為：
    $$E[\ln(X)] = p \ln(1 + f \cdot b) + q \ln(1 - f \cdot a)$$
    $$E[\ln(X)] = 0.6 \ln(1 + 0.4 \times 0.3) + 0.4 \ln(1 - 0.4 \times 0.5)$$
    $$E[\ln(X)] = 0.6 \ln(1.12) + 0.4 \ln(0.80) \approx 0.067997 - 0.089257 = -0.02126$$
    取指數還原為單次交易的幾何財富乘數：
    $$\exp(E[\ln(X)]) = e^{-0.02126} \approx 0.97896$$
    這代表勝率僅僅被高估了 $10\%$，卻導致交易員每做一筆交易，帳戶淨值就以 **$2.1\%$ 的幾何速度加速衰減**！

```
【股市參數高估的毀滅性傳導鏈】
回測多頭勝率 p = 70%  ==>  按全凱利重押 40% 倉位 (自認最佳化)
實盤震盪勝率 p = 60%  ==>  真實期望值已轉為 -2% (正確倉位應為 0%)
繼續重押 40% 的後果   ==>  E[ln(X)] = -0.02126  ==>  每筆交易本金幾何萎縮 2.1%
結論：在非平穩的金融市場中，使用「全凱利」等同於將自己暴露在過度下注的破產懸崖邊。
```

#### 陷阱二：隔夜跳空與穿價風險（Overnight Gap Risk）
在廣義凱利公式 $f^* = \frac{r^*}{a}$ 中，分母 $a$ 是你「預設的停損幅度」。例如 $r^* = 10\%$，你設定極窄的 $a = 2\%$ 停損，公式會叫你買進 $\frac{10\%}{2\%} = 500\%$（5 倍槓桿）的倉位！
然而，股市並非 24 小時連續交易。若持倉過夜遭遇突發利空、財報暴雷或系統性黑天鵝，隔日開盤直接跳空跌停 $-10\%$（穿價滑價），你的停損單只能在 $-10\%$ 成交，實際虧損是預設 $2\%$ 的 **5 倍**，單次跳空就會直接抹殺 $50\%$ 總本金！

#### 陷阱三：多持股同質性與 Beta 共振風險（Portfolio Correlation Risk）
凱利公式預設每次下注是獨立事件；但在股市中，若你同時買進 5 檔 AI 半導體波段強勢股，平時看似分散，一旦大盤發生系統性崩跌，這 5 檔股票的相關係數（Correlation）會瞬間趨近於 $1.0$ 並同時觸發停損。若每檔股票各押 $20\%$ 凱利風險，實質上等同於將 $100\%$ 風險重押在同一筆方向性賭注上。

### 3.4 實戰控倉引擎：分數凱利、多重硬上限與股數精算公式
為同時防禦參數高估、隔夜跳空與多標的共振，本系統強制執行以下四階段定量控倉算式：

#### 步驟 1：正期望值准入檢核（Edge Gate）
若個股不滿足以下任一條件，直接判定為無統計優勢，令實戰風險金 $r_{\text{actual}} = 0$（禁止買進）：
$$\text{准入條件} \iff \Big(E[R] \ge +0.20R\Big) \land \Big(B \ge 1.80 \text{（方向性波段建議 } \ge 2.00\text{）}\Big) \land \Big(S_{\text{mkt}} \ge 0\Big)$$

#### 步驟 2：帳戶回撤斷路器乘數（$\kappa_{\text{dd}}$）
設帳戶當前總淨值為 $W_t$，歷史峰值淨值為 $W_{\text{peak}}$，當前帳戶回撤率 $\text{DD}_t = \frac{W_{\text{peak}} - W_t}{W_{\text{peak}}}$，最近連續停損次數為 $L_{\text{streak}}$：
$$\kappa_{\text{dd}} = \begin{cases} 1.00, & \text{若 } \text{DD}_t < 8.0\% \text{ 且 } L_{\text{streak}} < 2 \\ 0.50, & \text{若 } 8.0\% \le \text{DD}_t < 12.0\% \text{ 或 } L_{\text{streak}} = 2 \text{（單筆風險強制砍半）} \\ 0.00, & \text{若 } \text{DD}_t \ge 12.0\% \text{ 或 } L_{\text{streak}} \ge 3 \text{（斷路器啟動，全面暫停開新倉）} \end{cases}$$

#### 步驟 3：計算實戰單筆風險金比例（$r_{\text{actual}}$）
將理論全凱利風險 $r^* = p - \frac{q}{B}$ 乘以**分數凱利折減係數 $k_{\text{frac}}$**（方向性波段標準取 $k_{\text{frac}} = \frac{1}{15} \approx 0.0667$，以對沖隔夜跳空與最多 5 檔持倉之 Beta 共振；中性套利取 $k_{\text{frac}} = 0.05$），並受策略單筆硬上限 $r_{\max}$（即 $1R$ Cap，介於 $1.00\% \sim 1.50\%$）與環境、回撤乘數約束：
$$r_{\text{actual}} = \kappa_{\text{regime}} \times \kappa_{\text{dd}} \times \min\Big(k_{\text{frac}} \cdot r^*, \; r_{\max}\Big)$$
*(註：當個股通過正期望值准入門檻且 $r^* \ge 18\%$ 時，在小額或標準帳戶中亦可直接以策略表定之標準單筆風險 $r_{\text{std}} \times \kappa_{\text{regime}} \times \kappa_{\text{dd}}$ 作為 $r_{\text{actual}}$，兩者在 $r^* \in [18\%, 27\%]$ 時完全收斂於 $1.0\% \sim 1.5\%$)*。

#### 步驟 4：總在險資金（Portfolio Heat）、集中度與最終股數（$N$）公式
設帳戶目前持有 $m$ 檔未平倉部位，第 $i$ 檔部位之買進股數為 $N_i$、買進均價為 $P_{\text{cost},i}$、當前設定之停損價為 $P_{\text{stop},i}$：
* **單一舊部位之未平倉在險資金比例（$r_{\text{open},i}$）**：
    當停損價已上移至含稅費保本點之上（即 $P_{\text{stop},i} \ge P_{\text{cost},i}(1 + c_{\text{fric}})$），該部位之在險資金歸零：
    $$r_{\text{open},i} = \max\left(0, \; \frac{N_i \times \big(P_{\text{cost},i}(1 + c_{\text{fric}}) - P_{\text{stop},i}\big)}{W_t}\right)$$
* **帳戶當前總在險資金（Portfolio Heat, $H_{\text{open}}$）與剩餘可用風險額度（$r_{\text{avail}}$）**：
    $$H_{\text{open}} = \sum_{i=1}^{m} r_{\text{open},i}, \qquad r_{\text{avail}} = \max\big(0, \; H_{\max} - H_{\text{open}}\big)$$
* **實質核定買進倉位比例（$f_{\text{actual}}$）**：
    同時受制於「停損距離反推倉位 $\frac{\min(r_{\text{actual}}, r_{\text{avail}})}{a}$」、「單一持股上限 $f_{\max}$（預設 $20\% \sim 25\%$）」、「單一產業／同題材集中度上限（$40\% - F_{\text{sector}}$，其中 $F_{\text{sector}}$ 為同族群已持倉佔比）」與「可用交割現金比例 $\frac{C_{\text{cash}}}{W_t(1+c_{\text{fric}})}$」四道硬邊界：
    $$f_{\text{actual}} = \min\left(\frac{\min(r_{\text{actual}}, \; r_{\text{avail}})}{a}, \; f_{\max}, \; \max(0, \; 0.40 - F_{\text{sector}}), \; \frac{C_{\text{cash}}}{W_t \cdot (1 + c_{\text{fric}})}\right)$$
* **最終核定買進股數（$N$）**：
    * **盤中零股精確模式（預設，適用於各級資金與高價股）**：
        $$N_{\text{shares}} = \left\lfloor \frac{W_t \times f_{\text{actual}}}{P_{\text{entry}}} \right\rfloor$$
    * **整張交易模式（千股向下取整）**：
        $$N_{\text{lots}} = \left\lfloor \frac{N_{\text{shares}}}{1000} \right\rfloor \times 1000$$

### 3.5 波段「動態加減碼（Pyramiding）」與出場防線的精確數學規範
持股買進後的動態管理（何時保本、何時加碼、何時減碼與清倉），全面以**當前實現／未實現風險倍數（$R_t$）**進行精確導航。

設某檔持股之平均買進成本為 $P_{\text{cost}}$、初始停損價為 $P_{\text{stop},0}$（若庫存表僅記載平均成本 $P_{\text{cost}}$ 而未記載歷史初始停損價，則統一以買進成本對應之波動幅度定錨：$P_{\text{stop},0} = \text{RoundTick}_{\downarrow}\big(P_{\text{cost}} - \min(\max(1.2 \times \text{ATR}_{14,t}, \; 0.05 \times P_{\text{cost}}), \; 0.07 \times P_{\text{cost}})\big)$）、初始含摩擦成本停損幅度為 $a_0 = \frac{P_{\text{cost}} - P_{\text{stop},0}}{P_{\text{cost}}} + c_{\text{fric}}$，則 T 日收盤之**未實現淨風險倍數（Unrealized R-Multiple, $R_t$）**與**當前動態有效防守價（$P_{\text{stop, active}}$）**為：
$$R_t = \frac{\left(\frac{C_t - P_{\text{cost}}}{P_{\text{cost}}}\right) - c_{\text{fric}}}{a_0}$$
$$P_{\text{stop, active}} = \begin{cases} \text{RoundTick}_{\downarrow}\!\big(\max(P_{\text{stop, BE}}, \; \text{MA}_{10,t})\big), & \text{若 } R_t \ge +2.50R \text{ 或 } \frac{C_t - \text{MA}_{20,t}}{\text{MA}_{20,t}} \ge 12.0\% \text{（強動能軌）} \\[6pt] \text{RoundTick}_{\downarrow}\!\big(\max(P_{\text{stop, BE}}, \; \min(L_{5,t}, \text{MA}_{20,t}))\big), & \text{若 } +1.50R \le R_t < +2.50R \text{（保本上移軌）} \\[6pt] \max(P_{\text{stop},0}, \; P_{\text{stop}}), & \text{若 } R_t < +1.50R \text{（初始結構防守軌）} \end{cases}$$

#### 1. 動態金字塔加碼（Pyramiding）三階段數學條件
唯有當底倉證明方向正確且釋放風險後，方允許順勢加碼（**絕對禁止在 $R_t < 0$ 虧損狀態下向下攤平**）：
* **階段一：底倉脫離成本與保本上移（Breakeven Release）**
    * **觸發條件**：$R_t \ge +1.50R$（或股價突破後拉回不破低並再創波段新高，且未實現淨報酬 $\ge +6.0\%$）。
    * **執行動作**：將底倉停損價 $P_{\text{stop}}$ 強制上移至含摩擦成本之損益兩平價：
        $$P_{\text{stop, BE}} = \text{RoundTick}_{\uparrow}\!\big(P_{\text{cost}} \times (1 + c_{\text{fric}})\big)$$
        此時底倉之在險資金 $r_{\text{open}} = 0\%$，正式釋放帳戶之 Portfolio Heat 額度。
* **階段二：金字塔順勢加碼點觸發與股數計算（$0.5R$ 遞減加碼法則）**
    * **加碼准入條件（須同時成立）**：
        1. 底倉已完成保本上移（$P_{\text{stop}} \ge P_{\text{stop, BE}}$）且當前 $R_t \ge +1.50R$；
        2. 個股出現量縮回測 $\text{MA}_{10,t}$ 止跌或平台二次突破，且當日重新核算之 $TC \ge +1.5$、$E[R] \ge +0.25R$；
        3. 大盤處於順風期（$S_{\text{mkt}} \ge +3$）。
    * **加碼股數公式（$N_{\text{add}}$）**：
        加碼單僅動用標準單筆風險金的 **$50\%$**（即 $r_{\text{add}} = 0.50 \times r_{\text{actual}}$）。設加碼買進價為 $P_{\text{add}} = C_t$、加碼結構停損價為 $P_{\text{stop, add}} = \text{RoundTick}_{\downarrow}(\min(L_{5,t}, \text{MA}_{10,t}) - \text{Tick}(C_t))$、加碼停損幅度為 $a_{\text{add}} = \frac{P_{\text{add}} - P_{\text{stop, add}}}{P_{\text{add}}} + c_{\text{fric}}$，且加碼後該股總持倉市值比例不得超過單一持股硬上限 $f_{\max}$：
        $$f_{\text{add}} = \min\left(\frac{0.50 \times r_{\text{actual}}}{a_{\text{add}}}, \; \max\left(0, \; f_{\max} - \frac{N_{\text{held}} \times C_t}{W_t}\right), \; \frac{r_{\text{avail}}}{a_{\text{add}}}\right)$$
        $$N_{\text{add}} = \left\lfloor \frac{W_t \times f_{\text{add}}}{P_{\text{add}}} \right\rfloor$$
        *(註：加碼成交後，整筆部位之合併停損價不得低於加權平均成本價 $P_{\text{cost, new}} \times (1 + c_{\text{fric}})$ 與 $P_{\text{stop, add}}$ 之較高者，確保加碼絕不讓整筆交易由盈轉虧)*。

#### 2. 六道結構化減碼與出場防線（Exit Priority Hierarchy）
當持股觸發以下任一數學條件時，依優先級由高至低執行減碼或清倉：

| 優先級 | 防線代碼與名稱 | 精確數學觸發條件 | 執行動作與減碼比例 |
| :---: | :--- | :--- | :--- |
| **P0** | **外生非模型風險撤離** | 觸發第 4.2 節任一外生異常條件（如財報現金流背離、無量跌停、利多爆量長黑破月線） | **次日開盤 $100\%$ 全數市價清倉**（先砍倉、後查證） |
| **P1** | **初始／保本硬停損** | 盤中或收盤價跌破當前有效停損價：$C_t \le P_{\text{stop}}$ | **觸價即刻 $100\%$ 全數停損出場**（嚴禁向下移動停損） |
| **P2** | **假突破與時間停損** | 1. 突破買進當日收長上影線收破樞紐點且 $V_t < 1.2 \cdot \text{MV}_{20,t}$；或<br>2. 持有滿 $6$ 個交易日，期間 $\max R_t < +0.5R$ 且當前 $|R_t| \le 0.3R$ 且 $TC < +1.0$ | **次日開盤 $100\%$ 全數平倉**，釋放時間與機會成本 |

| **P4** | **末升段高潮力竭減碼**<br>*(連續凱利 $\sigma^2$ 暴增縮倉)* | 1. 季線正乖離率 $\text{BIAS}_{60,t} = \frac{C_t - \text{MA}_{60,t}}{\text{MA}_{60,t}} \ge 45\%$；或<br>2. 高檔爆出 $V_t \ge 3.0 \cdot \text{MV}_{20,t}$ 且收黑 K（$C_t < O_t$，非漲停） | 變異數 $\sigma^2$ 急劇放大，依 $f^* \propto 1/\sigma^2$ **主動減碼 $50\% \sim 100\%$ 持股** |

## 4. 股市外生非模型風險與極端黑天鵝存活法則

### 4.1 導論：肥尾分佈（Fat Tails）與「切斷左尾」的存活戰略
傳統財務模型常假設股票報酬率服從常態分佈（Normal Distribution），但真實股市卻是典型的**「肥尾分佈（Heavy-tailed / Leptokurtic Distribution）」**——極端暴跌（如 1987 黑色星期一、2008 金融海嘯、2020 流動性熔斷）發生的頻率遠高於常態分佈預測的百萬分之一。

索普創立的量化避險基金 PNP（Princeton Newport Partners）之所以能創下連續 19 年零虧損年度、扣除管理費後年化複合報酬率（CAGR）約 $15\%$（累積成長 $14.2$ 倍），並在 1987 年 10 月美股單日暴跌 $22.6\%$ 的「黑色星期一」中全身而退，核心秘訣就在於**「偏態與峰度中性化（Skewness and Kurtosis Neutralization —— 切斷負向尾部風險 Negative Tail Risk）」**。

在股市複利競賽中，長期贏家並非單一年度賺取 $200\%$ 卻在隔年回吐 $70\%$ 的激進賭徒，而是能夠在任何股災中將最大回撤（MDD）控制在 $10\% \sim 15\%$ 以內、讓對數複利從不中斷的防禦型交易者。

### 4.2 股市非模型風險（Exogenous Non-Model Risks）的三大維度與量化一票否決式
即使選股邏輯、技術型態與凱利倉位計算毫無瑕疵，股市中仍存在無法由歷史 K 線內生建模的「外生非模型風險」。系統必須設立**硬性一票否決條件（一旦觸發，強制令 $p = 0, \; f_{\text{actual}} = 0$，既有持倉觸發 P0 撤離）**：

```
+-----------------------------------------------------------------------+
|              股市外生非模型風險的三大維度 (Non-Model Risks)            |
+-----------------------------------------------------------------------+
                                    |
    +-------------------------------+-------------------------------+
    |                               |                               |
    v                               v                               v
+-----------------------+   +-----------------------+   +-----------------------+
| 流動性枯竭與制度突變  |   |  財報造假與地雷詐欺   |   |  策略擁擠與微觀對抗   |
| (斷頭踩踏 / 交易限制) |   | (基本面黑天鵝識別)    |   | (Alpha 衰減 / 獵殺停損)|
+-----------------------+   +-----------------------+   +-----------------------+
| • 連續無量跌停鎖死    |   | • 財務報表虛增營收    |   | • 熱門技術型態假突破  |
| • 突發禁空令/提高保證金|   | • 營業現金流長期背離  |   | • 量化演算法狙擊停損點|
| • 融資維持率追繳連環爆|   | • 大股東掏空與高質押  |   | • 因子擁擠導致閃崩踩踏|
+-----------------------+   +-----------------------+   +-----------------------+
```

1. **流動性枯竭與制度/槓桿風險（對應 PNP 擠兌清算啟示）**：
    * **歷史借鏡**：1987 年底聯邦檢方動用《RICO 法案》搜查 PNP 東岸辦公室調查稅務問題（索普本人從未被起訴），法律調查引發機構客戶恐慌擠兌撤資，迫使一個連續 19 年無虧損、數學模型完全正常的基金清算解散。在股市中，**「融資追繳（Margin Call）與流動性枯竭」**就是散戶與基金的擠兌清算機。
    * **量化一票否決條件（Liquidity Gate）**：
        當近 20 日均量低於 500 張且近 20 日平均成交金額低於 5,000 萬元（排除高價千金股因張數較少之誤判），或列為處置／全額交割股、無量跌停鎖死時否決：
        $$\text{Reject}_{\text{liq}} \iff \Big(\text{MV}_{20,t} < 500\text{ 張} \land \text{MV}_{20,t} \times 1000 \times C_t < 5\times 10^7\text{ 元}\Big) \lor \Big(\text{處置／全額交割股}\Big) \lor \Big(H_t = L_t \land \frac{C_t - C_{t-1}}{C_{t-1}} \le -9.5\%\Big)$$
2. **財務造假與個股詐欺風險（對應索普識破馬多夫騙局）**：
    * **歷史借鏡**：1991 年索普審查馬多夫（Bernie Madoff）基金時，發現其宣稱的 S&P 500 期權交易量遠超整個 CBOE 交易所的市場總成交量，加上不自然平滑的報酬曲線，當機立斷執行「外生非模型風險離場機制」協助客戶撤資，提前 17 年避開史上最大龐氏騙局。
    * **量化一票否決條件（Financial Quality Gate，讀取季財報 CSV，適用於非金融保險業）**：
        當一般產業個股（非 `28xx` 金融股）帳面 $\text{EPS}_q > 0$，但同時出現**連續兩季營業活動現金流為負且應收帳款與存貨異常膨脹**，或**連續兩季虧損且負債率過高**時，無條件否決：
        $$\text{Reject}_{\text{fraud}} \iff \Big(\text{OCF}_q < 0 \land \text{OCF}_{q-1} < 0 \land \frac{\text{AR}_q + \text{INV}_q}{\text{流動資產}_q} \ge 0.75\Big) \lor \Big(\text{EPS}_q < 0 \land \text{EPS}_{q-1} < 0 \land \text{負債率}_q \ge 70\%\Big)$$
        *(其中 $\text{OCF}$ 為營業活動現金，$\text{AR}$ 為應收帳款淨額，$\text{INV}$ 為存貨；若為 `28xx` 金融保險業，僅於連續兩季 $\text{EPS}_q < 0$ 時觸發否決)*。
3. **策略擁擠與市場微觀結構對抗（Strategy Crowding & Alpha Decay）**：
    * **歷史借鏡**：如同賭場為了對抗算牌客而將 1 副牌改為 8 副牌並修改賠率，當某個教科書式的突破型態或量化因子被全市場廣泛熟知時，主力機構與高頻演算法便會針對散戶密集的停損區進行「獵殺停損（Stop Hunting / 假突破真拉回）」，或在因子平倉時引發多殺多踩踏。
    * **量化異常撤離條件（Microstructure Breakdown Exit）**：
        * **個股層級**：基本面或消息面發布重大利多，但當日爆出 $V_t \ge 2.5 \cdot \text{MV}_{20,t}$ 巨量長黑（$\frac{O_t - C_t}{C_{t-1}} \ge 5.0\%$）且收盤跌破 $\text{MA}_{20,t}$ $\implies$ 觸發 P0 無條件清倉。
        * **策略層級（預期最大回撤倍數限制 MDD Cap）**：任一策略上線前須通過至少 5 年樣本外（Out-of-Sample）測試與蒙地卡羅（Monte Carlo）壓力測試；若實盤累計回撤超過回測預期最大回撤的 **$1.5\text{ 倍}$（$1.5 \times \text{Expected MDD}$）**，判定該策略因擁擠而發生結構性 Alpha 衰減，立即暫停該策略並重新校準參數。

#### 索普與巴菲特的終極交會：兩大流派的共同鐵律
1968 年索普與巴菲特會面切磋牌藝後，敏銳察覺巴菲特卓越的資本配置天賦並投資了波克夏（Berkshire Hathaway）。在股市中，索普代表了**「量化與技術波段流派（透過精確停損、動態對沖與凱利公式控制變異數 $\sigma^2$）」**，而巴菲特則代表了**「基本面價值投資流派（透過商業護城河與買入價格折扣創造安全邊際 Margin of Safety）」**。
兩人的操作週期與工具截然不同，但在風險控制的最底層卻完全收斂於同一條鐵律：
> **「永遠不要承擔任何可能導致你被踢出牌局的致命風險（Never take a fatal risk）。」**

同時，這套體系的最高境界在於**「知道何時收手（Knowing When is Enough）」**。2000 年代初期，當索普觀察到大量機構資金湧入統計套利導致策略擁擠、Alpha 被壓縮且必須提高槓桿才能維持回報時，他毅然選擇關閉基金主動離場。在波段交易中，當行情進入末升段、正乖離過大、波動率急劇放大時，變異數 $\sigma^2$ 正在暴增；根據連續凱利公式 $f^* \approx \frac{\mu - r_f}{\sigma^2}$，分母 $\sigma^2$ 暴增意味著最佳倉位應主動大幅縮減——在眾人加槓桿狂歡時逐步將獲利轉為現金，正是凱利公式賦予交易員最理性的退場機制。

## 5. 股市實戰指南：標準作業程序（SOP）、配置矩陣與演算範例

### 5.1 實戰交易四步驟標準作業程序（SOP）
每一筆股票交易決策（包含新開倉評估與既有持股體檢），必須嚴格依序執行以下四道量化程序：

1. **步驟一：外生風險排查與大盤導航計數（Safety & Regime Navigation）**
    * 檢查個股是否觸發第 4.2 節之流動性或財務現金流一票否決條件（$\text{Reject}_{\text{liq}} \lor \text{Reject}_{\text{fraud}}$）。
    * 讀取加權指數與櫃買指數數據，依第 2.1 節公式計算大盤環境計數 $S_{\text{mkt}} \in [-5, +6]$，決定環境調節乘數 $\kappa_{\text{regime}} \in \{1.0, 0.5, 0.0\}$ 與帳戶總在險資金上限 $H_{\max} \in \{6.0\%, 3.0\%, 0.0\%\}$。
2. **步驟二：個股真實計數 $TC$ 與條件勝率 $p$ 核算（Win Rate Engine）**
    * 依第 2.2 節公式計算個股四大維度得分：$S_{\text{trend}} \in [0, 30]$、$S_{\text{vol}} \in [0, 25]$、$S_{\text{chip}} \in [0, 25]$、$S_{\text{fund}} \in [0, 20]$，加總得出 $S_{\text{stock}} \in [0, 100]$。
    * 代入 $TC = \frac{S_{\text{stock}} - 50}{10} + 0.5 \cdot S_{\text{mkt}}$ 算出索普真實計數，並依第 2.3 節公式 $p = \text{clip}(p_0 + 0.025 \cdot TC, \; p_{\min}, \; p_{\max})$ 得出唯一確定的條件勝率 $p$ 與敗率 $q = 1 - p$。
3. **步驟三：價格定錨、盈虧比 $B$ 與正期望值檢核（Payoff & Edge Check）**
    * 依第 2.4 節計算 $\text{ATR}_{14,t}$、進場價 $P_{\text{entry}}$、經 ATR 夾擠校正後之停損價 $P_{\text{stop}}$ 與波段目標價 $P_{\text{target}}$。
    * 計入來回摩擦成本率 $c_{\text{fric}} = 0.585\%$，算出實質停損幅度 $a$、實質獲利幅度 $b$、淨盈虧比 $B = \frac{b}{a}$ 與單位風險期望值 $E[R] = p \cdot B - q$。若 $E[R] < +0.20R$ 或 $B < 1.80$，直接否決買進。
4. **步驟四：分數凱利風險預算、Portfolio Heat 與股數換算（Position Sizing & Execution）**
    * 計算理論全凱利風險 $r^* = p - \frac{q}{B}$，乘以分數凱利係數與環境/回撤乘數並受單筆硬上限 $r_{\max}$ 約束，得出 $r_{\text{actual}}$。
    * 盤點帳戶既有未保本部位之總在險資金 $H_{\text{open}} = \sum r_{\text{open},i}$，確認剩餘風險額度 $r_{\text{avail}} = \max(0, H_{\max} - H_{\text{open}})$。
    * 代入第 3.4 節公式算出最終買進倉位比例 $f_{\text{actual}}$ 與應買進股數 $N_{\text{shares}} = \lfloor \frac{W_t \cdot f_{\text{actual}}}{P_{\text{entry}}} \rfloor$；若為既有持股，則依第 3.5 節計算 $R_t$，給出明確的保本上移、金字塔加碼股數 $N_{\text{add}}$ 或 P0～P5 減碼/出場價格與數量。

### 5.2 股市主流交易策略之凱利倉位與風控配置矩陣

以下為四大標準策略型態在中性偏多基準（$TC = 0 \implies p = p_0$）下的基準參數與風控硬上限配置表：

### 5.3 完整端到端數學演算範例（Step-by-Step Reproducible Calculation Example）

為確保後續每次執行分析時皆有完全統一的計算範本，以下示範如何由客觀市場數據一步步算出唯一確定的勝率 $p$ 與買進股數 $N_{\text{shares}}$：

#### 【輸入數據假設】
* **帳戶狀態**：總淨值 $W_t = 500,000\text{ 元}$，可用現金 $C_{\text{cash}} = 300,000\text{ 元}$，目前持有 1 檔未保本部位佔用在險資金 $H_{\text{open}} = 1.10\%$，同產業已持倉市值佔比 $F_{\text{sector}} = 10.0\%$，帳戶無顯著回撤（$\text{DD}_t = 2.0\% < 8\% \implies \kappa_{\text{dd}} = 1.00$）。
* **大盤數據（T 日）**：加權指數站上月線與季線（$m_1 = +2$），月線與季線斜率皆向上（$m_2 = +2$），指數位於年線之上（$m_3 = +1$），近 3 日法人合計買超且櫃買站上月線（$m_4 = 1 + 1 - 1 = +1$）。
* **目標個股數據（T 日，符合 Setup A 突破型態）**：
    * 收盤價 $C_t = 1,000\text{ 元}$（$\text{Tick} = 5\text{ 元}$），$\text{MA}_{10,t} = 975$（上揚）、$\text{MA}_{20,t} = 960$（上揚）、$\text{MA}_{60,t} = 910$、$\text{MA}_{240,t} = 820$，一年最高價 $H_{240,t} = 1,050$。
    * 近 5 日高低差壓縮比 $\rho_{\text{range}} = 0.42 \le 0.45$，T 日帶量突破 10 日高點（$V_t = 1.5 \times \text{MV}_{20,t}$ 且收最高）。
    * 近 5 日法人合計買超（$F_5 > 0$）、近 3 日投信與外資皆買超，且近 5 日融資減少（$\Delta M_5 < 0$）。
    * 最新月營收年增率 $g_{\text{rev},t} = +28.5\%$（較上月 $+21.0\%$ 加速擴大 $+7.5\%$），最新季報 $\text{EPS}_q = 12.5\text{ 元}$（去年同季 $8.0\text{ 元}$），營業利益率 $\text{OPM}_q = 24.0\%$（高於去年同季 $20.5\%$），且營業現金流為正。
    * 波動與區間參數：$\text{ATR}_{14,t} = 35.0\text{ 元}$，近 5 日低點 $L_{5,t} = 955\text{ 元}$，近 20 日高低差 $\Delta H_{20} = 120.0\text{ 元}$，近 60 日高點 $H_{60,t} = 1,050\text{ 元}$。

#### 【四步驟確定性數學演算】
1. **步驟一：計算大盤計數 $S_{\text{mkt}}$**
    $$S_{\text{mkt}} = m_1 + m_2 + m_3 + m_4 = 2 + 2 + 1 + 1 = +6 \ge +3 \implies \text{🟢 Risk-On（順風攻擊期）}$$
    $$\kappa_{\text{regime}} = 1.00, \qquad H_{\max} = 6.00\%$$
2. **步驟二：計算個股結構分 $S_{\text{stock}}$、真實計數 $TC$ 與條件勝率 $p$**
    * $S_{\text{trend}} = 10 + 8 + 6 + 6 = 30\text{ 分}$
    * $S_{\text{vol}} = 15\text{（}\rho_{\text{range}} \le 0.45\text{）} + 10\text{（帶量突破）} = 25\text{ 分}$
    * $S_{\text{chip}} = (8 + 4 + 3)\text{（法人三買）} + 10\text{（資減法人買）} = 25\text{ 分}$
    * $S_{\text{fund}} = (5 + 3)\text{（營收高成長且加速）} + 6\text{（EPS 成長）} + 6\text{（OPM 擴張）} = 20\text{ 分}$
    * 個股總分與真實計數：
        $$S_{\text{stock}} = 30 + 25 + 25 + 20 = 100\text{ 分}$$
        $$TC = \frac{100 - 50}{10} + (0.5 \times 6) = 5.0 + 3.0 = +8.0$$
    * 代入 Setup A（$p_0 = 0.420$，上界 $p_{\max} = 0.600$）計算條件勝率 $p$：
        $$p = \min\big(0.600, \; \max(0.280, \; 0.420 + 0.025 \times 8.0)\big) = \min(0.600, \; 0.620) = 0.600 \text{（即 } 60.0\%\text{）}, \quad q = 0.400$$
3. **步驟三：計算定錨價格、實質停損 $a$、實質獲利 $b$、盈虧比 $B$ 與期望值 $E[R]$**
    * 進場基準價：$P_{\text{entry}} = C_t = 1,000\text{ 元}$
    * 原始結構停損價：$\max(L_{5,t}, \text{MA}_{20,t}) = \max(955, 960) = 960\text{ 元} < 1,000\text{ 元}$，減 1 個 Tick（$5\text{ 元}$）得 $P_{\text{stop, raw}} = 955\text{ 元}$（原始差距 $D_{\text{raw}} = 45\text{ 元}$）。
    * ATR 夾擠檢驗：$D_{\min} = 1.0 \times 35 = 35\text{ 元}$，$D_{\max} = \min(2.0 \times 35, \; 0.08 \times 1000) = 70\text{ 元}$。因 $35 \le 45 \le 70$，核定最終停損價：
        $$P_{\text{stop}} = 955\text{ 元}$$
    * 實質含稅費停損幅度 $a$（加計 $c_{\text{fric}} = 0.585\%$）：
        $$a = \frac{1000 - 955}{1000} + 0.00585 = 0.04500 + 0.00585 = 0.05085 \text{（即 } 5.085\%\text{）}$$
    * 波段目標價 $P_{\text{target}}$：
        $$\lambda(TC) = \min(1.50, \; 1.00 + 0.08 \times 8.0) = 1.50$$
        $$P_{\text{target}} = \text{RoundTick}_{\uparrow}\!\big(1000 + 1.50 \times \max(120, \; 3.5 \times 35, \; 1050 - 1000)\big) = \text{RoundTick}_{\uparrow}(1000 + 1.50 \times 122.5) = 1,185\text{ 元}$$
    * 實質淨獲利幅度 $b$ 與淨盈虧比 $B$：
        $$b = \frac{1185 - 1000}{1000} - 0.00585 = 0.18500 - 0.00585 = 0.17915 \text{（即 } 17.915\%\text{）}$$
        $$B = \frac{b}{a} = \frac{0.17915}{0.05085} \approx 3.5231$$
    * 單位風險數學期望值 $E[R]$：
        $$E[R] = (0.600 \times 3.5231) - (0.400 \times 1) = 2.1139 - 0.4000 = +1.7139R \ge +0.20R \implies \text{✅ 通過正期望值檢核}$$
4. **步驟四：計算凱利風險金 $r_{\text{actual}}$、買進倉位 $f_{\text{actual}}$ 與核定股數 $N_{\text{shares}}$**
    * 理論全凱利風險金上限 $r^*$：
        $$r^* = p - \frac{q}{B} = 0.600 - \frac{0.400}{3.5231} \approx 0.4865 \text{（即 } 48.65\%\text{）}$$
    * 實戰單筆風險金比例 $r_{\text{actual}}$（Setup A 單筆硬上限 $r_{\max} = 1.20\%$）：
        $$r_{\text{actual}} = 1.00 \times 1.00 \times \min\big(0.0667 \times 48.65\%, \; 1.20\%\big) = 1.20\%$$
    * 剩餘總在險資金檢查：$r_{\text{avail}} = 6.00\% - 1.10\% = 4.90\% \ge 1.20\% \implies$ 風險配額充足。
    * 計算買進倉位比例 $f_{\text{actual}}$（Setup A 單檔上限 $f_{\max} = 20.0\%$，同產業剩餘上限 $40\% - 10\% = 30\%$，現金上限 $\frac{300,000}{500,000 \times 1.00585} = 59.65\%$）：
        $$f_{\text{actual}} = \min\left(\frac{1.20\%}{5.085\%}, \; 20.00\%, \; 30.00\%, \; 59.65\%\right) = \min(23.60\%, \; 20.00\%, \; 30.00\%, \; 59.65\%) = 20.00\%$$
    * 換算應買進股數（盤中零股精確模式）：
        $$N_{\text{shares}} = \left\lfloor \frac{500,000 \times 20.00\%}{1,000} \right\rfloor = 100\text{ 股（投入市值 } 100,000\text{ 元，實際承擔停損風險 } 100,000 \times 5.085\% = 5,085\text{ 元，佔總資金 } 1.017\%\text{）}$$

### 5.4 股市交易員必備：防止本金歸零的五大實戰鐵律

每一位希望在股市長期存活並享受複利奇蹟的交易者，必須將以下五條鐵律視為不可逾越的風控憲章：

#### 鐵律一：根除「向下攤平」惡習，嚴防波動拖累（No Averaging Down & Avoid Volatility Drag）
永遠記住虧損對幾何複利的不對稱傷害。在沒有預先規劃的分批建倉區間外，**嚴禁在部位發生虧損（$R_t < 0$）、跌破關鍵支撐時「向下攤平」**。虧損加碼違反了凱利公式「僅在條件勝率提升時擴大部位」的核心原則；唯有在底倉出現浮盈（$R_t \ge +1.5R$）、停損上移至保本點鎖定風險後，才允許執行 $0.5R$ 順勢金字塔加碼（Pyramiding）。

#### 鐵律二：無停損點即無凱利倉位，強制執行分數凱利（Stop-Loss First & Fractional Kelly）
在股市中，沒有明確的停損距離（$a$），分母即為未知，凱利倉位便無從定義。進場前必須先由 K 線結構與 $\text{ATR}_{14,t}$ 決定「哪個價位證明我看錯並無條件離場」，再由停損距離反推買進股數。永遠對模型勝率保持謙卑，將單筆停損對總資產的傷害嚴格控制在 **$0.5\% \sim 1.5\%$** 的分數凱利安全邊際內。

#### 鐵律三：防範「隔夜跳空」與「多持股 Beta 共振」（Cap Single Position & Control Beta Correlation）
切勿因停損設得很窄（如 $-1.5\%$）就將單一股票買到滿倉或高倍融資，因為隔夜跳空缺口隨時可能擊穿你的停損單。單一標的持倉市值原則上不超過總資金的 **$20\% \sim 25\%$**；同時，當手中多檔持股屬於同一熱門題材或高度相關族群時，其合計持倉市值不得超過總資金的 **$40\%$**，且帳戶總在險資金（Portfolio Heat）嚴格鎖定於 **$6.0\%$** 以內。

#### 鐵律四：對外生非模型風險保持絕對敬畏（Exogenous Risk Exit Protocol）
技術型態與量化模型無法預測公司財務造假、大股東掏空、突發地緣政治衝突或交易所流動性鎖死。當個股出現「營業現金流連續為負且應收帳款與存貨異常飆升、利多不漲反爆量長黑跌破月線、或無預警閃崩跌破所有均線」等非模型異常訊號時，必須秉持「先砍倉、後查證」的原則，優先保全本金流動性。

#### 鐵律五：啟動「動態回撤斷路器」，永遠留在牌桌上（Drawdown Circuit Breaker & Ergodicity）
大數法則與統計優勢需要數百筆以上的獨立交易才能完全顯現威力，前提是你必須永遠留在場上。建立帳戶級別的**「回撤斷路器（Circuit Breaker）」**：當帳戶總淨值從高點回撤達 $-8\%$（或連續 2 筆停損）時，強制將單筆風險預算（$1R$）減半（$\kappa_{\text{dd}} = 0.5$）；若回撤達 $-12\%$（或連續 3 筆停損），全面停止開新倉（$\kappa_{\text{dd}} = 0.0$）並檢視是否發生市場結構轉換（Regime Shift）。只要保住本金與遍歷性存活權，當下一波多頭順風期來臨時，對數複利終將帶你再創淨值高峰。
