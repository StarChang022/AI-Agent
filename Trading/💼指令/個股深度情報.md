# 額外規範

1. 禁止使用「---」分隔線。
2. 每個段落都要從 ## 這種 <h2> 開始使用，也就是說大段落為 <h2>，裡面如果還有子段落，則依序為 <h3> 和 <h4>。
3. 作為 <h2> 段落大標題的企業名稱採用 `# 股票` 列出的名稱「{Stock_ID} {Stock_Name}」即可。例如「- 2330 台積電」就採用「## 2330 台積電」，而不是「## 2330 台灣積體電路製造 (TSMC)」。
4. 不重要的資訊不需要特別翻譯英文。例如「中國大陸地區」不需要寫成「中國大陸地區（China）」。
