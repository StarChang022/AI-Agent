# 額外規範

1. 禁止使用「---」分隔線。
2. 每個段落都要從 ## 這種 <h2> 開始使用，也就是說大段落為 <h2>，裡面如果還有子段落，則依序為 <h3> 和 <h4>。
3. 關於金額的表現樣式，一律使用「$」符號。例如135元就寫成「$135」即可，不需要寫成「NT$135」或「135元」。
4. 如果數字有小數點，一律四捨五入至小數點第二位。例如「$135.00」。

# 重點
