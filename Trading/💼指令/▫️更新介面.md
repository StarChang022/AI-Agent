# 注意事項

- 報告日期格式：`報告撰寫日期：YYYY 年 M 月 D 日`，對應 `.report-date` 元素文字。
- 未來重要事件的日期格式統一使用 `MM/DD`（例如 09/10、12/17），對應 `.event-date` 元素文字。
- 持股損益如為正數，使用 class `pos`；如為負數，使用 class `neg`。
- 指數漲跌幅如為正數，使用 class `pos`；如為負數，使用 class `neg`。
- 如某個股已不在 `✅個股深度情報.md` 或 `✅價值投資.md` 中，移除其對應的 `<section>` 區塊，並同步移除快速跳轉清單中的 `.tag`。
- 如有全新個股，依照現有 `<section>` 的 HTML 結構範本新增，`id` 屬性格式為 `s{股票代號}`（個股深度）或 `v{股票代號}`（價值投資），例如 `id="s2330"`、`id="v2330"`。
