# 視覺設計與排版鐵律（嚴格遵守）

### 1. 淺色系主題（Light Theme）
- **頁面背景**：雲霧淺灰白 `#f0f4f8`，輔以柔和的放射狀漸層環境光。
- **卡片與導覽**：純白 `#ffffff`，搭配微細邊框 `rgba(0,0,0,0.08)` 或 `#e2e8f0` 與細緻懸浮陰影。
- **主要文字**：深邃墨藍 `#0f172a`（高對比度、極易閱讀）。
- **次要文字**：深石板灰 `#475569`；輔助標註：`#94a3b8`。

### 2. 台股慣用配色規範（紅漲綠跌）
- 📈 **上漲 / 獲利（Up / Bull / Gain）**：統一使用 **紅色**（`#dc2626`），用於漲幅（▲、`+`）、持股未實現獲利、多頭卡片頂部色條、潛在回歸漲幅等。
- 📉 **下跌 / 回檔（Down / Bear / Loss）**：統一使用 **綠色**（`#059669`），用於跌幅（▼、`-`）、跌停標記、空頭回檔卡片頂部色條等。
- ➖ **平盤 / 中性（Flat / Neutral）**：使用 **琥珀黃**（`#d97706`），用於持平數據、中性情緒指標。

### 3. 標籤樣式統一（Tag 簡潔灰）
- **所有標籤（Tag）統一採用中性灰色系**，嚴禁雜亂的彩虹色標籤，以維持畫面純淨度。
- 樣式定義：
  ```css
  .tag {
    display: inline-block;
    padding: 2px 8px;
    border-radius: 6px;
    font-size: 11px;
    font-weight: 500;
    background: #f1f5f9;
    color: #475569;
    border: 1px solid #e2e8f0;
  }
  ```

# 網頁架構與分頁規範

網頁需以頂部常駐導覽列提供 **4 大主題分頁（Tabs）** 切換，內容按以下架構組織：

```

[分頁導覽列] 🌏 今日市場情報 | ⚖️ 交易決策 | 🔬 個股深度情報 | 💎 價值投資分析
────────────────────────────────────────────────────────
[Tab 1: 今日市場情報]
  ├── 快速行情晶片（加權、櫃買、費半、台積電ADR、道瓊、那指、標普、上證、日經、恒生）
  ├── 今日利多消息清單 vs 今日利空消息清單
  ├── 市場情緒指標（VIX、CNN Fear & Greed 計量計、匯率、公債殖利率、法人買賣超）
  ├── 全球主要指數行情總覽表格
  ├── 今日名單個股速查卡片（開/高/低/收、漲跌幅、量能、核心亮點）
  ├── 聰明錢潛伏區表格（投資主題、核心標的、佈局邏輯）
  └── 未來 2 週重大事件時程表（Timeline）

[Tab 2: 交易決策]
  ├── 大盤趨勢與位階判定（5MA/10MA/20MA/60MA 多空排列、KD、乖離率）
  ├── 資金水位規劃（持股水位進度條、現金儲備比例、當前資產總值與可用現金）
  ├── 手中持股決策分析卡片（各檔持股狀態、損益紅/綠、技術型態、支撐壓力、操作策略與加減碼防守點）
  ├── 指定觀察個股分析（買進條件、觀望理由、進場訊號、停損點）
  └── 風控經理審查報告（整體資金集中度警告、單一個股風控核准狀態與強制紀律）

[Tab 3: 個股深度情報]
  └── 依照股票代號排序的互動折疊卡片（<details>）
      ├── 技術平台 / 產品營收佔比
      ├── 客戶結構與區域營收分佈
      ├── 企業營運概況、核心賺錢模式與競爭力
      ├── 最新季度財務表現（營收、EPS、三率毛利）
      └── 未來展望、潛在風險、競爭對手與護城河分析

[Tab 4: 價值投資分析]
  ├── 各核心個股巴菲特價值評估卡片
  │   ├── 核心財務數據（TTM EPS、2026E EPS、Forward P/E、Forward PEG、ROE、BVPS）
  │   ├── 五大估值模型交叉推算（本益比、PEG、股利折現 DDM、P/B-ROE 矩陣、DCF 現金流折現）
  │   ├── 五級估值區間色階條（便宜價、合理偏低、合理價中樞、合理偏高、昂貴價，並標記當前股價所在位置）
  │   └── 巴菲特視角總結評語
  └── 價值投資綜合比較表格（當前股價、本益比、PEG、合理價中樞、潛在回歸漲幅、巴菲特評級）
```
