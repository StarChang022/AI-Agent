- **Header 導航與 Logo 尺寸**：
  - Header 高度為 `62px`，Logo 高度為 `38px`（定義於 `css/style.css`，更新介面時切勿覆寫或更動）。
  - 導航選單僅保留 3 個項目：「今日市場情報」（`intelligence.html`）、「交易決策」（`strategy.html`）、「價值投資分析」（`value.html`）。
  - 已無「個股深度情報」獨立頁面或導航連結，切勿加回。
- **台股慣用配色規範（紅漲綠跌）**：
  - 依照台灣股市與繁體中文金融慣例，**「漲」為紅色、「跌」為綠色**（與美股相反）。
  - 指數漲跌點數、漲跌幅、持股損益、法人買超等**正數 / 漲幅 / 買超**：一律使用 class `pos`（紅色文字）。
  - 指數下跌點數、跌幅、持股虧損、法人賣超等**負數 / 跌幅 / 賣超**：一律使用 class `neg`（綠色文字）。
  - 切勿使用美股綠漲紅跌之相反配色。
- **未來重要事件**：
  - 日期格式統一使用 `MM/DD`（例如 09/10、12/17），對應 `.event-date` 元素文字。
- **個股部分更新原則（重要）**：
  - `⌚️暫存/value/` 資料夾**不一定**包含所有個股報告，每次可能只放入需要更新的部分個股。
  - **只對暫存資料夾中存在 `.md` 的個股執行新增或覆蓋**，其餘 `starck/value/` 中已存在的個股 HTML 頁面一律保持不動。
  - 判斷方式：逐一核對 `⌚️暫存/value/` 內的檔案名稱（格式 `{代號}{名稱}.md`），取出代號後，只處理對應的 `starck/value/{代號}.html`。
- **個股增刪處理**：
  - 若 `⌚️暫存/value/` 出現了 `starck/value/` 尚未存在的新個股，需同步執行：
    1. 建立 `value/{代號}.html` 個股頁面（參照現有個股頁面結構）
    2. 在 `value.html` 索引頁新增對應的 `<a href="value/{代號}.html">` 連結
    3. 在 `js/stock-tabs.js` 的 `STOCKS` 陣列新增對應的 `['{代號}', '{名稱}']` 項目
  - **不主動刪除**任何現有個股頁面，除非使用者明確指示。
